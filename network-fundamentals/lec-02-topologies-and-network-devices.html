Section 01

What is Network Topology?

Network Topology refers to the **geometric arrangement of nodes (computers, routers) and connecting lines (links)** in a communication network.

Aspect 1
📐 Physical Topology
The actual physical layout of cables, wires, computers, and central connecting hardware in a facility.
Aspect 2
⚡ Logical Topology
The path that data signals follow through the physical layout (e.g., Physical Star, Logical Bus or Ring).

Section 02

Mesh Topology (Formulas & Working)

🔥 IBPS SO IT – Numerical Favorite

In a fully connected Mesh topology, every device has a **dedicated point-to-point link** to every other device on the network.

⚡ Mesh Topology Formulas (Must Memorize)
$$\text{Number of Physical Links } L = \frac{N(N - 1)}{2}$$
$$\text{Number of I/O Ports per Node} = N - 1$$
Where $N$ = total number of devices/nodes in the network.
📝
Worked Example for IBPS SO IT
Question: How many physical links and ports per device are needed for 6 computers in a Mesh topology?
- Links: $L = \frac{6 \times (6 - 1)}{2} = \frac{30}{2} = \mathbf{15\text{ links}}$
- Ports per node: $N - 1 = 6 - 1 = \mathbf{5\text{ ports}}$

Advantages of Mesh

  • Dedicated traffic (no sharing, no congestion)
  • Robust: single link failure does not affect others
  • High privacy and security (dedicated lines)
  • Fault identification and isolation is easy

Disadvantages of Mesh

  • High installation and cable cost
  • Requires large number of I/O ports per device
  • Bulky wiring, difficult to reconfigure

Section 03

Star, Bus, Ring & Hybrid Topologies

Topology 1
⭐ Star Topology
- Each device is connected to a central hub or switch.
- Requires $N$ cables and $1$ port per node.
- Advantage: Easy to install, failure of 1 node doesn't affect network.
- Disadvantage: Central point of failure (if hub/switch fails, whole network crashes!).
Topology 2
🚌 Bus Topology
- All devices connected to a single backbone cable via drop lines and taps.
- Terminators required at both cable ends to prevent signal reflection.
- High collision risk (CSMA/CD protocol used).
- If backbone cable breaks, entire network goes down.
Topology 3
⭕ Ring Topology
- Each device connected to exactly 2 neighboring devices in a circular loop.
- Uses Token Passing (Token Ring IEEE 802.5) to prevent collisions.
- Token Release types: Early token release vs Delay token release.
- Monitor station manages the token. Break in ring breaks network.
Topology 4
🔀 Hybrid & Tree Topology
- Hybrid: Combination of 2 or more different topologies (e.g., Star-Bus, Star-Ring).
- Tree (Expanded Star): Hierarchical structure connecting multiple star networks to a central bus/hub.

Section 04

Network Devices by OSI Layer

Layer 1 · Physical
📡 Repeater
- 2-port device.
- Regenerates (copies bit-by-bit) weak signals before transmission over long distances.
- Does NOT amplify noise; purely regenerates clean signal.
Layer 1 · Physical
🔌 Hub
- Multiport repeater.
- Non-intelligent device: broadcasts incoming data to all connected ports.
- Types: Active Hub (regenerates signal) vs Passive Hub (wiring center only).
- Single collision domain, single broadcast domain.
Layer 2 · Data Link
🌉 Bridge
- 2-port device used to connect two LAN segments.
- Filters traffic by checking MAC addresses.
- Types: Transparent Bridge (auto-learning CAM table) vs Source Routing Bridge.
- Divides collision domain!
Layer 2 · Data Link
🔀 Switch
- Multiport bridge with dedicated hardware (ASIC).
- Uses MAC Address Table (CAM Table) to selectively forward frames to destination port.
- Divides collision domain (each port = separate collision domain).
- Broadcast domain remains 1 (unless VLAN configured).
Layer 3 · Network
🌐 Router
- Connects different networks (LANs & WANs).
- Routes packets using IP addresses and routing tables.
- Divides BOTH Collision Domains and Broadcast Domains!
Layer 1 - 7 · All Layers
🚪 Gateway
- Protocol converter.
- Connects two networks operating on different protocol architectures (e.g., OSI to TCP/IP or SNA).
- Operates at any/all layer(s) of OSI model.

Section 05

Collision Domain vs Broadcast Domain Table

Network Device OSI Operating Layer Collision Domains Broadcast Domains Addressing Used
Hub / Repeater Layer 1 (Physical) 1 (Shared by all ports) 1 None (Physical bits)
Switch (Layer 2) Layer 2 (Data Link) $N$ (1 per port) 1 (Entire switch) MAC Address (48-bit)
Bridge Layer 2 (Data Link) 2 (1 per segment) 1 MAC Address
Router Layer 3 (Network) $N$ (1 per port) $N$ (1 per interface) IP Address (32/128-bit)
Gateway Layers 1 – 7 $N$ $N$ Protocol Translations

Section 06

Transmission Media & Cables

Cable 1
🌀 Twisted Pair Cable
- Why twisted? Twisting cancels out Electromagnetic Interference (EMI) and crosstalk from neighboring pairs.
- Types: UTP (Unshielded) & STP (Shielded).
- Straight-through vs Crossover: Straight links different devices (PC to Switch); Crossover links same devices (PC to PC). Auto MDI-X auto-detects.
Cable 2
📺 Coaxial Cable
- Central copper conductor surrounded by insulator, metallic braid shield, and jacket.
- Legacy Ethernet: 10BASE5 (Thicknet), 10BASE2 (Thinnet).
- Used today in Cable TV and broadband Internet.
Cable 3
✨ Fiber Optic Cable
- Transmits signals as light pulses using Total Internal Reflection.
- Single-Mode (SMF): Small core, long distance, laser source.
- Multi-Mode (MMF): Larger core, short distance (data center), LED source.
- Immune to EMI, highest bandwidth and speed.

Section 08

IBPS SO IT PYQ Practice Questions

PYQ 01 Device Layer Mapping
Which device operates at the Data Link Layer and filters traffic based on MAC addresses?
  • A. Repeater
  • B. Hub
  • C. Switch / Bridge ✓
  • D. Router
Answer: C — Switch / Bridge
Switches and Bridges operate at Layer 2 (Data Link Layer) and forward frames using MAC addresses. Hubs/Repeaters operate at Layer 1, and Routers operate at Layer 3.
PYQ 02 Broadcast Domain
Which of the following devices separates Broadcast Domains?
  • A. Hub
  • B. Switch
  • C. Bridge
  • D. Router ✓
Answer: D — Router
Routers operate at Layer 3 and do NOT forward broadcast packets by default, thus creating separate Broadcast Domains for each port. Hubs, Switches, and Bridges maintain a single broadcast domain.
PYQ 03 Mesh Topology Ports
If a mesh network contains 8 computers, how many I/O ports are required for each computer?
  • A. 28
  • B. 7 ✓
  • C. 8
  • D. 14
Answer: B — 7
Ports per node in Mesh topology = $N - 1 = 8 - 1 = \mathbf{7\text{ ports}}$.
(Total physical links in network = $\frac{8 \times 7}{2} = 28$ links).
PYQ 04 Repeater Function
A repeater operates at the Physical layer. Its primary function is to:
  • A. Amplify the analog signal along with noise
  • B. Regenerate the digital signal bit-by-bit ✓
  • C. Route packets based on IP address
  • D. Filter frames based on MAC address
Answer: B
Repeaters do NOT amplify signals (amplifiers amplify both signal and noise). Repeaters regenerate digital signals bit-by-bit at original strength to extend cable distance.
PYQ 05 Protocol Conversion
Which networking device acts as a protocol converter between two different network architectures?
  • A. Router
  • B. Switch
  • C. Gateway ✓
  • D. Bridge
Answer: C — Gateway
A Gateway acts as a protocol converter that translates data between systems running entirely different networking models/protocols.
PYQ 06 Twisted Pair Wiring
Why are wire pairs twisted together in a Twisted Pair Ethernet cable?
  • A. To increase cable strength
  • B. To cancel out Electromagnetic Interference (EMI) and crosstalk ✓
  • C. To increase signal speed
  • D. To decrease manufacturing cost
Answer: B
Twisting forward and return conductors causes electromagnetic noise to affect both wires equally, canceling out EMI and crosstalk.
PYQ 07 Token Passing
Token Passing access mechanism is used in which topology to prevent collisions?
  • A. Bus Topology
  • B. Star Topology
  • C. Ring Topology ✓
  • D. Mesh Topology
Answer: C — Ring Topology
Token Ring (IEEE 802.5) uses a small token frame circulating in the ring. A station must hold the token to transmit, eliminating collision possibilities.
PYQ 08 Direct PC Connection Cable
Which type of Ethernet cable is required to connect two PCs directly together without a switch or hub?
  • A. Straight-through cable
  • B. Crossover cable ✓
  • C. Coaxial cable
  • D. Fiber optic patch cord
Answer: B — Crossover cable
Connecting similar devices (PC to PC, Switch to Switch) requires a crossover cable so transmit pins on one end connect to receive pins on the other.
PYQ 09 Collision Domain Count
A 12-port Ethernet Switch has 10 computers connected to it. How many Collision Domains exist on this switch?
  • A. 1
  • B. 10
  • C. 12 ✓
  • D. 0
Answer: C — 12
On a switch, EACH port creates an independent collision domain. A 12-port switch has 12 collision domains regardless of how many ports currently have active links.
PYQ 10 Fiber Optic Transmission
Fiber optic cables transmit data using which physical phenomenon?
  • A. Refraction
  • B. Total Internal Reflection ✓
  • C. Diffraction
  • D. Polarization
Answer: B — Total Internal Reflection
Light pulses bounce inside the glass core because the angle of incidence exceeds the critical angle, causing total internal reflection against the cladding.
