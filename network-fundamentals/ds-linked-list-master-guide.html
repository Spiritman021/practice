🔗 Lec 7: Introduction to Linked Lists & Structure Memory

A Linked List is a linear data structure where elements (nodes) are not stored in contiguous memory locations. Each node contains a data field and a next pointer referencing the memory address of the next node.

Self-Referential Structure Definition (C): 
struct Node {
    int data;
    struct Node* next; // Self-referential pointer
};

Complete Code Implementation:

#include <stdio.h> #include <stdlib.h> struct Node { int data; struct Node* next; }; int main() { // Create nodes dynamically in heap struct Node* head = (struct Node*)malloc(sizeof(struct Node)); struct Node* second = (struct Node*)malloc(sizeof(struct Node)); head->data = 100; head->next = second; second->data = 200; second->next = NULL; printf("Head Data: %d, Next Data: %d\n", head->data, head->next->data); return 0; }
class Node { int data; Node next; Node(int data) { this.data = data; this.next = null; } } public class LinkedListDemo { public static void main(String[] args) { Node head = new Node(100); head.next = new Node(200); System.out.println("Head: " + head.data + " -> Second: " + head.next.data); } }
class Node: def __init__(self, data): self.data = data self.next = None # Creating Linked List head = Node(100) head.next = Node(200) print(f"Head: {head.data} -> Second: {head.next.data}")
🔍 Lec 8: Find Last Node & Second-to-Last Node

Traversing a linked list requires linear scanning from head until specific pointer conditions are met.

Find Last Node: Loop while (current->next != NULL)
Find 2nd Last Node: Loop while (current->next->next != NULL)
Algorithm Details:
  • Find Last Node (O(N) Time, O(1) Space): Starts at head, advances current = current->next until current->next == NULL.
  • Find Second Last Node (O(N) Time): Guard condition: Check if head == NULL or head->next == NULL (returns NULL). Advance until current->next->next == NULL.

Code Implementations (C, Java, Python):

struct Node* findLastNode(struct Node* head) { if (head == NULL) return NULL; struct Node* current = head; while (current->next != NULL) { current = current->next; } return current; // Points to Tail Node } struct Node* findSecondLastNode(struct Node* head) { if (head == NULL || head->next == NULL) return NULL; struct Node* current = head; while (current->next->next != NULL) { current = current->next; } return current; }
public static Node findLastNode(Node head) { if (head == null) return null; Node current = head; while (current.next != null) { current = current.next; } return current; // Tail Node } public static Node findSecondLastNode(Node head) { if (head == null || head.next == null) return null; Node current = head; while (current.next.next != null) { current = current.next; } return current; }
def find_last_node(head): if head is None: return None current = head while current.next is not None: current = current.next return current def find_second_last_node(head): if head is None or head.next is None: return None current = head while current.next.next is not None: current = current.next return current
🔄 Lec 9: Reversing a Linked List & Move Last to First

Reversing pointers in-place is one of the most frequently asked GATE & IBPS SO IT algorithms.

Iterative 3-Pointer Technique: prev = NULL, current = head, next = NULL
In-Place Reversal Algorithm (O(N) Time, O(1) Space):
  1. Save next node: next = current->next
  2. Reverse current link: current->next = prev
  3. Move prev forward: prev = current
  4. Move current forward: current = next

Code Implementations (C, Java, Python):

struct Node* reverseLinkedList(struct Node* head) { struct Node *prev = NULL, *current = head, *next = NULL; while (current != NULL) { next = current->next; // Store next current->next = prev; // Reverse pointer prev = current; // Advance prev current = next; // Advance current } return prev; // New Head }
public static Node reverseLinkedList(Node head) { Node prev = null, current = head, next = null; while (current != null) { next = current.next; // Store next current.next = prev; // Reverse pointer prev = current; // Advance prev current = next; // Advance current } return prev; // New Head }
def reverse_linked_list(head): prev = None current = head while current is not None: next_node = current.next # Store next current.next = prev # Reverse pointer prev = current # Advance prev current = next_node # Advance current return prev # New Head
➕ Lec 10: Insertion & Fast/Slow Pointer (Middle Node)

🔥 Fast & Slow Pointer Algorithm (Find Middle Node):

Advance slow by 1 step (slow = slow->next) and fast by 2 steps (fast = fast->next->next). When fast reaches end, slow will be at the exact middle node!

Time Complexity: O(N) in single pass, Space: O(1).

Code Implementations (C, Java, Python):

struct Node* findMiddleNode(struct Node* head) { struct Node *slow = head, *fast = head; while (fast != NULL && fast->next != NULL) { slow = slow->next; fast = fast->next->next; } return slow; // Middle Node }
public static Node findMiddleNode(Node head) { Node slow = head, fast = head; while (fast != null && fast.next != null) { slow = slow.next; fast = fast.next.next; } return slow; // Middle Node }
def find_middle_node(head): slow = head fast = head while fast is not None and fast.next is not None: slow = slow.next fast = fast.next.next return slow # Middle Node

Insertion Complexities:

Insertion Operation Algorithm Logic Time Complexity
Insert at Beginning (Head) newNode->next = head; head = newNode; O(1)
Insert at End (Tail) Traverse to end, set last->next = newNode; O(N) (O(1) with Tail pointer)
Insert After Position Traverse to pos, newNode->next = curr->next; curr->next = newNode; O(N)
🗑️ Lec 11 & 12: Deletion Operations (First, Last & Specific Node)
Deletion Algorithms & Complexities:
  • Delete First Node (Head Deletion): struct Node* temp = head; head = head->next; free(temp); → O(1) Time.
  • Delete Last Node (Tail Deletion): Traverse to 2nd last node prev. free(prev->next); prev->next = NULL; → O(N) Time.
  • Delete Specific Node by Value: Track previous & current. Set previous->next = current->next; free(current); → O(N) Time.

Code Implementations (C, Java, Python):

struct Node* deleteNodeByValue(struct Node* head, int value) { if (head == NULL) return NULL; if (head->data == value) { // Delete Head struct Node* temp = head; head = head->next; free(temp); return head; } struct Node* current = head, *previous = NULL; while (current != NULL && current->data != value) { previous = current; current = current->next; } if (current != NULL) { // Found node previous->next = current->next; free(current); } return head; }
public static Node deleteNodeByValue(Node head, int value) { if (head == null) return null; if (head.data == value) return head.next; // Delete Head Node current = head, previous = null; while (current != null && current.data != value) { previous = current; current = current.next; } if (current != null) previous.next = current.next; return head; }
def delete_node_by_value(head, value): if head is None: return None if head.data == value: return head.next # Delete Head current = head previous = None while current is not None and current.data != value: previous = current current = current.next if current is not None: previous.next = current.next return head
🎯 IBPS SO IT PYQ Pattern Verification
  • Array vs Linked List Comparison: Linked Lists allow O(1) insertion/deletion at head, but arrays take O(N) due to element shifting.
  • Random Access: Arrays support O(1) random access by index; Linked Lists require O(N) sequential traversal.
  • Memory Overhead: Linked lists require additional memory for pointer/reference fields (`sizeof(struct Node*)`).
