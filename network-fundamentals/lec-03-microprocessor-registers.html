8085 & 8086 Microprocessor Registers Architecture

💻 1. What are CPU Registers?

Registers are small, ultra-fast memory locations internal to the CPU. They hold data currently being processed, memory addresses being accessed, status flags, and instructions.

General Purpose Registers (GPRs)

Used by programmers to temporarily store data values, intermediate computation results, or memory pointer addresses during execution.

Special Purpose Registers (SPRs)

Dedicated hardware registers performing specific control, addressing, instruction fetching, stack management, or status tracking functions.

⚡ 2. Intel 8085 Microprocessor Register Architecture (8-bit)

The 8085 is an 8-bit microprocessor with six 8-bit General Purpose Registers (B, C, D, E, H, L) and multiple 8/16-bit Special Purpose Registers:

A) 8085 General Purpose Registers (GPRs) & Register Pairs

Register Size Primary Function & Pair Capability
B & C 8-bit each General data storage. Can form 16-bit BC Register Pair.
D & E 8-bit each General data storage. Can form 16-bit DE Register Pair.
H & L 8-bit each Forms 16-bit HL Register Pair. Acts as default Memory Pointer ($M$) to address RAM in instructions like MOV A, M.

B) 8085 Special Purpose Registers (SPRs)

Special Register Size Function & IBPS Exam Clue
Accumulator (A) 8-bit Primary register for all ALU operations; holds 1st operand and stores final result.
Flag Register (F) 8-bit Holds 5 active status flags: Sign ($S$), Zero ($Z$), Auxiliary Carry ($AC$), Parity ($P$), Carry ($CY$). Format: $[S \mid Z \mid X \mid AC \mid X \mid P \mid X \mid CY]$.
Program Counter (PC) 16-bit Holds 16-bit address of the next instruction byte to be fetched from memory.
Stack Pointer (SP) 16-bit Points to the current Top of Stack ($TOS$) location in RAM. Decremented during PUSH, incremented during POP.
Instruction Register (IR) 8-bit Holds the opcode of the fetched instruction during execution cycle.
Temporary Registers (W, Z) 8-bit each Internal CPU registers used by Control Unit to hold intermediate data (not accessible by programmer).
MAR & MBR (MDR) 16-bit / 8-bit MAR holds 16-bit address for RAM bus; MBR (Memory Buffer Register) holds 8-bit data transferring to/from memory.
🚀 3. Intel 8086 Microprocessor Register Architecture (16-bit)

The 8086 is a 16-bit microprocessor. All registers are 16-bit wide. The 4 General Purpose Registers (AX, BX, CX, DX) can be split into High (H) and Low (L) 8-bit halves:

A) 8086 16-bit General Purpose Registers (GPRs)

AX (Accumulator) AH + AL

Used in 16-bit arithmetic, logical operations, I/O, and string operations. Holds implicit operand/result in MUL and DIV.

BX (Base Register) BH + BL

Used as base register for indirect data addressing ($EA = BX + D$). Only general register that can serve as memory base pointer.

CX (Count Register) CH + CL

Acts as loop counter for LOOP instructions and shift/rotate bit counts (stored in CL).

DX (Data Register) DH + DL

Holds 32-bit product/quotient high-word ($DX:AX$) in MUL/DIV and holds indirect I/O port numbers (`IN AL, DX`).

B) 8086 Pointers, Index & Segment Registers

Register Category Register Mnemonic Specialized Function
Pointer Registers (16-bit) SP (Stack Pointer)
BP (Base Pointer)		 SP points to offset of top of stack.
BP used for stack frame parameter passing and local variables.
Index Registers (16-bit) SI (Source Index)
DI (Destination Index)		 Used in indexed addressing modes and string operations (e.g. MOVSB: copies from DS:SI to ES:DI).
Segment Registers (16-bit) CS (Code Segment)
DS (Data Segment)
SS (Stack Segment)
ES (Extra Segment)		 Holds 16-bit base segment selectors for 1 MB segmented memory architecture.
Instruction Pointer (16-bit) IP (Instruction Pointer) Holds offset address of next instruction inside Code Segment ($CS$).
Flag Register (16-bit) FLAGS Register Holds 9 active flags: 6 Status flags ($CF, PF, AF, ZF, SF, OF$) + 3 Control flags ($TF$ Trap, $IF$ Interrupt Enable, $DF$ Direction).
🧮 4. 8086 20-bit Physical Address Calculation Math

The 8086 has a 20-bit address bus ($2^{20} = 1 \text{ MB}$ memory), but all registers are 16-bit. It generates 20-bit physical addresses using Memory Segmentation:

Physical Address (20-bit) = (Segment Register x 16_10) + Offset Physical Address (Hex) = (Segment Register Shifted Left by 1 Hex Digit) + Offset
🔥 IBPS SO IT / GATE Solved Numerical

Problem: If the Code Segment register $CS = 2500H$ and Instruction Pointer $IP = 0180H$, calculate the 20-bit Physical Address of the instruction byte.

Step-by-step Solution:
1. Shift $CS$ left by 4 bits (1 hex digit): $2500H \rightarrow 25000H$.
2. Add Offset ($IP$): $25000H + 0180H = 25180H$.
$\implies$ Physical Memory Address = 25180H.
📊 5. 8085 vs 8086 Register Architecture Comparison
Parameter / Feature 8085 Microprocessor 8086 Microprocessor
Data Bus Width 8-bit 16-bit
Address Bus Width & RAM Capacity 16-bit ($2^{16} = 64 \text{ KB}$) 20-bit ($2^{20} = 1 \text{ MB}$)
General Purpose Registers 6 (B, C, D, E, H, L) — 8-bit each 4 (AX, BX, CX, DX) — 16-bit each (split into H/L)
Memory Pointer HL Register Pair (`M`) Segment Registers + Offset Registers (`BX`, `BP`, `SI`, `DI`)
Segment Registers None (Flat 64 KB space) 4 Segment Registers (CS, DS, SS, ES)
Pipelining / Pre-fetch Queue No Pipelining 6-byte Instruction Queue in BIU
📝 6. IBPS SO IT Mains Practice Questions

Q1. In 8085 microprocessor instruction set, which register pair acts as the default memory pointer 'M'?

A) BC Pair
B) DE Pair
C) HL Pair
D) SP Pair

View Answer & Explanation

Correct Answer: C) HL Pair
Explanation: In 8085, operand M refers to the 8-bit memory content located at the 16-bit RAM address held in the HL register pair.

Q2. If 8086 Data Segment register DS = 3000H and Source Index register SI = 1200H, what is the 20-bit Physical Address?

A) 4200H
B) 31200H
C) 30120H
D) 42000H

View Answer & Explanation

Correct Answer: B) 31200H
Explanation: $\text{Physical Address} = (DS \times 10H) + SI = 30000H + 1200H = 31200H$.

Q3. Which 8086 register is specifically used as a loop counter for the LOOP instruction and bit shift count for CL?

A) AX
B) BX
C) CX
D) DX

View Answer & Explanation

Correct Answer: C) CX (Counter Register)
Explanation: CX (and CL) is the designated counter register for loop iterations, string operations, and multi-bit shift/rotate instructions.
