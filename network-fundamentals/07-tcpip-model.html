Section 7.1

Introduction & History

The TCP/IP (Transmission Control Protocol / Internet Protocol) Model is the practical architectural model of the internet. Unlike the OSI model which was created as a theoretical standard after protocols were invented, TCP/IP was created alongside its protocols by the US Department of Defense (DoD / DARPA) in the 1970s.

💡
Core Philosophy of TCP/IP
1. End-to-End Principle: Intelligence is placed at the endpoints (hosts), while the core network (routers) remains simple and fast.
2. Robustness: If part of the network fails, packets should automatically find an alternate route to the destination.

Section 7.2

4-Layer vs 5-Layer Models

In literature and textbooks, TCP/IP is presented in two variants: the classic **4-Layer DoD model** and the updated **5-Layer Internet model** (commonly used in Computer Science curricula like Kurose & Ross / Forouzan).

Section 7.3

Application Layer & Protocols

In the TCP/IP model, the Application layer combines the functions of the OSI Application, Presentation, and Session layers. It handles high-level protocols, data representation, formatting, and session management.

Major Application Layer Protocols

HTTP / HTTPS (Ports 80 / 443): Hypertext Transfer Protocol. Used for fetching web resources. HTTPS adds TLS encryption.

FTP / SFTP (Ports 20, 21 / 22): File Transfer Protocol for sending files between client and server.

DNS (Port 53): Domain Name System. Translates human-friendly domain names (google.com) into IP addresses (142.250.x.x). Uses UDP for queries, TCP for zone transfers.

DHCP (Ports 67, 68): Dynamic Host Configuration Protocol. Automatically assigns IP address, subnet mask, default gateway to devices.

SMTP (Port 25), POP3 (110), IMAP (143): Email protocols for sending (SMTP) and retrieving (POP3/IMAP) mail.

SSH (Port 22) & Telnet (Port 23): Remote terminal access protocols. SSH is encrypted; Telnet sends plaintext.

Transport Layer (TCP vs UDP)

The Transport layer provides end-to-end communication services. The two fundamental protocols operating at this layer are TCP and UDP.

Section 7.5

Internet (Network) Layer & Protocols

The Internet Layer corresponds to the OSI Network Layer. Its main job is to route packets across network boundaries.

Core Internet Layer Protocols

IP (Internet Protocol - IPv4 & IPv6): Provides logical addressing and packet routing across networks. Best-effort, connectionless.

ICMP (Internet Control Message Protocol): Used by network devices to send error messages and operational info (e.g., ping, traceroute).

ARP (Address Resolution Protocol): Resolves a known IP address to an unknown physical MAC address on a local network.

RARP (Reverse ARP): Resolves a physical MAC address to an IP address (used by diskless workstations).

IGMP (Internet Group Management Protocol): Used by hosts and routers to manage IP multicast group memberships.

🔗
Section 7.6

Network Access (Link & Physical) Layer

The Network Access Layer (or Link Layer) combines the OSI Data Link and Physical layers. It defines how data is physically transmitted over the network medium and handles hardware framing, error checking, and MAC addressing.

Technologies include: Ethernet (IEEE 802.3), Wi-Fi (IEEE 802.11), PPP (Point-to-Point Protocol), DSL, Fiber drivers.
