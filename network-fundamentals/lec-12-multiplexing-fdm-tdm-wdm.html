Section 01

What is Multiplexing? (MUX vs DEMUX)

Multiplexing is the process of combining multiple signal streams into a single composite signal for transmission over a shared physical channel (medium).

💡
Highway Analogy

Multiple lanes of cars (input data streams) merging onto a single multi-lane superhighway (shared high-capacity medium), and then separating back to local roads at their destination.

Sender Side
Multiplexer (MUX)
Combines $N$ input lines into 1 single physical link.
Receiver Side
Demultiplexer (DEMUX)
Separates the composite stream back into $N$ individual output lines.
📻
Section 02

Frequency Division Multiplexing (FDM)

🔥 IBPS SO IT – Core Concept

FDM is an analog multiplexing technique where the total available bandwidth of a physical medium is divided into non-overlapping frequency bands. Each channel carries a separate signal modulated onto different carrier frequencies.

Feature 1
Signal Type
Uses analog signals (modulated via AM, FM, or QAM).
Feature 2
🛡️ Guard Bands
Narrow unused frequency spaces left between channels to prevent overlap and crosstalk interference.
Feature 3
Applications
AM/FM Radio broadcasting, Cable Television (CATV), ADSL telephone lines.
⚡ Total FDM Bandwidth Formula
$$B_{\text{total}} = (N \times B_{\text{channel}}) + ((N - 1) \times B_{\text{guard}})$$
$N$ = number of channels  |  $B_{\text{channel}}$ = bandwidth per channel  |  $B_{\text{guard}}$ = guard band width
✨
Section 03

Wavelength Division Multiplexing (WDM & DWDM)

WDM is an analog optical multiplexing technique used exclusively in fiber optic cables. It combines multiple light beams of different wavelengths ($\lambda_1, \lambda_2, \dots, \lambda_n$) into a single optical fiber using optical prisms or diffraction gratings.

Variant 1
CWDM (Coarse WDM)
Wavelength channel spacing is wider ($\ge 20\text{ nm}$). Typically supports up to 8–18 channels.
Variant 2
DWDM (Dense WDM)
Ultra-narrow channel spacing ($0.8\text{ nm}$ or $0.4\text{ nm}$). Supports hundreds of simultaneous high-speed 100G/400G channels per fiber!
⏱️
Section 04

Time Division Multiplexing (Synchronous vs. Statistical TDM)

TDM is a digital multiplexing technique where time is divided into units called time slots. Multiple digital data streams share the total channel bandwidth by taking turns sending data in their allocated time slots.

TDM Type 1
1. Synchronous TDM
- Each input device is assigned a fixed time slot in every frame.
- Limitation: If a device has no data to send, its time slot remains empty and wasted.
- Frame Duration: $T_{\text{frame}} = T_{\text{slot}} \times N$.
- Example: T-1 ($1.544\text{ Mbps}$) and E-1 ($2.048\text{ Mbps}$) digital trunks in PSTN telephony.
TDM Type 2
2. Statistical (Asynchronous) TDM
- Time slots are allocated dynamically on-demand ONLY to active input lines.
- Eliminates empty slots, maximizing bandwidth efficiency!
- Requires an address header attached to each slot to identify the destination.
- Example: Packet-switched networks, IP routers.
📡
Section 05

Spread Spectrum (FHSS & DSSS)

Spread Spectrum expands the bandwidth of a signal to make it immune to jamming, eavesdropping, and multipath interference.

Technique 1
FHSS (Frequency Hopping)
Signal hops rapidly across different carrier frequencies according to a pseudorandom PN sequence. Used in Bluetooth.
Technique 2
DSSS (Direct Sequence)
Each data bit is multiplied by a high-speed code sequence called a chipping code. Used in Wi-Fi 802.11b & CDMA.

Section 08

IBPS SO IT PYQ Practice Questions

PYQ 01 FDM Guard Bands
In Frequency Division Multiplexing (FDM), what is the purpose of placing "Guard Bands" between adjacent channels?
  • A. To boost signal power
  • B. To prevent channel overlap and crosstalk interference ✓
  • C. To convert analog signals to digital
  • D. To store frame sequence numbers
Answer: B
Guard bands are narrow unused frequency ranges inserted between FDM channels to prevent overlap and inter-channel crosstalk.
PYQ 02 WDM Optical Hardware
Which optical component is used in Wavelength Division Multiplexing (WDM) to combine and separate light signals of different wavelengths?
  • A. Repeater
  • B. Prism / Diffraction Grating ✓
  • C. Modulator
  • D. Commutator
Answer: B — Prism / Diffraction Grating
WDM uses optical prisms or diffraction gratings to combine light beams at the MUX and split them at the DEMUX based on wavelength ($\lambda$).
PYQ 03 Statistical TDM Efficiency
Why is Statistical (Asynchronous) TDM more bandwidth-efficient than Synchronous TDM?
  • A. Statistical TDM uses optical signals
  • B. Time slots are allocated dynamically only to active lines rather than reserving slots for idle lines ✓
  • C. Statistical TDM does not require framing
  • D. Synchronous TDM requires guard bands
Answer: B
Synchronous TDM reserves a fixed time slot for every input line (wasting slots if idle). Statistical TDM allocates slots dynamically on-demand only when a line has data to transmit.
PYQ 04 FHSS Application
Frequency Hopping Spread Spectrum (FHSS) rapidly switches carrier frequencies according to a pseudorandom sequence. Which short-range wireless standard uses FHSS?
  • A. Bluetooth ✓
  • B. Ethernet 802.3
  • C. Satellite TV
  • D. ADSL
Answer: A — Bluetooth
Bluetooth uses FHSS, hopping across 79 channels in the $2.4\text{ GHz}$ ISM band 1600 times per second to avoid interference.
PYQ 05 FDM Bandwidth Calculation
Five channels, each with a bandwidth of $100\text{ kHz}$, are multiplexed together using FDM. If a guard band of $10\text{ kHz}$ is required between channels, what is the total link bandwidth required?
  • A. 500 kHz
  • B. 540 kHz ✓
  • C. 550 kHz
  • D. 600 kHz
Answer: B — 540 kHz
5 channels require 4 guard bands ($N-1 = 4$).
$B_{\text{total}} = (5 \times 100\text{ kHz}) + (4 \times 10\text{ kHz}) = 500 + 40 = \mathbf{540\text{ kHz}}$.
PYQ 06 TDM Domain Type
Time Division Multiplexing (TDM) is primarily categorized as what type of multiplexing technique?
  • A. Digital Multiplexing Technique ✓
  • B. Analog Frequency Technique
  • C. Optical Prism Technique
  • D. Baseband Filter Technique
Answer: A — Digital Multiplexing Technique
TDM interleaves digital bits or bytes into distinct time slots. FDM and WDM are analog multiplexing techniques.
PYQ 07 Synchronous TDM Bit Rate
Four $1\text{ Mbps}$ digital connections are multiplexed using Synchronous TDM. If 1 bit is taken from each line per frame, what is the output link bit rate?
  • A. 1 Mbps
  • B. 4 Mbps ✓
  • C. 8 Mbps
  • D. 16 Mbps
Answer: B — 4 Mbps
Output link bit rate = $N \times \text{Input Bit Rate} = 4 \times 1\text{ Mbps} = \mathbf{4\text{ Mbps}}$.
PYQ 08 DSSS Chipping Code
In Direct Sequence Spread Spectrum (DSSS), each data bit is combined with a high-speed code sequence known as a:
  • A. Chipping Code ✓
  • B. Parity Bit
  • C. Guard Band
  • D. Frame Check Sequence
Answer: A — Chipping Code
In DSSS, each bit is multiplied by a pseudorandom **chipping code** (e.g. 11-bit Barker code in 802.11b Wi-Fi).
PYQ 09 Statistical TDM Address Header
Why does each slot in Statistical (Asynchronous) TDM require an explicit channel address header?
  • A. Because signals are analog
  • B. Because time slots are not fixed; the address identifies which input line sent the data ✓
  • C. To calculate CRC error codes
  • D. To measure propagation delay
Answer: B
Since slots are not assigned in a fixed order in Statistical TDM, each slot must carry a small address header so the receiver knows which destination line to deliver the data to.
PYQ 10 PSTN TDM Application
The Public Switched Telephone Network (PSTN) T-1 carrier system multiplexes 24 voice channels onto a single line using which multiplexing method?
  • A. FDM
  • B. WDM
  • C. Synchronous TDM ✓
  • D. DSSS
Answer: C — Synchronous TDM
The T-1 carrier system uses Synchronous TDM to multiplex 24 voice channels ($24 \times 64\text{ kbps} + 8\text{ kbps framing} = 1.544\text{ Mbps}$).
