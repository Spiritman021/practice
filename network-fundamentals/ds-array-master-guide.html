📌 Lec 1: Array Fundamentals & Multi-Language Code

An Array is a linear data structure containing a collection of homogeneous elements stored in contiguous memory locations. It allows constant-time O(1) random access to any element using its index formula.

Core Properties:
  • Contiguous Allocation: Memory locations are sequential (e.g. 1000, 1004, 1008, …).
  • Random Access: Any element A[i] can be accessed directly in O(1) time.
  • Fixed Size: Static arrays cannot be dynamically resized without reallocation.

Complete Code Implementation:

#include <stdio.h> int main() { // 1D Array Declaration & Initialization int arr[5] = {10, 20, 30, 40, 50}; int size = 5; printf("Base Address: %p\n", (void*)arr); printf("Access element at index 2: %d\n", arr[2]); // O(1) Access // Traversal printf("Array elements: "); for(int i = 0; i < size; i++) { printf("%d ", arr[i]); } printf("\n"); return 0; }
public class ArrayDemo { public static void main(String[] args) { // 1D Array Creation int[] arr = {10, 20, 30, 40, 50}; // Access element at index 2 System.out.println("Element at index 2: " + arr[2]); // O(1) // Traversal System.out.print("Array elements: "); for (int num : arr) { System.out.print(num + " "); } System.out.println(); } }
# Python 1D Array / List Demo arr = [10, 20, 30, 40, 50] # Access element at index 2 print("Element at index 2:", arr[2]) # O(1) access # Traversal print("Array elements:", end=" ") for num in arr: print(num, end=" ") print()
📐 Lec 2 & 3: 1D Array Address Calculation (Positive & Negative Bounds)

To calculate the memory address of an element A[i] in a 1D array with Lower Bound (LB) and Upper Bound (UB):

LOC(A[i]) = Base Address + (i - LB) × Element Size (k)
Key Formulas:
  • 0-indexed (LB = 0): LOC(A[i]) = BA + i × k
  • 1-indexed (LB = 1): LOC(A[i]) = BA + (i - 1) × k
  • General (Custom LB): LOC(A[i]) = BA + (i - LB) × k
  • Total Elements: N = UB - LB + 1

1D Address Computation Implementation:

long calculate1DAddress(long baseAddress, int targetIndex, int lowerBound, int elementSize) { // LOC(A[i]) = BA + (i - LB) * k return baseAddress + (long)(targetIndex - lowerBound) * elementSize; }
public static long calculate1DAddress(long baseAddress, int targetIndex, int lowerBound, int elementSize) { // LOC(A[i]) = BA + (i - LB) * k return baseAddress + (long)(targetIndex - lowerBound) * elementSize; }
def calculate_1d_address(base_address, target_index, lower_bound, element_size): # LOC(A[i]) = BA + (i - LB) * k return base_address + (target_index - lower_bound) * element_size

🔥 Solved Example 1 (Lec 2 PDF - Positive Bound):

Given: Array A[80 … 450], Base Address BA = 1000, Element Size k = 2 bytes. Find LOC(A[295]).

Solution:

  • LB = 80, target index i = 295
  • Offset = i - LB = 295 - 80 = 215 elements
  • LOC(A[295]) = 1000 + 215 × 2 = 1000 + 430 = 1430

🔥 Solved Example 2 (Lec 3 PDF - Negative Lower Bound):

Given: Array A[-200 … 400], Base Address BA = 1000, Element Size k = 4 bytes. Find LOC(A[125]).

Solution:

  • LB = -200, target index i = 125
  • Offset = i - LB = 125 - (-200) = 125 + 200 = 325 elements
  • LOC(A[125]) = 1000 + 325 × 4 = 1000 + 1300 = 2300
📊 Lec 4 & 5: 2D Array Row-Major Order (RMO)

In Row-Major Order (RMO), elements are stored row-by-row in linear RAM (Row 0, then Row 1, then Row 2…).

LOC(A[i][j]) = Base Address + [(i - LB₁) × N + (j - LB₂)] × k
where N = Total Columns = (UB₂ - LB₂ + 1)

2D RMO Address Computation Implementation:

long calculateRMO(long ba, int i, int j, int lb1, int ub1, int lb2, int ub2, int k) { int N = ub2 - lb2 + 1; // Total Columns return ba + (long)((i - lb1) * N + (j - lb2)) * k; }
public static long calculateRMO(long ba, int i, int j, int lb1, int ub1, int lb2, int ub2, int k) { int N = ub2 - lb2 + 1; // Total Columns return ba + (long)((i - lb1) * N + (j - lb2)) * k; }
def calculate_rmo(ba, i, j, lb1, ub1, lb2, ub2, k): N = ub2 - lb2 + 1 # Total Columns return ba + ((i - lb1) * N + (j - lb2)) * k

🔥 Solved Example 1 (Lec 5 PDF - Standard Bounds):

Given: Array A[50 … 120, 70 … 250], BA = 1000, k = 5 bytes. Find LOC(A[75][140]) in RMO.

Solution:

  • Row Lower Bound LB₁ = 50, Col Lower Bound LB₂ = 70
  • Total Columns N = UB₂ - LB₂ + 1 = 250 - 70 + 1 = 181
  • Row offset = 75 - 50 = 25 rows passed
  • Col offset = 140 - 70 = 70 cols passed
  • Elements prior = 25 × 181 + 70 = 4525 + 70 = 4595
  • LOC(A[75][140]) = 1000 + 4595 × 5 = 1000 + 22975 = 23975

🔥 Solved Example 2 (Lec 5 PDF - Negative Bounds):

Given: Array A[-65 … 145, -30 … 195], BA = 0, k = 3 bytes. Find LOC(A[-15][86]) in RMO.

Solution:

  • Total Columns N = 195 - (-30) + 1 = 226
  • Row offset = -15 - (-65) = 50
  • Col offset = 86 - (-30) = 116
  • Elements prior = 50 × 226 + 116 = 11300 + 116 = 11416
  • LOC(A[-15][86]) = 0 + 11416 × 3 = 34248
🏛️ Lec 6: 2D Array Column-Major Order (CMO) & RMO vs CMO

In Column-Major Order (CMO), elements are stored column-by-column (Col 0, then Col 1, then Col 2…). Used in Fortran, MATLAB, and R.

LOC(A[i][j]) = Base Address + [(j - LB₂) × M + (i - LB₁)] × k
where M = Total Rows = (UB₁ - LB₁ + 1)

2D CMO Address Computation Implementation:

long calculateCMO(long ba, int i, int j, int lb1, int ub1, int lb2, int ub2, int k) { int M = ub1 - lb1 + 1; // Total Rows return ba + (long)((j - lb2) * M + (i - lb1)) * k; }
public static long calculateCMO(long ba, int i, int j, int lb1, int ub1, int lb2, int ub2, int k) { int M = ub1 - lb1 + 1; // Total Rows return ba + (long)((j - lb2) * M + (i - lb1)) * k; }
def calculate_cmo(ba, i, j, lb1, ub1, lb2, ub2, k): M = ub1 - lb1 + 1 # Total Rows return ba + ((j - lb2) * M + (i - lb1)) * k

Comparison Table (RMO vs CMO):

Parameter Row-Major Order (RMO) Column-Major Order (CMO)
Storage Pattern Row by row (Row 0, Row 1, Row 2…) Column by column (Col 0, Col 1, Col 2…)
Multiplier Parameter N = Total Columns = (UB₂ - LB₂ + 1) M = Total Rows = (UB₁ - LB₁ + 1)
Address Formula BA + [(i - LB₁) × N + (j - LB₂)] × k BA + [(j - LB₂) × M + (i - LB₁)] × k
Primary Languages C, C++, Java, Python, C# Fortran, MATLAB, R
