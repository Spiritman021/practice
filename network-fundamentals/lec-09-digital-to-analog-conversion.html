Section 01

Taxonomy of Digital-to-Analog Conversion

Digital-to-Analog conversion is the process of changing one of the characteristics of an analog carrier wave (amplitude, frequency, or phase) based on information in digital binary data.

Category 1
ASK (Amplitude Shift Keying)
Modifies carrier amplitude. Simple, but vulnerable to noise.
Category 2
FSK (Frequency Shift Keying)
Modifies carrier frequency ($f_1$ vs $f_2$). Noise resistant.
Category 3
PSK (Phase Shift Keying)
Modifies carrier phase angles. High noise immunity.
Category 4
QAM (Quadrature AM)
Modifies BOTH amplitude AND phase simultaneously. Highest data density.
📈
Section 02

Amplitude Shift Keying (ASK & BASK)

In Binary ASK (BASK), also called **On-Off Keying (OOK)**, a binary `1` is represented by transmitting a carrier frequency signal ($A_1 \cos(2\pi f_c t)$), and a binary `0` is represented by zero voltage ($0\text{V}$).

⚡ ASK Bandwidth Formula
$$B = (1 + d) \times S$$
$S$ = Baud Rate (signal rate in bauds)  |  $d$ = factor related to filtering process ($0 \le d \le 1$)
🔊
Section 03

Frequency Shift Keying (FSK & BFSK)

In Binary FSK (BFSK), the carrier frequency shifts between two values: binary `1` is transmitted at frequency $f_1 = f_c + \Delta f$, and binary `0` is transmitted at frequency $f_2 = f_c - \Delta f$. Peak amplitude remains constant!

⚡ BFSK Bandwidth Formula
$$B = (1 + d) \times S + 2\Delta f = (1 + d) \times S + (f_1 - f_2)$$
$2\Delta f$ = difference between the two carrier frequencies $f_1 - f_2$
🌀
Section 04

Phase Shift Keying (BPSK, QPSK, 8-PSK)

🔥 IBPS SO IT – Top Numerical Concept
Scheme 1
BPSK (Binary PSK)
Uses 2 phase angles ($0^\circ$ for `1`, $180^\circ$ for `0`). Carries **1 bit/symbol** ($r=1$). $S = N$.
Scheme 2
QPSK (Quadrature PSK / 4-PSK)
Uses 4 phase angles ($45^\circ, 135^\circ, 225^\circ, 315^\circ$). Carries **2 bits/symbol** ($r=2$). $S = N / 2$.
Scheme 3
8-PSK
Uses 8 phase angles ($0^\circ, 45^\circ, 90^\circ, \dots$). Carries **3 bits/symbol** ($r=3$). $S = N / 3$.
🌌
Section 05

QAM & Constellation Diagrams

A **Constellation Diagram** maps signal symbols in a 2D polar plot:

  • X-axis (Horizontal): In-Phase Component ($I$).
  • Y-axis (Vertical): Quadrature Component ($Q$).
  • Distance from origin: Peak amplitude of symbol.
  • Angle with X-axis: Phase shift angle ($\phi$).
Modulation Scheme Constellation Points ($M$) Bits per Symbol ($r = \log_2 M$) Baud Rate Formula
BPSK / BASK 2 points 1 bit / symbol $S = N$
QPSK / 4-QAM 4 points 2 bits / symbol $S = N / 2$
8-PSK / 8-QAM 8 points 3 bits / symbol $S = N / 3$
16-QAM 16 points ($4 \times 4$ grid) 4 bits / symbol $S = N / 4$
64-QAM 64 points ($8 \times 8$ grid) 6 bits / symbol $S = N / 6$

Section 07

Master Formulas Cheat Sheet Table

Concept / Formula Mathematical Expression Key Meaning & Units
Bits per Symbol $$r = \log_2(M)$$ $M$ = constellation points
Bit Rate / Baud Rate $$S = \frac{N}{r} = \frac{N}{\log_2 M}$$ $N$ = bps, $S$ = baud
ASK / PSK Bandwidth $$B = (1+d) \times S$$ $S$ = baud rate, $d \ge 0$
BFSK Bandwidth $$B = (1+d)S + 2\Delta f$$ $2\Delta f = f_1 - f_2$

Section 08

IBPS SO IT PYQ Practice Questions

PYQ 01 64-QAM Bits per Symbol
How many bits per symbol element are transmitted in a 64-QAM digital-to-analog modulation scheme?
  • A. 4 bits
  • B. 6 bits ✓
  • C. 8 bits
  • D. 12 bits
Answer: B — 6 bits
Formula: $r = \log_2(M) = \log_2(64) = \mathbf{6\text{ bits per symbol}}$.
PYQ 02 QPSK Baud Rate
A QPSK (Quadrature Phase Shift Keying) signal transmits at a bit rate of $12\text{ Mbps}$. What is the baud rate of the signal?
  • A. 6 Mbaud ✓
  • B. 12 Mbaud
  • C. 24 Mbaud
  • D. 3 Mbaud
Answer: A — 6 Mbaud
QPSK carries $r = \log_2(4) = 2\text{ bits/symbol}$.
$\text{Baud Rate } S = \frac{N}{r} = \frac{12}{2} = \mathbf{6\text{ Mbaud}}$.
PYQ 03 Constellation Axes
In a constellation diagram used for digital-to-analog modulation, the horizontal axis represents:
  • A. In-Phase Component ($I$) ✓
  • B. Quadrature Component ($Q$)
  • C. Frequency Shift
  • D. Noise Margin
Answer: A — In-Phase Component ($I$)
Horizontal axis = In-Phase component ($I$). Vertical axis = Quadrature component ($Q$).
PYQ 04 BASK Concept
Binary Amplitude Shift Keying (BASK) is also commonly referred to as:
  • A. Frequency Modulation
  • B. On-Off Keying (OOK) ✓
  • C. Phase Inversion
  • D. Pulse Code Modulation
Answer: B — On-Off Keying (OOK)
In BASK, binary 1 turns the carrier wave ON, and binary 0 turns the carrier wave OFF (On-Off Keying).
PYQ 05 ASK Bandwidth Calculation
An ASK signal has a baud rate of $2000\text{ bauds}$. With $d=0$, what is the minimum bandwidth required for transmission?
  • A. 1000 Hz
  • B. 2000 Hz (2 kHz) ✓
  • C. 4000 Hz
  • D. 8000 Hz
Answer: B — 2000 Hz (2 kHz)
$B = (1+d) \times S = (1+0) \times 2000 = \mathbf{2000\text{ Hz}} = 2\text{ kHz}$.
PYQ 06 BPSK Constellation Points
How many constellation points are located on the constellation diagram for BPSK (Binary PSK)?
  • A. 2 points ($0^\circ$ and $180^\circ$) ✓
  • B. 4 points
  • C. 8 points
  • D. 16 points
Answer: A — 2 points
BPSK uses 2 phase shifts ($0^\circ$ and $180^\circ$) lying on the horizontal axis of the constellation diagram.
PYQ 07 V.32 Modem Scheme
The V.32 modem standard achieves $9600\text{ bps}$ over standard telephone lines operating at $2400\text{ baud}$ by using which modulation technique?
  • A. BPSK
  • B. QPSK
  • C. 32-QAM ✓
  • D. BASK
Answer: C — 32-QAM
V.32 uses 32-QAM (with 4 data bits + 1 trellis error bit per symbol = $r=4$) at $2400\text{ baud} \implies 2400 \times 4 = \mathbf{9600\text{ bps}}$.
PYQ 08 BFSK Bandwidth Extra Term
Why does Binary FSK (BFSK) require more total bandwidth than Binary ASK (BASK)?
  • A. FSK requires extra bandwidth proportional to the frequency separation $2\Delta f$ between $f_1$ and $f_2$ ✓
  • B. FSK carries twice as many bits per symbol
  • C. FSK operates at higher baud rates
  • D. FSK is an analog-to-analog modulation
Answer: A
BFSK bandwidth is $B = (1+d)S + 2\Delta f$. The additional $2\Delta f$ term accounts for the physical frequency separation between carrier $f_1$ and carrier $f_2$.
PYQ 09 Constellation Vector Distance
In a constellation diagram, the length of the vector from the origin to a constellation point represents the symbol's:
  • A. Peak Amplitude ✓
  • B. Phase Angle
  • C. Frequency
  • D. Wavelength
Answer: A — Peak Amplitude
The distance from the origin to a point represents peak amplitude; the angle with the positive horizontal axis represents phase.
PYQ 10 56K Modem Asymmetry
Why do traditional 56K telephone modems (V.90) achieve 56 kbps for downloads but are limited to 33.6 kbps for uploads?
  • A. Uploads use ASK while downloads use FSK
  • B. Downloads avoid quantization noise by connecting directly to the ISP's digital PCM trunk ✓
  • C. Telephone cables are one-way only
  • D. 56K modems use full-duplex FM
Answer: B
V.90 modems achieve 56 kbps downstream because the ISP is connected directly to the telephone company's digital PCM switch, bypassing one A/D quantization step. Upstream still undergoes A/D conversion at the local loop, limiting it to 33.6 kbps.
