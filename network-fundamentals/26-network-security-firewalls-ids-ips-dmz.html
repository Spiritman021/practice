26.1 Network Security & The CIA Triad

The foundation of information security rests upon three core pillars known as the CIA Triad:

Pillar 1
Confidentiality
Ensures data is accessible only to authorized users and protected from unauthorized disclosure. (Enforced via Encryption).
Pillar 2
Integrity
Guarantees that data remains accurate, complete, and unaltered during transmission. (Enforced via Hashing & Digital Signatures).
Pillar 3
Availability
Ensures authorized users have timely, reliable access to network resources. (Enforced via Redundancy & DDoS Protection).

Section 26.2

Firewalls Overview & Types

A Firewall is a network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules.

Firewall Generation / TypeOSI LayerOperating Mechanism
Stateless Packet Filter Network / Transport (Layers 3–4) Inspects individual packet headers (IPs, Ports) against Access Control Lists (ACLs) without tracking connection state.
Stateful Packet Inspection (SPI) Transport (Layer 4) Tracks active TCP connection states in a state table. Automatically permits return traffic for legitimate outbound connections.
Circuit-Level Gateway Session (Layer 5) Validates TCP handshakes before permitting sessions without inspecting actual payload contents.
Application-Level Gateway (Proxy) Application (Layer 7) Terminates incoming connection, deep-inspects payload contents (e.g. HTTP, FTP), and forwards request to destination.
Next-Generation Firewall (NGFW) Layers 3 through 7 Combines SPI with Deep Packet Inspection (DPI), Intrusion Prevention (IPS), TLS decryption, and Application Identification.

Section 26.3

Stateless vs Stateful Packet Inspection (SPI)

Older / Simple
Stateless Filtering
Evaluates each packet independently. Requires explicit rules for both outbound and inbound traffic. Vulnerable to IP spoofing and ACK scanning.
Modern Standard
Stateful Filtering (SPI)
Maintains a **State Table** recording TCP sequence numbers, SYN/ACK states, and IP:Port 4-tuples. Blocks unsolicited inbound packets automatically.

26.4 DMZ (Demilitarized Zone) Network Architecture

A DMZ (Demilitarized Zone) is a physical or logical subnetwork that isolates public-facing services (e.g. Web, Mail, DNS servers) from an organization's private internal LAN.

If a hacker compromises a public web server in the DMZ, the internal firewall blocks them from reaching sensitive private databases in the internal LAN!

26.6 Signature-Based vs Anomaly-Based Detection

  • Signature-Based Detection: Compares network traffic against a database of known attack patterns (e.g. Snort rules). High accuracy for known threats; **blind to zero-day attacks**.
  • Anomaly-Based / Behavioral Detection: Establishes a baseline of normal network behavior using machine learning. Flags deviations from baseline. Can detect **zero-day attacks**, but suffers higher false positive rates.
