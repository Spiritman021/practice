1.1 CIA Triad & AAA Security Framework

Network Security is built upon two core foundational frameworks: the CIA Triad (information goals) and the AAA Framework (access management).

1. The CIA Triad

🔒 Confidentiality
Goal: Ensures data is kept private and accessible ONLY to authorized users. Protects against eavesdropping.
Enforcement: Encryption algorithms (AES, RSA), SSL/TLS, VPNs, Access Control Lists (ACLs).
Exam Attack: Sniffing, Man-in-the-Middle (MITM), Shoulder Surfing.
🛡️ Integrity
Goal: Ensures data is NOT altered, modified, or tampered with during transit or storage.
Enforcement: Cryptographic Hashes (SHA-256, MD5), Digital Signatures, HMAC.
Exam Attack: Packet Injection, Tampering, Replay Attacks.
⚡ Availability
Goal: Guarantees data, networks, and services are accessible to legitimate users whenever needed.
Enforcement: High Availability (HA), Redundancy, Load Balancing, Firewalls, SYN Cookies.
Exam Attack: DoS (Denial of Service), DDoS SYN Floods, Ransomware.

2. The AAA Framework

Component Question Answered Description & Mechanism Real-World Protocol / Tech
Authentication "Who are you?" Verifying the claimed identity of a user or system. Passwords, Biometrics, Smart Cards, 2FA/MFA, Kerberos
Authorization "What can you do?" Determining permissions and access rights granted to an authenticated identity. Role-Based Access Control (RBAC), File Permissions (chmod), ACLs
Auditing / Accounting "What did you do?" Logging and tracking actions for accountability, forensic investigation, and compliance. Syslog, Audit Trails, RADIUS / TACACS+ loggers

1.2 Cryptography: Symmetric vs Asymmetric Encryption

Cryptography is the science of converting readable Plaintext into unreadable Ciphertext (Encryption) and back (Decryption).

Feature Symmetric Key Cryptography (Private Key) Asymmetric Key Cryptography (Public Key)
Key Count 1 Secret Key (shared between sender & receiver). 2 Keys per user (1 Public Key + 1 Private Key).
Key Relationship Same key used for both Encryption & Decryption. Public Key encrypts $\rightarrow$ Private Key decrypts (or vice versa).
Speed & Efficiency Extremely Fast (computational overhead is minimal). Slower (complex mathematical prime factorizations).
Key Distribution Hard to distribute key securely (Key Distribution Problem). Easy key distribution (Public Key is distributed freely).
Primary Use Cases Bulk data encryption (file systems, database streams, AES). Digital signatures, key exchange protocols (Diffie-Hellman), SSL/TLS handshake.
Algorithms AES, DES, 3DES, Blowfish, RC4, IDEA. RSA, Diffie-Hellman, ECC (Elliptic Curve), DSA.
🧮 IBPS SO IT Mathematical Key Formulas
  • Symmetric Encryption Key Count Formula: For $N$ users to communicate securely pairwise: $$\text{Total Keys} = \frac{N(N - 1)}{2}$$ Example: For 10 users $\rightarrow \frac{10 \times 9}{2} = 45$ secret keys required.
  • Asymmetric Encryption Key Count Formula: For $N$ users: $$\text{Total Keys} = 2N$$ Example: For 10 users $\rightarrow 2 \times 10 = 20$ total keys (10 Public + 10 Private).

1.3 Hash Functions (MD5, MD6, SHA Family)

A Cryptographic Hash Function is a mathematical algorithm that converts an arbitrary-sized input string into a fixed-length bit string (Digest).

1. One-Way Property
It is computationally impossible to reverse a hash digest back into its original input plaintext: $H = \text{hash}(M)$, cannot get $M$ from $H$.
2. Avalanche Effect
Changing even a single bit in the input message changes more than 50% of the output hash digest completely.
3. Collision Resistance
It should be virtually impossible to find two distinct inputs $M_1 \neq M_2$ such that $\text{hash}(M_1) = \text{hash}(M_2)$.

Hash Family Output Digest Master Table (High Yield IBPS SO IT)

Algorithm Name Output Digest Size (Bits) Output Digest Size (Bytes) Security Status & Remarks
MD5 (Message Digest 5) 128 Bits 16 Bytes Deprecated due to collision vulnerability (Brucker attacks).
MD6 (Message Digest 6) 256 Bits (Up to 512) 32 Bytes Variable-length hash algorithm designed for parallelized CPU architecture.
SHA-1 (Secure Hash Algorithm) 160 Bits 20 Bytes Deprecated by Google/Microsoft (SHAttered collision attack 2017).
SHA-256 (SHA-2 Family) 256 Bits 32 Bytes Industry Standard (Used in Bitcoin, SSL/TLS certificates, IPsec).
SHA-512 (SHA-2 Family) 512 Bits 64 Bytes Ultra-high security hash standard.

1.4 Digital Signatures & Non-Repudiation Mechanics

A Digital Signature is a mathematical technique used to guarantee message Authenticity, Integrity, and Non-Repudiation.

🔄 Step-by-Step Signing & Verification Process:

  1. Signing (Sender / Alice):
    • Alice computes Hash $H = \text{SHA-256}(\text{Message})$.
    • Alice encrypts Hash $H$ using Alice's PRIVATE Key $\rightarrow$ This produces the Digital Signature!
    • Alice sends both the original Message + Digital Signature to Bob.
  2. Verification (Receiver / Bob):
    • Bob receives Message + Signature.
    • Bob decrypts Signature using Alice's PUBLIC Key $\rightarrow$ yields Hash $H_1$.
    • Bob computes fresh Hash $H_2 = \text{SHA-256}(\text{Message})$.
    • If $H_1 == H_2$, the signature is VALID! (Proves authenticity & integrity).

⚠️ IBPS SO IT Golden Rule: Key Usage Distinction

  • To achieve Confidentiality (Privacy) $\rightarrow$ Encrypt with RECEIVER'S Public Key.
  • To achieve Digital Signature / Non-Repudiation $\rightarrow$ Encrypt Hash with SENDER'S Private Key.
  • Non-Repudiation: The sender CANNOT deny sending the message because only the sender holds their private key!

1.5 Firewall Fundamentals & Form Factors

A Firewall is a network security device that monitors, filters, and controls incoming and outgoing network traffic based on configured security rules (Access Control Lists - ACLs).

🖥️ Software Firewalls
Installed as software applications directly on endpoints (e.g. Windows Defender Firewall, iptables). Protects individual host computers.
🔌 Hardware Firewalls
Dedicated standalone physical appliances placed between internal router and external network (e.g., Cisco ASA, Palo Alto). Handles high throughput for entire LANs.
☁️ Cloud Firewalls (FWaaS)
Virtual firewalls deployed in cloud infrastructure (AWS Security Groups, Azure Firewall). Scalable perimeter control for cloud workloads.

1.6 Firewall Generations by OSI Layer

Firewalls are categorized based on the OSI Layer at which they inspect network traffic:

Firewall Type OSI Operating Layer Inspection Details Pros & Cons / Security Level
Packet Filtering Firewall Layer 3 (Network) & Layer 4 (Transport) Inspects IP addresses (Source/Dest), Port numbers (Source/Dest), and Protocol types (TCP/UDP/ICMP). Does NOT open packet payload. Pros: Extremely fast, low CPU load.
Cons: Cannot detect malware in payload. Vulnerable to IP spoofing.
Circuit-Level Gateway Layer 5 (Session Layer) Verifies TCP 3-Way Handshake (SYN, SYN-ACK, ACK) and virtual connection validity before allowing packet flow. Pros: Fast, resource-efficient, validates connection legitimacy.
Cons: Does not inspect packet content/payload. Malicious payloads passing TCP handshake will bypass it.
Application-Level Gateway (Proxy Firewall) Layer 7 (Application Layer) Acts as a full proxy intermediary. Performs Deep Packet Inspection (DPI), inspecting HTTP headers, URLs, FTP commands, and file payloads. Pros: Highest security level, detects application-layer malware & viruses.
Cons: Slower performance, high CPU/memory consumption.

1. Stateless vs Stateful SPI

• Stateless Packet Filter: Evaluates every packet in isolation against static rule lists without tracking connection state.
• Stateful Packet Inspection (SPI): Tracks active TCP connection states in a State Table. Allows return traffic dynamically for established sessions!

2. Next-Gen Firewall (NGFW)

Combines traditional Stateful Packet Inspection (SPI) with Application Control, Deep Packet Inspection (DPI), Integrated Intrusion Prevention System (IPS), and TLS/SSL encrypted traffic inspection.

IBPS SO IT 2022 Verified
Q1. A Circuit-Level Gateway firewall operates at which layer of the OSI model to filter network traffic?
A) Network Layer (Layer 3)
B) Transport Layer (Layer 4)
C) Session Layer (Layer 5) ✓
D) Application Layer (Layer 7)
Correct Answer: C) Session Layer (Layer 5).
Explanation: Circuit-level gateways operate at Layer 5 (Session Layer) by validating TCP 3-way handshakes (SYN, SYN-ACK, ACK) and session establishment. Packet Filtering operates at L3/L4, and Proxy Firewalls operate at L7 (Application Layer).
IBPS SO IT 2023 Verified
Q2. To provide Non-Repudiation and verify sender authenticity in digital message exchange, the digital signature is created by encrypting the message digest with:
A) Receiver's Public Key
B) Receiver's Private Key
C) Sender's Public Key
D) Sender's Private Key ✓
Correct Answer: D) Sender's Private Key.
Explanation: A digital signature is generated by hashing the plaintext message and encrypting that hash using the Sender's Private Key. Because only the sender possesses their private key, anyone can verify the signature using the sender's public key, guaranteeing non-repudiation!
IBPS SO IT 2020 Verified
Q3. If 20 users in a banking network wish to communicate with complete confidentiality using Symmetric Encryption, how many total secret keys must be generated?
A) 20 Keys
B) 40 Keys
C) 190 Keys ✓
D) 400 Keys
Correct Answer: C) 190 Keys.
Formula: $\text{Total Keys} = \frac{N(N-1)}{2} = \frac{20 \times 19}{2} = 190$ secret keys. (If Asymmetric Encryption were used, it would require $2N = 40$ keys!).
IBPS SO IT 2021 Verified
Q4. What is the fixed hash output size generated by the Message Digest 5 (MD5) algorithm?
A) 128 Bits (16 Bytes) ✓
B) 160 Bits (20 Bytes)
C) 256 Bits (32 Bytes)
D) 512 Bits (64 Bytes)
Correct Answer: A) 128 Bits.
Key Reference: MD5 generates a 128-bit digest, SHA-1 generates 160-bit, and SHA-256 generates 256-bit hash digest.
IBPS SO IT 2024 Verified
Q5. Which type of firewall performs Deep Packet Inspection (DPI) at the Application Layer to inspect actual packet contents for malicious code?
A) Packet Filtering Firewall
B) Circuit-Level Gateway
C) Application-Level Gateway (Proxy Firewall) ✓
D) Stateless Packet Filter
Correct Answer: C) Application-Level Gateway (Proxy Firewall).
Explanation: Application-Level Gateways (Proxy Firewalls) operate at Layer 7 (Application Layer) and perform Deep Packet Inspection (DPI) on the actual application payload.

1.8 Quick Exam Revision Cheat Sheet

1. CIA Triad: Confidentiality (Privacy/Encryption), Integrity (Tamper-proofing/Hashes), Availability (Accessibility/Redundancy).

2. AAA Framework: Authentication (Who are you?), Authorization (What permissions do you have?), Accounting (Logging actions).

3. Cryptography Keys: Symmetric = 1 Secret Key ($\frac{N(N-1)}{2}$ keys). Asymmetric = Public/Private pair ($2N$ keys). Fast = Symmetric (AES); Key Exchange = Asymmetric (RSA/Diffie-Hellman).

4. Hash Bit Sizes: MD5 = 128 bits | SHA-1 = 160 bits | SHA-256 = 256 bits | SHA-512 = 512 bits.

5. Digital Signature: Message Hash encrypted with Sender's Private Key. Verified with Sender's Public Key. Provides Non-Repudiation.

6. Firewall Layers:
• Packet Filter = Layers 3 & 4 (Network & Transport - IP/Ports)
• Circuit Gateway = Layer 5 (Session - TCP 3-Way Handshake)
• Proxy Gateway = Layer 7 (Application - Deep Packet Inspection DPI)
