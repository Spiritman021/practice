Section 01

Why Error Control? The Big Picture

📬
🇮🇳 Real-World Analogy

Imagine sending a letter, but the postal service might tear or smudge some words. To verify your letter arrived correctly, you add a "summary" at the end. The receiver checks that summary — if it matches, the letter is intact. That's exactly what Error Control does at the Data Link Layer!

💡
Core Principle
Data can be corrupted during transmission over physical media (noise, interference). The Data Link Layer adds redundant (extra) bits to data so the receiver can detect or even correct errors — without asking for retransmission.

Two Goals of Error Control

Goal 1
🔍 Error Detection
Find out whether the received data is the same as sent data. Does NOT correct — just raises a flag. The receiver asks sender to re-send.

Techniques: Parity, CRC, Checksum
Goal 2
🔧 Error Correction
Not only detect, but also fix the error at receiver side — no need to ask for retransmission!

Technique: Hamming Code (adds more redundant bits)
⚡
Section 02

Types of Errors

Type 1 – Less Common
🔴 Single-Bit Error
Only one bit changes in a data unit. If 0 was sent, 1 is received (or vice versa).

Rare in real networks. Mainly seen in parallel transmission.
Type 2 – Most Common
🔴🔴 Burst Error
Two or more bits in a data unit are corrupted. The length of burst = from first corrupted bit to last corrupted bit.

Common in serial transmission due to electrical interference.
📻
Analogy

Single-bit error = one letter smudged in a book. Burst error = a whole paragraph blurred due to water damage. Burst errors are far more common and need stronger detection!

Section 03

Block Coding – Datawords & Codewords

Block coding is the foundation of error detection and correction. Here's how it works:

1
Split the message into k-bit blocks → called Datawords
Each block has k bits. These are your original data units.
2
Add r redundant bits to each dataword → creates Codeword
The codeword has n = k + r bits. These extra r bits help detect/correct errors.
3
Receiver checks codeword validity
Receiver uses the same algorithm — if the codeword is valid, data is error-free; if invalid, an error occurred.
⚡ Key Formula
n = k + r
n = codeword length  |  k = dataword length  |  r = number of redundant bits

IBPS SO IT Tip
In IBPS SO IT questions, they often give you k and n and ask for r, or vice versa. Just remember: r = n − k. If dataword has 4 bits and codeword has 7 bits, then r = 7 − 4 = 3 redundant bits.

Section 04

Hamming Distance ⭐ Most Asked!

🔥 IBPS SO IT – Very High Frequency
🔤
What is Hamming Distance?

Count how many bits are different between two binary words of the same length. Like counting how many letters differ between "CAT" and "COT" (answer: 1 — only middle letter differs). For bits: 0010 vs 0100 → positions 2 and 3 differ → Hamming distance = 2.

How to Calculate Hamming Distance

XOR the two words and count the number of 1s in the result. The count of 1s = Hamming distance.

1 0 1 0 1  ← Word 1
1 1 1 1 0  ← Word 2
0 1 0 1 1  ← XOR result
Three 1s → Hamming Distance = 3
XOR approach to find Hamming Distance

Minimum Hamming Distance (dmin)

In a set of codewords, the Minimum Hamming Distance is the smallest Hamming distance between any two valid codewords. This is the most important property of a code scheme.

🔴 For Error DETECTION (detect up to s errors)
dmin = s + 1
To detect up to s errors → minimum Hamming distance must be at least s+1
🟢 For Error CORRECTION (correct up to t errors)
dmin = 2t + 1
To correct up to t errors → minimum Hamming distance must be at least 2t+1

Worked Examples (Exam-Style)

📝
Example 1: Detection
Q: A code has dmin = 4. How many errors can it detect?
A: Use s = dmin − 1 = 4 − 1 = 3 errors can be detected.
📝
Example 2: Correction
Q: A code has dmin = 4. How many errors can it correct?
A: Use t = (dmin − 1) / 2 = (4 − 1) / 2 = 1.5 → floor = 1 error can be corrected.
Note: dmin must be odd for full correction capability. Even dmin wastes capacity.
📝
Example 3: Find dmin for 5-error correction
Q: What minimum Hamming distance is needed to correct up to 5 errors?
A: dmin = 2t + 1 = 2(5) + 1 = 11

Section 05

Parity Check – Simple & 2D

Error Detection Only

Simple Parity Check (1D Parity)

The simplest error detection method. A single parity bit is added to make the total number of 1s either Even (even parity) or Odd (odd parity).

Simple Parity Code
n = k + 1   |   dmin = 2
One extra parity bit → can detect odd number of errors only
What it CAN detect
✅ Odd number of errors
1 error, 3 errors, 5 errors… If an odd number of bits flip, the parity will be wrong and the error is caught.
What it CANNOT detect
❌ Even number of errors
2 errors, 4 errors… Two flipped bits cancel each other out — parity stays the same and error is missed!

2D Parity Check (Two-Dimensional)

Data is arranged in a grid (rows and columns). Parity bit is added for each row AND each column. This allows detecting AND correcting single-bit errors.

📊
2D Parity: Think like a Sudoku row+column check!

If one bit is wrong, the error shows up in both its row parity AND column parity — giving us the exact position of the error. Then we flip that bit to fix it!

🎯
IBPS SO IT Key Point
Simple parity: detects odd errors only. 2D parity: can detect and correct single-bit errors AND detect (not always correct) burst errors. Simple parity C(5,4) means 5-bit codeword from 4-bit dataword.
🔄
Section 06

Cyclic Redundancy Check (CRC)

🔥 IBPS SO IT – Most Frequently Asked
Error Detection (Very Powerful)

CRC is the most powerful and widely used error detection technique. It is based on binary division (modulo-2 division). It is used at the Data Link Layer.

➗
CRC in Plain English

Sender divides data by a "secret code" (generator polynomial). The remainder is appended to data. Receiver divides received data by same "secret code". If remainder = 0 → no error. If remainder ≠ 0 → error detected!

CRC – Step by Step (Sender Side)

1
Append zeros to the data
If generator has degree r (r+1 bits), append r zeros to the data message.
2
Divide (Modulo-2 Division)
Divide the augmented data by the generator polynomial using XOR operations (no carry/borrow in modulo-2).
3
Get the Remainder (CRC bits)
The remainder of this division becomes the CRC (Frame Check Sequence – FCS).
4
Append CRC to original data
Replace those r appended zeros with the actual CRC remainder. Send this complete frame.
Data Bits
÷
Generator (G(x))
=
Remainder (CRC)

CRC – Receiver Side

1
Receive the full frame (data + CRC)
The entire received frame is divided by the same generator polynomial.
2
Check the Remainder (Syndrome)
Remainder = 0: No error detected. Data accepted.
Remainder ≠ 0: Error detected! Frame rejected/retransmit requested.
⚙️
Properties of a Good Generator Polynomial
A CRC generator polynomial must:
1. Have at least two terms
2. Coefficient of x0 must be 1
3. Should NOT divide xt + 1 (for t between 2 and n-1)
4. Should have the factor (x + 1) — to detect all odd-numbered errors

Note: Errors that are divisible by g(x) are NOT detected by CRC.
Standard CRC Generator Polynomial Usage Bits
CRC-8x⁸ + x² + x + 1ATM headers8
CRC-16x¹⁶ + x¹⁵ + x² + 1HDLC, USB16
CRC-32x³² + ... + 1Ethernet, ZIP, PNG32
CRC-CCITTx¹⁶ + x¹² + x⁵ + 1X.25, V.34, ISDN16

Section 07

Checksum

Error Detection — Used by Internet Protocols

Checksum is used in the Internet layer protocols (IP, TCP, UDP) — NOT at Data Link Layer. But Forouzan discusses it here to complete the error-detection topic.

Sender Steps
📤 How to Send
1. Divide message into 16-bit segments
2. Add all segments using one's complement arithmetic
3. Take complement of the final sum → this is the checksum
4. Append checksum to message and send
Receiver Steps
📥 How to Verify
1. Divide received message + checksum into 16-bit segments
2. Add all segments using one's complement arithmetic
3. Take complement of result
4. If result = 0 → Accept! If result ≠ 0 → Error!
🎯
IBPS SO IT Key Distinction
Parity & CRC → used at Data Link Layer. Checksum → used at Transport Layer (TCP/UDP) and Network Layer (IP). This is a frequently tested distinction in IBPS SO IT exams!

Section 08

ARQ Protocols – Error Control via Retransmission

ARQ = Automatic Repeat reQuest
📡
What is ARQ?

When error is detected, instead of correcting it, the receiver asks the sender to resend the corrupted frame. ARQ combines error detection + retransmission. It's like saying "Sorry, I didn't catch that — could you repeat?" in a phone call!

3 Types of ARQ Protocols

⏸ Stop-and-Wait ARQ
Sender sends ONE frame at a time. Waits for ACK before sending next frame. Simplest but most inefficient — wastes bandwidth while waiting.
Window Size = 1

✅ Simple to implement
❌ Very slow, low efficiency
❌ Half-bandwidth wasted in waiting
🔙 Go-Back-N ARQ
Sender can send multiple frames (window size = 2ⁿ−1). If error in frame i: sender goes BACK to frame i and retransmits ALL frames from i onwards.
Sender window: 2ⁿ⁻¹ | Receiver window: 1

✅ Better than Stop-Wait
❌ Wastes bandwidth (retransmits correct frames)
❌ Receiver window = 1 (can't buffer)
🎯 Selective Repeat ARQ
Sender can send multiple frames. If error in frame i: ONLY frame i is retransmitted. Receiver buffers correct out-of-order frames.
Sender = Receiver window: 2ⁿ⁻¹

✅ Most efficient
✅ Minimum retransmissions
❌ Complex, needs large receiver buffer

ARQ Protocol Comparison Table

Feature Stop-and-Wait Go-Back-N Selective Repeat
Sender Window Size 1 2ⁿ⁻¹ 2ⁿ⁻¹
Receiver Window Size 1 1 2ⁿ⁻¹
On Error: Retransmit Only that 1 frame Error frame + all after Only error frame
Efficiency Lowest Medium Highest
Buffer at Receiver Not needed Not needed (discards) Large buffer needed
Complexity Simple Moderate Complex
⚠️
Important: ARQ is Error CONTROL, not just Error DETECTION
Stop-and-Wait ARQ is a flow control and error control technique. When asked in IBPS SO IT "Stop-and-wait ARQ is a ___ technique" → Answer is Error Control.

Section 10

IBPS SO IT PYQ Practice Questions

📌
How to Use This Section
These questions are sourced from IBPS SO IT Officer previous year papers and similar competitive exams. Try answering each question before revealing the answer. All answers are verified from the Forouzan textbook (same source as Lec 14).
PYQ 01 CRC – Error Detection
Error detection at the Data Link Layer is typically achieved by:
  • A. Bit stuffing
  • B. Cyclic Redundancy Codes (CRC) ✓
  • C. Hamming codes
  • D. Equalization
Answer: B — CRC
CRC is the standard error detection method at Data Link Layer. Hamming codes are used for error correction. Bit stuffing is used for framing (flag synchronization), not error detection. Equalization is a physical layer concept.
PYQ 02 Hamming Distance – Detection Formula
To guarantee detection of up to 5 errors, the minimum Hamming distance must be:
  • A. 5
  • B. 6 ✓
  • C. 11
  • D. 10
Answer: B — 6
Formula: dmin = s + 1 = 5 + 1 = 6
Trick: Option C (11) is for correcting 5 errors, not detecting. Don't confuse detection and correction formulas!
PYQ 03 Hamming Distance – Correction Formula
To guarantee correction of up to 5 errors in all cases, the minimum Hamming distance in a block code must be:
  • A. 5
  • B. 6
  • C. 11 ✓
  • D. None of the above
Answer: C — 11
Formula: dmin = 2t + 1 = 2(5) + 1 = 11
Remember: Error CORRECTION formula uses 2t+1 (the "2" makes it harder). Error detection just needs s+1.
PYQ 04 Parity Check
A simple parity check code can detect:
  • A. All types of errors
  • B. An odd number of errors ✓
  • C. An even number of errors
  • D. Burst errors only
Answer: B — Odd number of errors
Simple parity has dmin = 2, so it can detect up to s = dmin − 1 = 1 error. But more specifically, parity check detects any odd number of errors (1, 3, 5, …). If 2 bits flip, parity remains valid and error is missed.
PYQ 05 ARQ Protocols
Stop-and-Wait ARQ is a _______ technique.
  • A. Line discipline
  • B. Flow control
  • C. Error control ✓
  • D. Session management
Answer: C — Error Control
ARQ (Automatic Repeat reQuest) is an error control protocol. Stop-and-Wait ARQ uses acknowledgments and timeouts to achieve reliable frame delivery. It detects errors via CRC and requests retransmission.
PYQ 06 CRC Properties
In CRC, if syndrome s(x) = 0 after division at receiver, it means:
  • A. No error OR undetected error ✓
  • B. Always no error
  • C. Error detected
  • D. Frame discarded
Answer: A
When s(x) = 0: either (a) no bit is corrupted, OR (b) some bits are corrupted but the error pattern is divisible by g(x) — decoder fails to detect. When s(x) ≠ 0: one or more bits are definitely corrupted. This is a subtle but important point from the textbook.
PYQ 07 Go-Back-N ARQ
In Go-Back-N ARQ with n=3 (3-bit sequence number), what is the maximum sender window size?
  • A. 3
  • B. 4
  • C. 7 ✓
  • D. 8
Answer: C — 7
Formula: Sender Window = 2ⁿ − 1 = 2³ − 1 = 8 − 1 = 7
For Selective Repeat with n=3: Window = 2ⁿ⁻¹ = 2² = 4
Remember: Go-Back-N uses 2ⁿ−1; Selective Repeat uses 2ⁿ⁻¹.
PYQ 08 Network Layer vs Data Link
Which of the following is NOT a function of the Data Link Layer?
  • A. Framing
  • B. Error detection and correction
  • C. Network (IP) addressing ✓
  • D. Flow control
Answer: C — Network addressing
Network/IP addressing is the function of the Network Layer (Layer 3). Data Link Layer (Layer 2) handles: Framing, Physical Addressing (MAC), Error Detection, Error Correction, Flow Control, and Access Control.
PYQ 09 Hamming Code dmin=4
A code scheme has a Hamming distance dmin = 4. What is the error detection and correction capability?
  • A. Detect 4 errors, Correct 2 errors
  • B. Detect 2 errors, Correct 2 errors
  • C. Detect 3 errors, Correct 1 error ✓
  • D. Detect 4 errors, Correct 1 error
Answer: C
Detection: s = dmin − 1 = 4 − 1 = 3 errors
Correction: t = floor((dmin−1)/2) = floor(3/2) = 1 error
Note: Error correction codes need odd minimum distance (3, 5, 7…). dmin=4 wastes some correction capability.
PYQ 10 Block Coding – n, k, r
In block coding, if a dataword is 4 bits and the codeword is 7 bits, how many redundant bits are added?
  • A. 4
  • B. 7
  • C. 11
  • D. 3 ✓
Answer: D — 3
Formula: r = n − k = 7 − 4 = 3 redundant bits
This is the classic C(7,4) Hamming code — 4 data bits + 3 parity/redundant bits = 7-bit codeword. This code can correct 1 error (dmin = 3).
🚀
Quick Exam Revision – Remember These!
1. Error DETECTION: dmin = s + 1  |  2. Error CORRECTION: dmin = 2t + 1
3. CRC → Best for burst errors, Data Link Layer
4. Parity → Detects odd errors only. Simple parity: dmin=2
5. Checksum → Network & Transport Layer (NOT Data Link)
6. Go-Back-N: sender window = 2ⁿ−1, receiver window = 1
7. Selective Repeat: both windows = 2ⁿ⁻¹
8. ARQ = Error Control technique (retransmission-based)
9. n = k + r (codeword = dataword + redundant bits)
10. CRC: if s(x) = 0 → no error detected; if s(x) ≠ 0 → error!
