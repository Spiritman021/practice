The OSI 7-Layer Reference Model

Created by ISO in 1984, the Open Systems Interconnection (OSI) model provides a universal 7-layer architectural framework for understanding network communication, data encapsulation, and layer responsibilities.

Section 6.1

Introduction & Need for Layering

The OSI (Open Systems Interconnection) Model was developed by the International Organization for Standardization (ISO) in 1984. It is a conceptual framework that divides network communications into seven distinct layers.

Why a Layered Architecture?

  • Modularity & Interoperability: Enables hardware and software from different vendors to work together seamlessly.
  • Simplifies Design: Complex networking problems are broken down into smaller, manageable sub-problems.
  • Flexibility: Changes made at one layer do not affect other layers (e.g., changing from Wi-Fi to Ethernet does not break your browser).
  • Standardization: Defines clear interfaces and boundaries between network components.

Section 6.3

PDUs & Data Encapsulation Process

A Protocol Data Unit (PDU) is the single unit of information transmitted among peer entities of a computer network. As data moves down the OSI layers on the sender side, each layer attaches its own Header (H) (and Trailer at Layer 2) — a process called Encapsulation.

On the receiver side, as data moves up through the layers, headers are stripped off — a process called Decapsulation.

Application Layer
PDU: Data / Message

The Application Layer is the topmost layer of the OSI model. It serves as the interface between software applications and the underlying network. It directly interacts with application programs (browsers, email clients) to provide network services.

Core Functions

  • Network Services Interface: Provides protocols that allow software to send and receive data over a network.
  • File Transfer & Management: Facilitates remote file access and operations (FTP, SFTP).
  • Email Services: Handles mail routing and store-and-forward capabilities (SMTP, IMAP, POP3).
  • Web Browsing: Transfers hypermedia documents (HTTP, HTTPS).
  • Directory Services: Provides distributed database sources for global object lookup (DNS, LDAP).

Key Protocols

HTTP, HTTPS, FTP, SMTP, DNS, DHCP, Telnet, SSH, SNMP

6
Presentation Layer
PDU: Data

The Presentation Layer acts as the "translator" for the network. It ensures that data sent from the application layer of one system is readable by the application layer of another system.

Core Functions

  • Data Translation / Formatting: Converts data between vendor-dependent formats (e.g., ASCII to EBCDIC or Unicode).
  • Encryption & Decryption: Handles privacy and security formatting (SSL/TLS encryption happens here conceptually).
  • Compression & Decompression: Reduces data size to increase transmission efficiency (JPEG, MPEG, ZIP).
5
Session Layer
PDU: Data

The Session Layer is responsible for establishing, managing, maintaining, and terminating sessions (connections) between applications on different devices.

Core Functions

  • Session Establishment & Termination: Starts, maintains, and cleanly closes communication dialogues.
  • Dialog Control: Determines which device transmits when (Simplex, Half-Duplex, or Full-Duplex).
  • Synchronization & Checkpointing: Inserts checkpoints into long data streams so that if a failure occurs, transmission resumes from the last checkpoint rather than starting over.
4
Transport Layer
PDU: Segment / Datagram

The Transport Layer provides end-to-end communication services for applications. It ensures reliable, transparent, and error-free data transfer between process-to-process (host-to-host).

Core Functions

  • Service Point (Port) Addressing: Uses 16-bit Port numbers (e.g., Port 80 for HTTP) to ensure data reaches the correct application process on a host.
  • Segmentation & Reassembly: Divides large messages into smaller segments at sender; reassembles them in correct sequence at receiver using sequence numbers.
  • Connection Control: Can be connection-oriented (TCP with 3-way handshake) or connectionless (UDP).
  • Flow Control: Prevents a fast sender from overwhelming a slow receiver (Sliding Window Protocol).
  • Error Control: Ensures entire message arrives without error or loss through sequence numbering, checksums, and ACKs.

Key Protocols

TCP (Transmission Control Protocol), UDP (User Datagram Protocol)

3
Network Layer
PDU: Packet

The Network Layer is responsible for the source-to-destination (host-to-host) delivery of packets across multiple intermediate network links/routers.

Core Functions

  • Logical Addressing: Adds logical IP addresses (source & destination IP) to packet headers.
  • Routing: Determines the optimal physical path for packets to travel across interconnected networks using routing algorithms and routing tables.
  • Packet Fragmentation & Reassembly: Breaks packets into smaller fragments if the underlying network's MTU (Maximum Transmission Unit) is smaller than the packet size.

Key Hardware & Protocols

Hardware: Routers, Layer 3 Switches | Protocols: IP (IPv4, IPv6), ICMP, ARP, OSPF, BGP

2
Data Link Layer
PDU: Frame

The Data Link Layer transforms a raw physical transmission facility into a reliable link. It is responsible for node-to-node (hop-to-hop) delivery of data frames on the same local network.

Sublayers

  • LLC (Logical Link Control - IEEE 802.2): Interfaces with the Network layer above, handles flow control, and manages error checking.
  • MAC (Media Access Control - IEEE 802.3/802.11): Manages physical media access, framing, and hardware MAC addressing.

Core Functions

  • Framing: Divides stream of bits into manageable data units called Frames with headers and trailers.
  • Physical Addressing: Adds 48-bit MAC addresses (Source MAC and Destination MAC) to the frame.
  • Flow & Error Control: Performs error detection using CRC (Cyclic Redundancy Check) in the trailer (FCS).
  • Access Control: Determines which device has control over the shared transmission medium at any given time (CSMA/CD, CSMA/CA).

Key Hardware & Protocols

Hardware: Switches, Bridges, NICs | Protocols: Ethernet (802.3), Wi-Fi (802.11), PPP, HDLC

1
Physical Layer
PDU: Bits

The Physical Layer is the lowest layer of the OSI model. It is responsible for transmitting raw, unstructured bitstreams over a physical medium.

Core Functions

  • Representation of Bits: Defines how 0s and 1s are converted into electrical voltages, light pulses, or radio signals.
  • Data Rate (Transmission Speed): Defines the duration of a bit and number of bits sent per second (bps).
  • Synchronization of Bits: Ensures sender and receiver clocks are synchronized.
  • Physical Topologies & Line Configuration: Defines topology (Star, Bus, Ring) and connection type (Point-to-Point, Multipoint).
  • Transmission Mode: Defines direction of signal flow (Simplex, Half-Duplex, Full-Duplex).

Key Hardware & Media

Hardware: Repeaters, Hubs, Modems, Cables (Cat6, Fiber Optic), Connectors (RJ-45)
