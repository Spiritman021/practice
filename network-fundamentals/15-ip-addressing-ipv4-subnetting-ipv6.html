Section 15.1

IPv4 Address Basics

An IPv4 Address is a **32-bit (4-byte) logical address** that uniquely identifies a network interface on an IP network. Written in **dotted-decimal notation**: 192.168.1.100 (each octet ranges from 0 to 255).

Every IP address consists of two parts:

  • Network ID (NetID): Identifies the specific network to which the host belongs.
  • Host ID (HostID): Identifies the specific device on that network.

Section 15.3

Special & Private IP Ranges (RFC 1918)

1. RFC 1918 Private IP Ranges (Non-routable on Internet)

  • Class A Private: 10.0.0.0 to 10.255.255.255 (10.0.0.0/8)
  • Class B Private: 172.16.0.0 to 172.31.255.255 (172.16.0.0/12)
  • Class C Private: 192.168.0.0 to 192.168.255.255 (192.168.0.0/16)

2. Special Purpose IPv4 Addresses

  • Loopback Address: 127.0.0.1 (127.0.0.0/8 range) — used to test local host protocol stack.
  • APIPA (Automatic Private IP): 169.254.0.0/16 — assigned automatically by Windows if DHCP server fails.
  • Default Route: 0.0.0.0/0 — matches any network destination.
  • Limited Broadcast: 255.255.255.255 — broadcasts to all hosts on local subnet (not routed).

Section 15.4

Subnetting (FLSM & VLSM)

Subnetting is the process of borrowing bits from the **Host ID** part to create smaller, logical sub-networks (subnets). This reduces broadcast domain size and conserves IP addresses.

Core Subnetting Formulas:
• Number of Subnets created = 2s (where s = borrowed subnet bits)
• Number of Usable Hosts per Subnet = 2h - 2 (where h = remaining host bits)
• Block Size (Magic Number) = 256 - Subnet Octet Value

FLSM vs VLSM

  • FLSM (Fixed-Length Subnet Mask): All subnets are equal in size (same subnet mask). Wastes IP addresses if subnets have different host requirements.
  • VLSM (Variable-Length Subnet Mask): Subnets have different sizes tailored to exact host requirements. Minimizes wasted IP addresses.
⚡
Section 15.5

CIDR & Supernetting

CIDR (Classless Inter-Domain Routing) replaced classful addressing in 1993. It eliminates A, B, C classes and allows custom prefix lengths using **Slash Notation** (e.g. 192.168.1.0/26).

Supernetting (Route Aggregation) combines multiple contiguous smaller network prefixes into a single shorter prefix (e.g., combining four /24 routes into one /22 route), drastically reducing internet routing table sizes.

Section 15.6

IPv6 Architecture & Address Types

IPv6 was developed to replace exhausted 32-bit IPv4 addresses with a 128-bit (16-byte) address space — providing 2128 ≈ 3.4 × 1038 unique addresses!

Written in **hexadecimal colon notation** divided into 8 groups of 4 hex digits: 2001:0db8:85a3:0000:0000:8a2e:0370:7334.

IPv6 Address Abbreviation Rules

  • Omit leading zeros in any 4-digit hex group (e.g., :0db8: → :db8:).
  • Replace consecutive groups of all-zero fields with a double colon :: (allowed **only once** per address).
  • Example: 2001:db8:85a3::8a2e:370:7334.

IPv6 Address Types

  • Global Unicast Address (GUA): Publicly routable on internet (starts with 2000::/3).
  • Link-Local Address: Used for communication on the local link only (starts with fe80::/10). Automatically self-configured.
  • Unique Local Address (ULA): Private IP equivalent (starts with fc00::/7 or fd00::/7).
  • Multicast Address: Replaces broadcast (starts with ff00::/8). E.g., ff02::1 (all nodes), ff02::2 (all routers).
  • Anycast Address: Assigned to multiple interfaces; packets are delivered to the *nearest* interface.
  • Loopback Address: ::1/128.
