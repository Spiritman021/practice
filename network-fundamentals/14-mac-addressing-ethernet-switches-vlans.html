Section 14.1

MAC Addressing Structure

A MAC (Media Access Control) Address is a unique 48-bit (6-byte) physical hardware address burned into the ROM of a Network Interface Card (NIC).

Written in hexadecimal format: 00:1A:2B:3C:4D:5E or 00-1A-2B-3C-4D-5E.

Types of MAC Addresses

  • Unicast MAC: Addresses a specific single NIC. LSB of 1st byte = 0 (e.g. 00:1A...).
  • Multicast MAC: Addresses a group of NICs. LSB of 1st byte = 1 (e.g. 01:00:5E:xx:xx:xx for IPv4 multicast).
  • Broadcast MAC: Addresses ALL NICs on the local LAN. All 48 bits set to 1s: FF:FF:FF:FF:FF:FF.

Section 14.4

Switches & Learning Bridge Operation

A Layer 2 Switch maintains a **CAM (Content Addressable Memory) Table** (also called Switching Table or MAC Address Table) that maps connected MAC addresses to physical switch ports.

Switch Forwarding Logic (The 3 Rules)

  1. Learning: When a frame arrives, the switch examines the Source MAC address and records `[Source MAC → Ingress Port]` in its CAM table with an aging timer (default 300s).
  2. Filtering: If the Destination MAC is already in the CAM table and located on the SAME port it arrived on, the switch drops (filters) the frame.
  3. Forwarding / Flooding:
    • If Destination MAC is in CAM table on a DIFFERENT port → Forward to that specific port only.
    • If Destination MAC is NOT in CAM table (Unknown Unicast) OR is Broadcast (FF:FF:FF:FF:FF:FF) → Flood to all ports except the ingress port.

Section 14.5

VLAN Concepts & Benefits

A VLAN (Virtual Local Area Network) is a logical grouping of network devices on one or more physical switches, configured so that they communicate as if they were connected to the same physical switch wire, regardless of physical location.

Why Use VLANs?

  • Broadcast Control: Segments large physical broadcast domains into smaller logical domains (reduces broadcast traffic).
  • Enhanced Security: Users on VLAN 10 (HR) cannot access traffic on VLAN 20 (Finance) without passing through a Layer 3 router/firewall.
  • Cost & Flexibility: Devices can be grouped by department or function rather than physical location.

Section 14.6

IEEE 802.1Q Tagging & Trunking

1. Access Ports vs Trunk Ports

  • Access Port: Belongs to a single VLAN. Carries standard **untagged** Ethernet frames (for end devices like PCs, printers).
  • Trunk Port: Connects switch-to-switch or switch-to-router. Carries traffic for **multiple VLANs** simultaneously using **802.1Q frame tagging**.

2. IEEE 802.1Q Frame Tag Structure

802.1Q inserts a **4-byte VLAN Tag** into the standard Ethernet frame header right after the Source MAC address.

📌
4-Byte 802.1Q Tag Breakdown
• TPID (2 Bytes): Tag Protocol Identifier set to 0x8100 to identify 802.1Q tagged frame.
• TCI (2 Bytes): Tag Control Information containing:
  - PCP (3 bits): Priority Code Point for QoS (CoS 0–7).
  - DEI (1 bit): Drop Eligible Indicator.
  - VLAN ID / VID (12 bits): Identifies the VLAN (Supports 212 = 4096 VLANs, IDs 1 to 4094).

Section 14.7

Inter-VLAN Routing

By default, devices on different VLANs **cannot communicate** at Layer 2. Routing at Layer 3 is required to forward packets between VLANs.

Method 1
Router-on-a-Stick
A single physical link connects Layer 2 Switch to a Router. The router interface is divided into logical **subinterfaces** (e.g. g0/0.10 for VLAN 10), each acting as the default gateway for a VLAN.
Method 2
Layer 3 Switch (SVI)
Modern enterprise approach. A Layer 3 switch performs hardware wire-speed routing between VLANs using **SVI (Switch Virtual Interfaces)** (e.g. interface vlan 10 with an IP address). Fast & highly scalable.
