Section 01

Digital Signal Levels & Bits per Level

A digital signal can have two or more voltage levels ($L$). Each level represents a group of bits.

⚡ Bits per Level Formula
$$n = \log_2(L)$$
$n$ = number of bits per signal level  |  $L$ = number of discrete voltage levels
📝
Worked Example
- If a digital signal has 2 levels ($L=2$) $\implies n = \log_2 2 = \mathbf{1\text{ bit per level}}$ (0 or 1).
- If a digital signal has 4 levels ($L=4$) $\implies n = \log_2 4 = \mathbf{2\text{ bits per level}}$ (00, 01, 10, 11).
- If a digital signal has 8 levels ($L=8$) $\implies n = \log_2 8 = \mathbf{3\text{ bits per level}}$ (000, 001, ..., 111).

Section 02

Bit Rate vs. Baud Rate (Signal Rate)

🔥 IBPS SO IT – High Frequency Numerical Concept
Term 1
Bit Rate ($N$)
The number of data bits transmitted per second ($\text{bps}$). Measured in bps, Mbps, Gbps.
Term 2
Baud Rate / Signal Rate ($S$)
The number of signal elements (symbols) transmitted per second ($\text{baud}$).
⚡ Bit Rate & Baud Rate Relationship
$$S = N \times \frac{1}{r} \quad \implies \quad N = S \times r$$
$$S_{\text{avg}} = c \times N \times \frac{1}{r}$$
$r = \log_2 L$ (data bits carried per signal element)  |  $c$ = case factor ($c = 1/2$ average)

Section 03

Baseband vs. Broadband Transmission

Feature Baseband Transmission Broadband Transmission
Definition Sending a digital signal directly over a channel without converting it to an analog signal. Converting the digital signal to an analog signal (modulation) for transmission.
Channel Type Low-pass channel (frequencies start from 0 Hz). Bandpass channel (frequencies centered around carrier $f_c$).
Multiplexing Time Division Multiplexing (TDM) – single signal at a time. Frequency Division Multiplexing (FDM) – multiple signals simultaneously.
Distance Short distance (LANs, Ethernet cabling). Long distance (Cable TV, DSL, Satellite, Cellular).

Section 04

Line Coding Schemes Overview

Line coding is the process of converting digital data into a digital signal. It maps binary 0s and 1s to specific voltage levels.

Family 1
1. Unipolar (NRZ)
Uses only 1 voltage polarity (e.g., $+V$ for 1, $0\text{V}$ for 0). High DC component and baseline wander. Very inefficient.
Family 2
2. Polar (NRZ-L, NRZ-I, RZ)
Uses 2 voltage polarities ($+V$ and $-V$).
- NRZ-L: Level determines bit ($+V$ for 0, $-V$ for 1).
- NRZ-I: Inversion (transition at start of bit) represents 1; no transition represents 0.
- RZ: Signal returns to 0V in the middle of each bit period.
Family 3
3. Bipolar (AMI, Pseudoternary)
Uses 3 voltage levels ($+V, 0\text{V}, -V$).
- AMI (Alternate Mark Inversion): 0 is $0\text{V}$; 1 alternates between $+V$ and $-V$. Eliminates DC component!
Family 4
4. Multilevel & Multiline
- 2B1Q: 2 bits packed into 1 quaternary signal element.
- MLT-3: Multi-Level Transmit 3 (uses $+V, 0\text{V}, -V$ with 4 transition states, used in Fast Ethernet).
⚡
Section 05

Manchester & Differential Manchester Deep Dive

🔥 IBPS SO IT – Most Tested Line Coding Concept
Standard Ethernet Encoding
⚡ Manchester Encoding
- A voltage transition occurs in the middle of EVERY bit period.
- Transition serves as clock synchronization.
- Bit 0: High-to-Low transition at mid-bit.
- Bit 1: Low-to-High transition at mid-bit.
- Baud Rate: $S = 2 \times N$ (requires double the bandwidth of NRZ).
Token Ring Encoding
⚡ Differential Manchester
- Always has a transition in the middle of the bit period for clocking.
- Bit 0: Transition at the beginning of the bit period.
- Bit 1: NO transition at the beginning of the bit period.
- Ideal for noisy environments and Token Ring networks.
💡
Why Manchester is Self-Synchronizing
Because every bit interval has a transition in the exact middle, the receiver's clock stays perfectly synchronized with the sender's clock even during long streams of 0s or 1s!

Section 06

Bandwidth vs Throughput Solved Examples

📝
Example 1: Document Download Bit Rate
Question: Download 100 text pages/min. Each page has 25 lines, 100 characters/line, 8 bits/character. What is the required bit rate?
$$\text{Total Bits} = 100 \times 25 \times 100 \times 8 = 2,000,000\text{ bits in 60 sec}$$ $$\text{Bit Rate} = \frac{2,000,000\text{ bits}}{60\text{ sec}} = \mathbf{33.33\text{ kbps}} \quad (\text{or } 2\text{ Mbps total data volume per minute})$$
📝
Example 2: Network Throughput Calculation
Question: A network with Bandwidth = $10\text{ Mbps}$ passes an average of $12,000\text{ frames/minute}$, each frame carrying $10,000\text{ bits}$. What is the throughput?
$$\text{Throughput} = \frac{12,000 \times 10,000\text{ bits}}{60\text{ seconds}} = \frac{120,000,000\text{ bits}}{60\text{ sec}} = \mathbf{2,000,000\text{ bps}} = \mathbf{2\text{ Mbps}}$$ Note: Throughput (2 Mbps) is much less than the maximum Bandwidth (10 Mbps).
📊

Master Formulas Cheat Sheet Table

Concept / Formula Mathematical Expression Key Meaning & Units
Bits per Signal Level $$n = \log_2(L)$$ $L$ = signal voltage levels, $n$ = bits/level
Signal Rate / Baud Rate $$S = N \times \frac{1}{r} = \frac{N}{\log_2 L}$$ $N$ = Bit Rate (bps), $S$ = Baud Rate (baud)
Manchester Baud Rate $$S_{\text{Manchester}} = 2 \times N$$ Baud rate is twice the bit rate (2 transitions/bit)

Section 08

IBPS SO IT PYQ Practice Questions

PYQ 01 Bits per Signal Level
If a digital signal has 8 discrete voltage levels, how many bits are carried by each signal level?
  • A. 2 bits
  • B. 3 bits ✓
  • C. 4 bits
  • D. 8 bits
Answer: B — 3 bits
Formula: $n = \log_2(L) = \log_2(8) = \mathbf{3\text{ bits per level}}$.
PYQ 02 Manchester Mid-Bit Transition
Which line coding scheme guarantees a transition in the exact middle of EVERY bit period for clock synchronization?
  • A. NRZ-L
  • B. NRZ-I
  • C. Manchester Encoding ✓
  • D. Bipolar AMI
Answer: C — Manchester Encoding
Manchester encoding forces a transition at the midpoint of each bit interval, making it self-synchronizing.
PYQ 03 Manchester Baud Rate
In standard Manchester encoding, if the bit rate is $10\text{ Mbps}$, what is the required baud rate (signal rate)?
  • A. 5 Mbaud
  • B. 10 Mbaud
  • C. 20 Mbaud ✓
  • D. 40 Mbaud
Answer: C — 20 Mbaud
In Manchester encoding, 2 signal elements (transitions) represent 1 bit ($r = 1/2$). Therefore, $S = 2 \times N = 2 \times 10 = \mathbf{20\text{ Mbaud}}$.
PYQ 04 Bipolar AMI DC Component
In Bipolar AMI (Alternate Mark Inversion) encoding, how is a binary '1' represented?
  • A. Always by a positive voltage $+V$
  • B. Always by zero voltage $0\text{V}$
  • C. Alternating between positive $+V$ and negative $-V$ voltages ✓
  • D. By a transition at the start of bit
Answer: C
In Bipolar AMI, binary 0 is represented by zero voltage ($0\text{V}$), while binary 1s alternate between positive $+V$ and negative $-V$, eliminating DC component.
PYQ 05 Baseband vs Broadband
Sending a digital signal directly over a low-pass wire channel without modulation is known as:
  • A. Baseband Transmission ✓
  • B. Broadband Transmission
  • C. Passband Transmission
  • D. Carrier Modulation
Answer: A — Baseband Transmission
Baseband transmission sends digital signals directly without converting them to analog signals. Broadband uses modulation to convert digital data to analog carriers.
PYQ 06 Throughput Calculation
A network passes 30,000 frames per minute, with each frame carrying 4,000 bits. What is the throughput of the network?
  • A. 1 Mbps
  • B. 2 Mbps ✓
  • C. 4 Mbps
  • D. 120 Mbps
Answer: B — 2 Mbps
$\text{Throughput} = \frac{30,000 \times 4,000\text{ bits}}{60\text{ sec}} = \frac{120,000,000}{60} = 2,000,000\text{ bps} = \mathbf{2\text{ Mbps}}$.
PYQ 07 Differential Manchester
In Differential Manchester encoding, how is a binary '0' distinguished from a binary '1'?
  • A. Binary '0' has a transition at the start of the bit period; binary '1' has none ✓
  • B. Binary '1' has a transition at the start; binary '0' has none
  • C. Binary '0' has no mid-bit transition
  • D. Binary '1' uses zero voltage
Answer: A
In Differential Manchester, both 0 and 1 have a mid-bit transition for clocking. Binary 0 has an additional transition at the *start* of the bit period, while binary 1 has no transition at the start.
PYQ 08 NRZ-I Transition
In NRZ-I (Non-Return-to-Zero Invert) line coding, a transition in voltage level occurs when:
  • A. A binary '0' is encountered
  • B. A binary '1' is encountered ✓
  • C. At the middle of every bit
  • D. Only at the end of frame
Answer: B — Binary '1'
NRZ-I inverts the voltage level whenever a binary 1 is encountered; binary 0 results in no change in voltage level.
PYQ 09 Baud Rate Definition
Baud rate is defined as the number of:
  • A. Bits transmitted per second
  • B. Signal elements (symbols) transmitted per second ✓
  • C. Bytes transmitted per second
  • D. Packets routed per second
Answer: B — Signal elements per second
Bit rate is bits/sec ($N$). Baud rate is signal elements/sec ($S$).
PYQ 10 Baseline Wandering
Which issue occurs in line coding when a long stream of consecutive 0s or 1s causes the average signal level to drift?
  • A. Baseline Wandering ✓
  • B. Crosstalk
  • C. Modal Dispersion
  • D. Thermal Noise
Answer: A — Baseline Wandering
Baseline wandering happens when long sequences of identical bits shift the receiver's baseline reference voltage, causing bit decoding errors.
