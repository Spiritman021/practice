5.1 What is a Brute Force Attack?

A Brute Force Attack is a trial-and-error method used by attackers to guess credentials, encryption keys, or sensitive tokens by systematically testing every possible combination until the correct one is discovered.

⚡ Exhaustive Key Space Search

The attacker attempts combinations sequentially (e.g. 0000, 0001, 0002... or aaaa, aaab...). Guaranteeing success if given unlimited time and compute resources.

🎯 Target Vulnerabilities

Short passwords, simple alphanumeric patterns (e.g. password123), un-throttled authentication endpoints, and lack of multi-factor authentication (MFA).

5.2 Dictionary Attack & Automated Penetration Tools

A Dictionary Attack is a specialized, optimized variant of a brute force attack. Instead of trying every theoretical combination of letters and digits, it uses a pre-defined wordlist of common passwords, dictionary words, and leaked credential databases (e.g. rockyou.txt) to compromise accounts significantly faster.

Attack Type Search Strategy Speed & Efficiency Success Determinant
Full Brute Force Attack Tries ALL possible character permutations ($A-Z, a-z, 0-9, \text{symbols}$). Slow (computationally expensive for long keys). Guaranteed to find key eventually (if space is finite).
Dictionary Attack Tries pre-compiled lists of words & leaked passwords (e.g. admin, 123456). Very Fast (targeted small search space). Succeeds if victim uses common/predictable passwords.

🛠️ Common Penetration Testing Tools

  • THC-Hydra: Fast network login cracker supporting HTTP-GET, HTTP-POST, SSH, FTP, Telnet, MySQL, etc.
  • Burp Suite (Intruder): Popular web app security tool used for automated custom payload brute forcing against web forms and APIs.
  • Hashcat / John the Ripper: High-speed offline password hash cracking software using GPU acceleration.

5.3 4 Core Defense Mitigation Techniques

The PDF slide highlights 4 primary defensive measures to prevent and mitigate brute force attacks:

🔒

1. Account Lockouts

Locks user account temporarily (e.g. for 30 minutes) or permanently after 3–5 consecutive failed login attempts.

🧩

2. CAPTCHA Verification

Completely Automated Public Turing test to tell Computers and Humans Apart. Blocks automated bot scripts.

📱

3. Multi-Factor Auth (MFA)

Requires TOTP/SMS OTP or hardware security key; rendering correct password useless without 2nd factor.

⏱️

4. Rate Limiting

Restricts total HTTP login requests allowed per IP address/session within a specified timeframe (e.g. max 5 req/min).

5.4 Step-by-Step Key Space Mathematical Calculation ($62^6$)

📝 PDF Slide Problem Statement

"How many attempts would it theoretically take, on average, to brute-force a 6-character alphanumeric password, assuming each character can be a letter (52 possibilities: 26 lowercase + 26 uppercase) or a digit (10 possibilities: 0 to 9)?"

Step 1: Determine Total Character Set Possibilities ($N$)
$$\text{Letters (A-Z, a-z)} = 52$$ $$\text{Digits (0-9)} = 10$$ $$N = 52 + 10 = 62 \text{ possibilities per position}$$
Step 2: Calculate Total Key Space / Total Combinations ($S$)
$$\text{Password Length } L = 6$$ $$S = N^L = 62^6$$ $$S = 62 \times 62 \times 62 \times 62 \times 62 \times 62 = 56,800,235,584 \text{ combinations}$$ $$\approx 56.8 \text{ billion total combinations}$$
Step 3: Calculate Theoretical Average Attempts ($A_{avg}$)

For a uniform probability distribution across key space, the average number of attempts needed to find the correct password is half of the total search space ($\frac{S}{2}$):

$$A_{avg} = \frac{S}{2} = \frac{62^6}{2} = \frac{56,800,235,584}{2}$$ $$\mathbf{A_{avg} = 28,400,117,792 \text{ attempts} \approx 28.4 \text{ billion attempts}}$$

5.6 Quick Exam Revision Cheat Sheet

1. Brute Force Attack: Exhaustive search testing all character combinations ($N^L$).

2. Dictionary Attack: Uses pre-defined wordlists (e.g., rockyou.txt) to guess common passwords faster.

3. Tools: Hydra, Burp Suite (Intruder), Hashcat, John the Ripper.

4. Key Space Formula: Total combinations $S = N^L$. Average attempts $A_{avg} = \frac{N^L}{2}$. For 6-char alphanumeric ($52+10=62$), $S = 62^6 = 56.8 \text{ billion}$, $A_{avg} = 28.4 \text{ billion}$.
