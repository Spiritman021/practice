Algorithm Basics, Complexity & Master Theorem TOP PRIORITY 🔥
Big-O hierarchy, best/worst/average/amortized, Master Theorem
Algorithm: A finite sequence of unambiguous, well-defined computational steps that transforms input into output.
Properties: Input, Output, Definiteness, Finiteness, Effectiveness.
Asymptotic Complexity Order of Growth 🔥
O(1) < O(log n) < O(√n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
Amortized Analysis (Dynamic Array Doubling) ⭐

Average cost per operation over a sequence of operations. In a dynamic array (e.g. ArrayList/Vector), appending is normally O(1). When full, it doubles size and copies all $n$ items (costs $O(n)$). Because doubling occurs geometrically rarely, the amortized cost per insertion remains $O(1)$.

Master Theorem for Divide & Conquer Recurrences ⭐

For $T(n) = aT(n/b) + f(n)$ with $a \ge 1, b > 1$:
• If $f(n) = O(n^{\log_b a - \epsilon}) \implies T(n) = \Theta(n^{\log_b a})$
• If $f(n) = \Theta(n^{\log_b a}) \implies T(n) = \Theta(n^{\log_b a} \log n)$
• If $f(n) = \Omega(n^{\log_b a + \epsilon}) \implies T(n) = \Theta(f(n))$
Example: Merge Sort $T(n) = 2T(n/2) + O(n) \implies O(n \log n)$.

Linked List & Floyd's Cycle Detection TOP PRIORITY 🔥
Singly, Doubly, Circular LL & Tortoise-Hare Algorithm
Linked List: Dynamic linear collection of non-contiguous nodes where each node contains Data + Pointer(s).
TypeStructureKey Features
Singly Linked ListHead → [Data|Next] → [Data|Next] → NULLUnidirectional traversal; insertion/deletion at head is $O(1)$.
Doubly Linked ListNULL ← [Prev|Data|Next] ⇄ [Prev|Data|Next] → NULLBidirectional traversal; deletion of a given node reference is $O(1)$. Extra pointer overhead.
Circular Linked ListLast node's next points back to HeadNo NULL pointers; useful in round-robin schedulers.
🔑 Floyd's Cycle Detection (Tortoise and Hare Algorithm) ⭐⭐
Use two pointers: slow (advances 1 step) and fast (advances 2 steps).
• If slow == fast at any point → Cycle Exists ✓
• If fast == NULL or fast->next == NULL → No Cycle ✘
Complexity: Time $O(n)$, Space $O(1)$.

Stack (LIFO) & Applications TOP PRIORITY 🔥
Last In First Out, push/pop, Infix to Postfix, Parentheses matching
Stack: Linear LIFO (Last In, First Out) data structure. All insertions and deletions occur exclusively at the single end called Top. All operations (push, pop, peek) take O(1) time.
Key Applications of Stack
  • Function Call Stack & Recursion management.
  • Expression Evaluation & Conversion: Infix → Postfix (Reverse Polish), Infix → Prefix.
  • Balanced Parentheses Checking: Validating compiler syntax.
  • Undo / Redo operations in editors & Browser back/forward history.
  • Graph Depth First Search (DFS).
⚠ Overflow vs Underflow
Stack Overflow: Attempting to push into an already full stack.
Stack Underflow: Attempting to pop from an empty stack (top == -1).

Queue (FIFO) & Queue Types TOP PRIORITY 🔥
First In First Out, Simple, Circular, Deque, Priority Queue
Queue: Linear FIFO (First In, First Out) structure. Elements inserted at Rear (Enqueue) and removed from Front (Dequeue). Both operations take O(1) time.
Queue TypeMechanismKey Conditions & Notes
Simple Linear QueueFIFO order in array/LLSuffers from false overflow in linear arrays when rear reaches end.
Circular Queue ⭐Last position wraps around to first using modulo arithmeticEmpty: front == -1
Full: (rear + 1) % size == front
Deque (Double-Ended Queue)Insertion and deletion permitted at both ends (Front and Rear)Supports both stack and queue abstractions.
Priority Queue ⭐Elements served by highest/lowest priority, not arrival orderImplemented using Binary Heap (Insert $O(\log n)$, Extract Min/Max $O(\log n)$).

Recursion & Tail Recursion
Base case, call stack, Tail Call Optimization (TCO)
Recursion: Process where a function calls itself directly or indirectly. Requires a Base Case (termination condition) and a Recursive Step. Uses the system Call Stack; missing base case causes Stack Overflow.
🔑 Tail Recursion & TCO ⭐
A recursive function is Tail Recursive if the recursive call is the very last operation performed (no pending computation like addition/multiplication after return).
Compilers can apply Tail Call Optimization (TCO) to convert tail-recursive calls into iterative jumps, reusing the existing stack frame and executing in O(1) auxiliary space.

Hashing & Collision Resolution HIGH YIELD
Chaining vs Open Addressing (Linear, Quadratic, Double Hashing), Load Factor
Hashing: Maps arbitrary keys to fixed table indices using a Hash Function ($h(k) = k \pmod m$). Average lookup/insert: O(1); Worst case: $O(n)$.
Separate Chaining (Open Hashing)

Each bucket stores a linked list of entries colliding at that index. Never fills up; handles $lpha > 1$.

Open Addressing (Closed Hashing)

All entries stored inside array itself. If collision occurs, probe for next empty slot ($lpha \le 1$).

Probing Methods in Open Addressing
  • Linear Probing: $h(k, i) = (h'(k) + i) \pmod m$. Suffers from Primary Clustering (long contiguous occupied blocks).
  • Quadratic Probing: $h(k, i) = (h'(k) + c_1 i + c_2 i^2) \pmod m$. Reduces primary clustering; suffers from Secondary Clustering.
  • Double Hashing ⭐: $h(k, i) = (h_1(k) + i \cdot h_2(k)) \pmod m$. Best open addressing method; eliminates clustering.
🔑 Load Factor (α) & Rehashing
$lpha = rac{ ext{Number of elements } n}{ ext{Table size } m}$. When $lpha$ exceeds threshold (e.g. 0.75), Rehashing doubles table size and re-maps all keys.

Tree Terminology & Properties
Root, Leaf, Degree, Height, Depth, Formula: n - 1 edges
  • Root: Topmost node without parent. Leaf Node: Node with degree 0 (no children).
  • Degree of Node: Number of children of that node. Degree of Tree: Maximum degree among all nodes.
  • Depth of Node: Number of edges from root to that node (Root depth = 0).
  • Height of Tree: Length of longest path from root to any leaf node.
  • Golden Tree Formula 🔥: A tree with $n$ nodes has exactly $n - 1$ edges.

Binary Tree Types & Formulas TOP PRIORITY 🔥
Full, Complete, Perfect, Skewed Trees & Node Formulas
Binary Tree TypeDefinition & Identifying Property
Full (Strict) Binary TreeEvery node has either 0 or 2 children (no node has 1 child).
Complete Binary Tree ⭐All levels filled completely except possibly the last, and the last level is filled strictly from left to right. (Used in Binary Heaps).
Perfect Binary TreeAll internal nodes have 2 children and all leaves are at the exact same level. Max nodes at height $h$: $2^{h+1} - 1$.
Degenerate / Skewed TreeEvery parent has only 1 child. Degenerates into a linked list ($O(n)$ search).
🔑 Full Binary Tree Theorem
In any non-empty full binary tree: Number of Leaf Nodes ($L$) = Number of Internal Nodes ($I$) + 1  ($L = I + 1$).

Binary Heap & Priority Queue TOP PRIORITY 🔥
Max Heap, Min Heap, Array Index Formulas, Heapify O(n)
Binary Heap: A Complete Binary Tree satisfying Heap Order Property.
• Max Heap: Parent key ≥ Children keys (Root = Global Maximum).
• Min Heap: Parent key ≤ Children keys (Root = Global Minimum).
0-Based Array Representation Formulas 🔥
For a node at index i: Left Child Index = 2i + 1 Right Child Index = 2i + 2 Parent Node Index = ⌊(i - 1) / 2⌋
🔑 Complexities
• Build Heap (Heapify): $O(n)$ time.
• Insert / Extract Min/Max: $O(\log n)$ time.

Graph Basics & Handshaking Lemma
Vertices, Edges, Degree, Handshaking Theorem
Graph $G = (V, E)$: Non-linear structure consisting of a set of vertices (nodes) and edges (connections).
🔑 Handshaking Lemma (Undirected Graphs)
$\sum_{v \in V} ext{deg}(v) = 2 |E|$  (Sum of degrees of all vertices is twice the number of edges).
Corollary: In any graph, the number of vertices with odd degree is always even.

BFS (Breadth-First Search) ⭐⭐
Queue based, level-by-level, unweighted shortest path
BFS: Explores neighbor nodes at current depth level before moving to nodes at next depth level. Uses a Queue.
Time Complexity: O(V + E) | Space Complexity: $O(V)$
Applications: Shortest path in unweighted graphs, level-order traversal, web crawler, finding connected components.

DFS (Depth-First Search) ⭐⭐
Stack / Recursion based, backtracking, cycle detection
DFS: Plunges deep down along a path before backtracking. Uses a Stack / Recursion.
Time Complexity: O(V + E) | Space Complexity: $O(V)$
Applications: Cycle detection (directed & undirected), Topological Sorting, finding Strongly Connected Components, Maze pathfinding.

Spanning Tree Concepts
Connected subgraph, no cycles, V - 1 edges
A Spanning Tree of a connected undirected graph $G=(V, E)$ is an acyclic subgraph containing all $V$ vertices and exactly $V - 1$ edges. For a complete graph $K_n$, total spanning trees = $n^{n-2}$ (Cayley's Formula).

Topological Sorting (DAG) ⭐⭐
Directed Acyclic Graphs, Kahn's Algorithm (Indegrees + Queue)
Topological Sort: Linear ordering of vertices in a Directed Acyclic Graph (DAG) such that for every directed edge $u o v$, vertex $u$ comes before $v$.
Condition: Graph MUST be a DAG (cyclic graph has NO topological ordering).
  • Kahn's Algorithm (BFS-based): Computes in-degrees of all vertices. Pushes 0-indegree nodes into Queue. Decrements neighbor in-degrees on dequeue. Complexity: O(V + E).
  • DFS-based: Push vertex onto stack after visiting all its descendants; pop stack at end.
  • Applications: Build dependency resolution (Makefiles), task scheduling, course prerequisites.
24
Greedy Algorithms & Huffman Coding
Locally optimal choices, Fractional Knapsack, Huffman Tree
Greedy Paradigm: Makes the locally optimal choice at each step hoping it leads to a global optimum. Fast, but does NOT always guarantee global optimum.
  • Works for: Fractional Knapsack, Prim's, Kruskal's, Dijkstra's, Activity Selection, Job Sequencing.
  • FAILS for: 0/1 Knapsack Problem (requires Dynamic Programming).
🔑 Huffman Coding (Data Compression) ⭐
Builds an optimal prefix-free code using a Min-Heap. Repeatedly merges two lowest-frequency characters into a parent node. Higher frequency characters get shorter binary codes. Complexity: O(n log n).

Backtracking Paradigm
Choose → Explore → Undo (Pruning state space trees)
Backtracking: Systematic search through state-space tree. Builds candidates incrementally and abandons/undoes ("backtracks") a candidate as soon as it cannot lead to a valid solution.
Classic Problems: N-Queens, Sudoku Solver, Rat in a Maze, Subset Sum, Graph Hamiltonian Cycle.

Trie (Prefix Tree)
Fast string retrieval, autocomplete, dictionary lookups
Trie: Multi-way tree structure where each node represents a character of a string. Edges represent characters, and paths from root to leaf represent words.
Search / Insert Time: O(L) where $L$ = length of the word (independent of the number of words stored).
Applications: Autocomplete, Spell checkers, IP routing longest-prefix lookup.

Bit Manipulation Tricks & Kernighan's Algorithm
XOR properties, power-of-2 test, Brian Kernighan set bits count
Crucial XOR Tricks ⭐

• $a \oplus a = 0$
• $a \oplus 0 = a$
• $a \oplus b \oplus b = a$ (Finds single non-repeating element)

Power of 2 & Low Bit Clear

Check power of 2: n > 0 && (n & (n - 1)) == 0
Clear lowest set bit: n & (n - 1)

🔑 Brian Kernighan's Set Bit Counting Algorithm
Loop n = n & (n - 1) until $n = 0$. Number of iterations equals the exact count of set bits (1s) in binary representation. Complexity: O(number of set bits).
32
Disjoint Set Union (Union-Find) ⭐⭐
Path Compression, Union by Rank, O(α(n)) Amortized Time
Disjoint Set (Union-Find): Maintains partition of $n$ elements into disjoint sets. Operations: Find(x) (finds set representative) and Union(x, y) (merges two sets).
  • Path Compression: Flattens tree during find by pointing all visited nodes directly to the root.
  • Union by Rank / Size: Attaches smaller depth tree under root of larger depth tree.
  • With both optimizations: Amortized time per operation is nearly constant: O(α(n)) (Inverse Ackermann function $\le 4$ for all practical $n$).
  • Used in: Kruskal's MST algorithm, cycle detection in undirected graphs.

Core Algorithmic Techniques (Two Pointer, Sliding Window, Kadane's) NEW ⭐
O(n) linear optimization patterns for subarrays and pairs
Two Pointer Technique

Two index pointers moving inward or at different speeds. Solves pair sum in sorted array in O(n) instead of $O(n^2)$.

Sliding Window

Maintains contiguous range $[L, R]$ that expands/shrinks dynamically to find maximum sum or unique substrings in O(n).

Kadane's Algorithm ⭐

Finds maximum sum contiguous subarray in a single pass: curr_max = max(A[i], curr_max + A[i]) in O(n) time.

NP-Complete ⭐Hardest problems in NP. Problem $X$ is NP-Complete if: 1. $X \in ext{NP}$ and 2. Every problem in NP reduces to $X$ in polynomial time.Circuit-SAT, 3-SAT, Traveling Salesperson Decision, Vertex Cover, Hamiltonian Path
NP-HardAt least as hard as NP-Complete problems, but does not need to be in NP (not necessarily a decision problem).Halting Problem, TSP Optimization version
🧠 P vs NP Core Question
Is every problem whose solution can be verified quickly also solvable quickly? (Currently unsolved Millennium Prize problem).
