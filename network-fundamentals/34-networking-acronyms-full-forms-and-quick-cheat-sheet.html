IBPS SO IT High-Yield One-Liner Exam Facts

#High-Yield Fact / One-LinerTopic / Category
1Minimum size of an Ethernet frame is 64 Bytes; Maximum size (MTU) is 1518 Bytes (or 1522 Bytes with 802.1Q VLAN tag).Data Link Layer
2Maximum hop count supported by RIP is 15 Hops (16 Hops signifies infinity / unreachable destination).Routing Protocols
3Standard size of a fixed IPv4 Header is 20 Bytes (maximum 60 Bytes with Options).IPv4 Protocol
4Fixed size of an IPv6 Header is 40 Bytes. Checksum field is completely removed in IPv6.IPv6 Protocol
5Fixed size of a UDP Header is 8 Bytes (Source Port, Destination Port, Length, Checksum).Transport Layer
6Standard size of a fixed TCP Header is 20 Bytes (maximum 60 Bytes with Options).Transport Layer
748-bit MAC Address is written in 12 Hexadecimal digits (e.g., 00:1A:2B:3C:4D:5E). First 24 bits = OUI (Vendor ID).Data Link Layer
8ARP resolves IP address to MAC address; RARP resolves MAC address to IP address.Network Layer
9ICMP Ping uses Type 8 (Echo Request) and Type 0 (Echo Reply).ICMP Protocol
10Traceroute operates by sending packets with incrementing TTL values starting at TTL = 1. Router drops packet and sends ICMP Type 11 (Time Exceeded).ICMP Protocol
11Class A Private IP: 10.0.0.0/8 | Class B Private IP: 172.16.0.0/12 | Class C Private IP: 192.168.0.0/16.IP Addressing
12Loopback IP address range is 127.0.0.0/8 (specifically 127.0.0.1 localhost).IP Addressing
13APIPA (Automatic Private IP) range is 169.254.0.0/16 (used when DHCP fails).IP Addressing
14TCP 3-Way Handshake control flag sequence: SYN → SYN-ACK → ACK.TCP Handshake
15TCP 4-Way Termination control flag sequence: FIN → ACK → FIN → ACK.TCP Termination
16TIME_WAIT state duration in TCP connection teardown is equal to 2 × MSL (Maximum Segment Lifetime).TCP States
17Dijkstra's Shortest Path First (SPF) algorithm is used in Link-State Routing Protocols (OSPF).Routing Algorithms
18Bellman-Ford algorithm is used in Distance-Vector Routing Protocols (RIP). Count-to-Infinity is a major issue!Routing Algorithms
19BGP (Border Gateway Protocol) is an Exterior Gateway Protocol (EGP) based on Path-Vector routing operating over TCP Port 179.Routing Protocols
20DHCP uses 4-step DORA process: Discover (Broadcast) → Offer (Unicast) → Request (Broadcast) → Acknowledge (Unicast).Application Layer
21DNS operates over UDP Port 53 for standard queries and TCP Port 53 for Zone Transfers.Application Layer
22FTP uses TCP Port 21 for Control/Commands and TCP Port 20 for Data Transfer.Application Layer
23SMTP is used to send/push email; POP3 (download/delete) and IMAP (sync) are used to retrieve email.Application Layer
24Telnet sends data in unencrypted plaintext (Port 23); SSH uses encrypted tunneling (Port 22).Application Layer
25SNMP uses UDP Port 161 for Manager Polling and UDP Port 162 for Unsolicited Traps.Application Layer
26A Hub has 1 Collision Domain & 1 Broadcast Domain; A Switch has N Collision Domains & 1 Broadcast Domain; A Router has N Collision & N Broadcast Domains.Network Devices
27CSMA/CD is used in wired Ethernet; CSMA/CA (with RTS/CTS) is used in wireless Wi-Fi.Medium Access Control
28Hamming Code parity bits formula: 2r ≥ m + r + 1 where m is data bits and r is parity bits.Error Correction
29Nyquist Max Data Rate formula: Bit Rate = 2 × B × log2(V); Shannon Capacity: C = B × log2(1 + SNR).Channel Capacity
30Bandwidth-Delay Product formula: BDP = Bandwidth (bps) × RTT (sec). Represents max bits in flight.Network Performance
