Section 3.1

Introduction to Topology

A network topology defines the arrangement or layout of elements (nodes, links) of a computer network. It is a critical design decision that affects performance, fault tolerance, scalability, and cost.

Types of Topology

  • Physical Topology: The actual physical layout — how cables, devices, and connections are physically arranged in space.
  • Logical Topology: How data flows through the network, regardless of physical layout. (e.g., a network can be physically a star but logically a bus.)
📌
Key Concept
The topology affects: cost of cabling, ease of installation, fault isolation, scalability, and performance under load. Choosing the right topology is essential for efficient network design.
Bus Bus Topology
Cable
Single coaxial (backbone)
Standard
IEEE 802.3 (10BASE2, 10BASE5)
Status
Obsolete (historical)

In a Bus Topology, all devices are connected to a single central cable called the backbone or bus. Data transmitted by any device travels along the entire bus in both directions and is received by all devices. Only the intended recipient accepts the data; others ignore it.

Terminators are placed at both ends of the bus to prevent signal reflection. If the bus cable breaks, the entire network fails.

How it Works

  • All devices share the same medium (bus). Only one device can transmit at a time.
  • CSMA/CD (Carrier Sense Multiple Access with Collision Detection) is used to manage access.
  • Data travels in both directions from the sender along the bus.
  • Each NIC reads all packets but only processes packets addressed to it.

Advantages

  • Simple and inexpensive to install
  • Requires less cable than star/mesh
  • Easy to connect new devices
  • Well-suited for small networks

Disadvantages

  • Single point of failure (bus breaks → network fails)
  • Performance degrades with more devices
  • Difficult to troubleshoot
  • Limited cable length and number of nodes
  • Not scalable
Star Star Topology
Central Device
Hub or Switch
Cable
Twisted pair / Fiber per device
Status
Most widely used today

In a Star Topology, all devices are connected individually to a central hub, switch, or access point. Every communication between devices goes through this central device. The central node manages traffic and provides dedicated connections.

This is the most popular topology used in modern LANs — from home Wi-Fi routers to office Ethernet networks.

How it Works

  • Each device has a dedicated point-to-point link to the central hub/switch.
  • With a hub: Data received is broadcast to all ports (collision domain shared).
  • With a switch: Data is forwarded only to the destination port (each port is its own collision domain).
  • Failure of one device does not affect others — only the link between that device and the center is lost.

Advantages

  • Easy to install and manage
  • Fault isolation — one failure doesn't affect others
  • Easy to add/remove devices
  • High performance with switch (dedicated bandwidth)
  • Centralised monitoring

Disadvantages

  • Central hub/switch failure = entire network down
  • More cable required than bus
  • Cost increases with the number of devices
  • Performance limited by central device capacity
Ring Ring Topology
Direction
Unidirectional (usually)
Access Method
Token Passing
Standard
IEEE 802.5 (Token Ring), FDDI

In a Ring Topology, each device is connected to exactly two other devices, forming a closed loop (ring). Data travels in one direction (unidirectional) around the ring from node to node. Each device acts as a repeater to boost the signal before passing it to the next device.

Access is controlled by a token — a special signal that circulates around the ring. Only the device holding the token can transmit data (Token Ring protocol).

Dual Ring

A Dual Ring (used in FDDI) has two rings — one for primary data flow and one as a backup. If the primary ring fails, the backup ring takes over, providing fault tolerance.

Advantages

  • No collisions (token controls access)
  • Performance is predictable under load
  • Equal access for all devices
  • Dual ring provides fault tolerance

Disadvantages

  • Single node failure can disrupt entire ring
  • Difficult to add/remove devices
  • Slow for large networks (token must circle)
  • Troubleshooting is complex
Mesh Mesh Topology
Links (Full Mesh)
n(n-1)/2 for n nodes
Types
Full Mesh, Partial Mesh
Used In
WAN, critical infrastructure

In a Mesh Topology, every device is connected to every other device in the network. This provides multiple paths between any two devices, ensuring maximum redundancy and fault tolerance. There are two types:

  • Full Mesh: Every node connects to every other node. For n nodes: links = n(n-1)/2. Extremely redundant but very expensive.
  • Partial Mesh: Some nodes are fully connected; others connect to only some nodes. Balances cost and redundancy.
📐
Formula
For a Full Mesh with n nodes:
• Number of links = n(n-1)/2
• Input/output ports per device = (n-1)
Example: 5 nodes → 10 links; 10 nodes → 45 links!

Advantages

  • Maximum redundancy and fault tolerance
  • Multiple paths between nodes
  • Traffic can be distributed (load balanced)
  • Failure of one link doesn't affect network
  • Privacy (dedicated links)

Disadvantages

  • Extremely expensive — huge cabling cost
  • Complex installation and management
  • Each device needs many ports
  • Impractical for large networks
Tree Tree Topology
Structure
Hierarchical (Star of Stars)
Root Node
Central backbone switch/router
Used In
Enterprise, campus networks

A Tree Topology (also called Hierarchical Topology) combines characteristics of Bus and Star topologies. It has a root node (the top-level device), which connects to intermediate nodes (secondary hubs/switches), which in turn connect to leaf nodes (end devices). It looks like an inverted tree.

Advantages

  • Scalable — easy to add branches
  • Fault isolation at segment level
  • Hierarchical management
  • Suitable for large organisations

Disadvantages

  • Root node failure affects all
  • Heavy dependency on trunk cable
  • Complex cabling
  • More expensive than bus
Hybrid Hybrid Topology
Composition
Combination of 2+ topologies
Flexibility
Very High
Used In
Real-world enterprise networks

A Hybrid Topology is a combination of two or more different types of topologies. Most real-world networks use hybrid topologies because no single topology perfectly fits all requirements. For example, a large enterprise might use a star topology within each department (floor) and connect departments using a ring or mesh backbone.

Common Hybrid Combinations

  • Star-Bus: Multiple star networks connected to a bus backbone.
  • Star-Ring: Star clusters connected via a ring backbone (common in enterprise).
  • Star-Mesh: Star LANs at branches connected via mesh WAN for redundancy.

Advantages

  • Highly flexible and scalable
  • Combines best features of each topology
  • Suitable for large, complex networks
  • Fault isolation at topology boundaries

Disadvantages

  • Complex design and management
  • Higher cost
  • Difficult to troubleshoot
  • Requires skilled network engineers
