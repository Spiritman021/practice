📦 Section 1: Stack Fundamentals & TOS (Top of Stack) State

A Stack is a linear, restricted data structure following the LIFO (Last In First Out) or FILO (First In Last Out) principle. All insertions (Push) and deletions (Pop) take place at a single end called the TOS (Top of Stack).

Initial Empty State: TOS = -1 (0-indexed array size n)
Stack Full (Overflow): TOS == n - 1
Stack Empty (Underflow): TOS == -1
TOS Pointer Movement Rules:
  • Push Operation: First increment TOS++, then insert element a[TOS] = x.
  • Pop Operation: First extract element x = a[TOS], then decrement TOS--.
  • Peek / Top Operation: Return a[TOS] without modifying TOS.

Complete Stack Implementation (C, Java, Python):

#include <stdio.h> #define MAX 5 int stack[MAX]; int Top = -1; // TOS initially starts from -1 void Push(int x) { if (Top == MAX - 1) { printf("Stack Overflow!\n"); } else { Top++; stack[Top] = x; } } int Pop() { if (Top == -1) { printf("Stack Underflow!\n"); return -1; } else { int x = stack[Top]; Top--; return x; } }
public class StackArray { private int[] stack; private int top; private int capacity; public StackArray(int size) { capacity = size; stack = new int[capacity]; top = -1; // TOS initially starts from -1 } public void push(int x) { if (top == capacity - 1) { System.out.println("Stack Overflow!"); return; } stack[++top] = x; } public int pop() { if (top == -1) { System.out.println("Stack Underflow!"); return -1; } return stack[top--]; } }
class Stack: def __init__(self, capacity): self.capacity = capacity self.stack = [] self.top = -1 # TOS initially starts from -1 def push(self, x): if self.top == self.capacity - 1: print("Stack Overflow!") return self.top += 1 self.stack.append(x) def pop(self): if self.top == -1: print("Stack Underflow!") return None self.top -= 1 return self.stack.pop()
⏳ Section 2: How to Find Average Lifetime of an Element in Stack

The Lifetime of an element $k$ is the total elapsed time from the instant element $k$ is pushed onto the stack ($\text{Push}(k)$) until the instant it is popped off the stack ($\text{Pop}(k)$).

Lifetime(k) = Time after Push(k) and before Pop(k)
Let x = Execution time per stack operation (Push/Pop)
Let y = Elapsed time between consecutive operations

🔥 Solved Example (3 Elements Pushed & Popped: a, b, c):

Sequence of operations: $\text{Push}(a), \text{Push}(b), \text{Push}(c), \text{Pop}(c), \text{Pop}(b), \text{Pop}(a)$.

  • Element $c$ (Topmost element):
    Between $\text{Push}(c)$ and $\text{Pop}(c)$, there is only 1 time gap $y$.
    $$\text{Lifetime}(c) = y$$
  • Element $b$ (Middle element):
    Between $\text{Push}(b)$ and $\text{Pop}(b)$, 2 operations occur ($\text{Push}(c)$ & $\text{Pop}(c)$ taking $2x$) and 3 time gaps ($3y$).
    $$\text{Lifetime}(b) = 2x + 3y$$
  • Element $a$ (Bottommost element):
    Between $\text{Push}(a)$ and $\text{Pop}(a)$, 4 operations occur ($2\text{Push} + 2\text{Pop} = 4x$) and 5 time gaps ($5y$).
    $$\text{Lifetime}(a) = 4x + 5y$$

Total Lifetime:

$$\text{Total} = \text{LT}(c) + \text{LT}(b) + \text{LT}(a) = y + (2x + 3y) + (4x + 5y) = 6x + 9y$$

Average Lifetime of an Element:

$$\text{Average Lifetime} = \frac{6x + 9y}{3} = \mathbf{2x + 3y}$$

If $x = 3$ units and $y = 4$ units: Average Lifetime = $2(3) + 3(4) = 6 + 12 = 18$ units.

General Formula for $n$ Pushed Elements:

For $n$ elements pushed sequentially and popped in reverse order:

$$\text{Average Lifetime} = (n - 1) x + n \cdot y \quad \text{(or } (n-1)(x+y) + y\text{)}$$
🧮 Section 3: Infix, Postfix & Prefix Conversion & Evaluation

Operator Precedence & Associativity Table:

Operator Description Precedence Associativity
^ or $ Exponentiation Highest (3) Right to Left ($\text{R} \to \text{L}$)
*, /, % Multiplication, Division, Modulo Medium (2) Left to Right ($\text{L} \to \text{R}$)
+, - Addition, Subtraction Lowest (1) Left to Right ($\text{L} \to \text{R}$)

🔥 Postfix Evaluation Algorithm using Stack:

  1. Scan expression left to right.
  2. If token is an operand (number), Push(operand) onto stack.
  3. If token is an operator ($op$), val2 = Pop(), val1 = Pop(). Compute result = val1 op val2 and Push(result).
  4. Final answer is at Pop().
🎯 IBPS SO IT PYQ Pattern Verification
  • TOS Initial Pointer State: When implementing stack using a 0-indexed array of size $n$, empty stack has TOS = -1. First push increments TOS to 0.
  • Time Complexities: Push, Pop, Peek, isEmpty, isFull all execute in O(1) time complexity.
  • Average Lifetime Formula: Remember $\text{Lifetime}(k) = \text{Push}(k) \to \text{Pop}(k)$ time span.
