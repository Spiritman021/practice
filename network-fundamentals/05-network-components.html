Section 5.1

Introduction & OSI Layer Context

Every network component operates at a specific layer of the OSI (Open Systems Interconnection) model. Understanding which layer a device operates at tells you what intelligence it has — what information it can read and act upon in a packet.

A Network Interface Card (NIC) is the hardware component that physically connects a computer to a network. Every device that can connect to a network must have a NIC. It operates at both Layer 1 (physical — handling electrical signals) and Layer 2 (data link — handling MAC addresses and framing).

Key Functions

  • MAC Address: Each NIC has a globally unique 48-bit MAC (Media Access Control) address burned into its ROM. Format: 00:1A:2B:3C:4D:5E. First 24 bits = manufacturer OUI; last 24 bits = device ID.
  • Data Encoding: Converts digital data into electrical signals (wired) or radio waves (wireless) for transmission.
  • Framing: Assembles data into frames for transmission; receives and strips frame headers on receipt.
  • Media Access Control: Implements CSMA/CD (Ethernet) or CSMA/CA (Wi-Fi) to manage who transmits when.
  • Buffering: Temporarily stores incoming/outgoing data to handle speed mismatches.
📌
MAC vs IP Address
MAC address = permanent hardware address (Layer 2), used within the LAN. IP address = logical software address (Layer 3), used for internet routing. ARP (Address Resolution Protocol) maps IP → MAC within a LAN.

A repeater is the simplest networking device, operating at the Physical Layer (Layer 1). Over long distances, electrical signals weaken (attenuation). A repeater receives the weakened signal, regenerates/amplifies it back to full strength, and retransmits it — extending the effective range of the cable.

Key Characteristics

  • No intelligence: Cannot read MAC or IP addresses. Simply boosts the signal bit-by-bit.
  • No filtering: Forwards all signals including errors and broadcast storms.
  • Single collision domain: Both segments connected by a repeater are in the same collision domain.
  • Maximum usage: Ethernet 10BASE5 allows maximum 4 repeaters in a network segment (5-4-3 rule).
  • Modern equivalence: Wi-Fi Range Extenders / Boosters are modern wireless repeaters.

A Hub is a multi-port repeater — a central connecting device that takes input from one port and broadcasts it to all other ports. It has no intelligence — it cannot read MAC or IP addresses. All devices connected to a hub share the same collision domain and broadcast domain.

Types of Hubs

  • Passive Hub: Simply connects cables together; no signal amplification. Acts as a junction box.
  • Active Hub: Amplifies the signal before broadcasting to all ports. More like a multiport repeater.
  • Intelligent Hub: Has some management capability (port monitoring, traffic analysis) — a step toward switches.
⚠️
Hub vs Switch
Hubs are largely obsolete — replaced by switches. The critical problem: when PC1 sends data to PC3, ALL devices (PC2, PC4, Printer) also receive and must process it, wasting bandwidth and creating security risks. Switches fix this by forwarding only to the intended port.

A Bridge operates at Layer 2 (Data Link) and connects two or more network segments. Unlike a hub, a bridge learns MAC addresses by reading frames and building a MAC address table. It forwards frames only to the segment where the destination device is located, reducing unnecessary traffic.

How a Bridge Works

  • Learning: When a frame arrives, the bridge records the source MAC address and the port it arrived on in its MAC table.
  • Filtering: If the destination MAC is on the same segment as the source, the bridge drops the frame (no need to forward).
  • Forwarding: If the destination is on a different segment, the bridge forwards the frame to that segment only.
  • Flooding: If the destination MAC is unknown, the bridge floods the frame to all ports (except the source port).

Types of Bridges

  • Transparent Bridge (IEEE 802.1D): Standard Ethernet bridge — devices are unaware of its presence.
  • Source Routing Bridge (IEEE 802.5): Used in Token Ring networks; source specifies the route.
  • Translating Bridge: Connects different types of networks (e.g., Ethernet to Token Ring).
📌
Bridge vs Switch
A switch is essentially a multi-port bridge. A traditional bridge has 2–4 ports; a switch has 24–48+ ports. Both operate at Layer 2 and use MAC address tables. Modern switches have made bridges largely redundant.

A Switch is the most important device in a modern LAN. It is a multi-port bridge that maintains a MAC address table (CAM table) and forwards frames only to the specific port connected to the destination device. Each port is its own collision domain, and the switch provides dedicated bandwidth to each device.

Switch vs Hub – Critical Difference

  • Hub: Broadcasts to all ports. All devices in one collision domain. Half-duplex.
  • Switch: Forwards to specific port only. Each port = separate collision domain. Full-duplex possible.
  • A 24-port switch with 100 Mbps per port provides 24 × 100 Mbps = 2.4 Gbps total capacity. A 24-port hub provides only 100 Mbps shared across all 24 devices!

Types of Switches

  • Unmanaged Switch: Plug-and-play, no configuration needed. For home/small office use.
  • Managed Switch: Fully configurable — supports VLANs, QoS, port security, SNMP monitoring. For enterprise.
  • Layer 3 Switch: Can perform routing (uses IP addresses) in addition to Layer 2 switching. Faster than a traditional router for intra-VLAN routing.
  • PoE Switch: Power over Ethernet — provides electrical power to connected devices (IP phones, cameras) via Ethernet cable.

A Router is the most intelligent standard networking device. It operates at Layer 3 (Network) and is responsible for routing packets between different networks. Routers use IP addresses and routing tables to determine the best path for each packet to travel from source to destination.

Core Functions of a Router

  • Packet Forwarding: Receives packets, examines the destination IP, looks up the routing table, and forwards to the next-hop router or destination network.
  • Routing Table Maintenance: Builds and maintains a table of network prefixes and their next-hops using static routes or dynamic routing protocols (RIP, OSPF, BGP).
  • NAT (Network Address Translation): Translates private IP addresses (192.168.x.x) to a public IP — allowing many devices to share one public IP.
  • Broadcast Domain Separation: Routers do NOT forward broadcast frames — each network connected to a router is its own broadcast domain.
  • DHCP Server: Home routers often include a DHCP server to automatically assign IP addresses to connected devices.
  • Firewall: Modern routers include basic firewall functionality — packet filtering and NAT provide a degree of protection.

Routing Protocols

  • Static Routing: Routes manually configured by admin. Simple but not scalable.
  • RIP (Routing Information Protocol): Distance-vector protocol; uses hop count as metric. Simple, limited to 15 hops.
  • OSPF (Open Shortest Path First): Link-state protocol; uses Dijkstra's algorithm. Scalable, fast convergence. Enterprise standard.
  • BGP (Border Gateway Protocol): Path-vector protocol used between autonomous systems on the Internet. The backbone of internet routing.

A Gateway is the most intelligent and complex networking device. It operates at the upper layers (4–7) of the OSI model and acts as a protocol converter — it can connect networks that use completely different protocols and translate between them.

Note: In common usage, your home router is often called a "default gateway" — this means it is the router that provides access to networks outside your local LAN (typically the Internet).

Types of Gateways

  • Network Gateway (Default Gateway): The router/device that connects a LAN to the internet. In routing tables, this is the "gateway of last resort" — if no specific route matches, forward to the default gateway.
  • Email Gateway: Converts between different email protocols (e.g., SMTP to X.400 used in older systems). Spam filters are email gateways.
  • VoIP Gateway: Converts PSTN (analog telephone) signals to VoIP (digital) packets, enabling traditional phones to work with internet phone systems.
  • API Gateway: In microservices architectures, an API gateway routes HTTP requests from clients to appropriate backend services, handling authentication, rate limiting, and load balancing.
  • Cloud Storage Gateway: Bridges on-premise applications with cloud storage (e.g., AWS Storage Gateway translating SMB/NFS to S3).
📌
Key Distinction
A router routes packets within the same protocol family (IP). A gateway translates between completely different protocols — it understands the application-level semantics of both networks. This makes gateways much more computationally expensive.

A Modem (short for Modulator-Demodulator) converts digital data from your computer into signals that can travel over the medium used by your ISP (analog telephone lines, cable TV coax, fiber optic), and vice versa.

  • Modulation (Transmit): Converts outgoing digital bits → analog/carrier signal suitable for the transmission medium.
  • Demodulation (Receive): Converts incoming analog/carrier signal → digital bits for the computer.

Types of Modems

  • Dial-up Modem: Uses standard telephone lines (PSTN). Speed: 56 Kbps maximum. Obsolete today.
  • DSL Modem: Digital Subscriber Line — uses telephone lines but at higher frequencies. ADSL: ~8 Mbps down. VDSL2: up to 100 Mbps.
  • Cable Modem: Uses cable TV coaxial infrastructure. DOCSIS 3.1 standard provides Gbps speeds.
  • Fiber ONT (Optical Network Terminal): Technically not a modem (no analog conversion), but performs similar connection function for fiber-to-home.
  • 4G/5G Modem: Connects to mobile cellular networks. Used in MiFi/hotspot devices and home broadband in areas without wired infrastructure.
  • Satellite Modem: Modulates/demodulates signals for satellite internet (e.g., Starlink uses a phased-array antenna + modem).
