Section 1.1

Definition of a Computer Network

A computer network is a collection of two or more interconnected computing devices (nodes) that can communicate with each other and share resources such as data, hardware (printers, storage), and software over a communication medium.

Formally: "A computer network is an interconnection of a set of autonomous computers, terminals, and other devices, connected via communication links for the purpose of data communication and resource sharing."

Key Terms

Node / Host
Device on the Network
Any device connected to a network — computer, printer, server, smartphone, router, etc.
Link / Medium
Communication Channel
The physical or logical connection between nodes — cables (copper, fiber) or wireless (radio, satellite).
Protocol
Rules of Communication
A set of standardised rules that define how data is transmitted and received (e.g., TCP/IP, HTTP, FTP).
Bandwidth
Data Transfer Rate
The maximum rate of data transfer across the network, typically measured in bits per second (bps).

Section 1.2

Evolution & History

Computer networking has evolved from simple point-to-point communication systems to a global, interconnected internet with billions of devices.

1960s
ARPANET – Birth of Networking
Funded by US DoD, ARPANET was the first packet-switched network connecting 4 universities. The first message ("LO") was sent in 1969.
1970s
TCP/IP Protocol Developed
Vint Cerf and Bob Kahn design TCP/IP — the foundational protocol suite still powering the internet today.
1980s
Ethernet & LANs Emerge
Ethernet (IEEE 802.3) standardised in 1983. Personal computers connect via LANs in offices and universities.
1990s
World Wide Web & Internet Boom
Tim Berners-Lee invents the Web (1991). Commercial internet services boom, dial-up modems connect households worldwide.
2000s
Broadband & Wi-Fi Era
High-speed broadband replaces dial-up. IEEE 802.11 (Wi-Fi) enables wireless networking. Social media and e-commerce explode.
2010s–now
Mobile, Cloud & IoT
4G/5G, cloud computing, IoT (billions of connected devices), SD-WAN, and edge computing redefine network architectures.

Section 1.3

Goals of Computer Networks

Networks are built to achieve several fundamental goals. Understanding these goals explains why networking is so critical in modern computing.

🔗
Goal 01
Resource Sharing
The primary goal of a network is to allow all programs, data, and hardware to be available to anyone on the network regardless of the physical location of the resource. For example, multiple users can share a single printer, file server, or database. This eliminates duplication and reduces cost.
💬
Goal 02
Communication
Networks facilitate communication between people and organizations — email, instant messaging, video conferencing, VoIP calls. It supports both synchronous (real-time) and asynchronous communication. Modern collaboration tools like Teams or Zoom depend entirely on networking.
⚡
Goal 03
High Reliability
Networks provide fault tolerance by having alternative sources of supply. If one machine crashes, another can take over. Redundant links and load balancing ensure that network services remain available. RAID arrays, server clusters, and CDNs are examples.
💰
Goal 04
Cost Reduction
Sharing expensive resources (servers, storage, printers, software licenses) across many users significantly reduces costs per user. Cloud computing takes this further — pay only for what you use instead of buying dedicated hardware.
📈
Goal 05
Scalability
Networks can be easily expanded to add more nodes, users, or services without completely redesigning the existing infrastructure. New computers, servers, or devices can be plugged in without disrupting existing users.
🛡️
Goal 06
Security & Access Control
Networks implement authentication, encryption, firewalls, and access control lists to ensure that only authorized users can access sensitive resources. Centralised security policy management is easier in a networked environment.
🌍
Goal 07
Global Connectivity
Networks — especially the Internet — connect people, businesses, and governments worldwide, enabling global commerce, education, governance, research, and cultural exchange at unprecedented scale and speed.
✅

📌
Key Formula
Throughput = Amount of data transferred / Time taken (bits/second). Latency = Propagation delay + Transmission delay + Queuing delay + Processing delay.

Business Applications

  • Resource Sharing: Employees share files, printers, and databases without physically moving hardware or storage media.
  • Remote Work: VPNs and cloud apps allow employees to work from anywhere as if they are in the office.
  • Business Communication: Email, video conferencing (Zoom, Teams), and instant messaging enable fast business decisions.
  • E-Commerce: Amazon, Flipkart, and millions of online stores depend entirely on network infrastructure.
  • Supply Chain Management: Real-time tracking, inventory management, and supplier communication over networks.

Home Applications

  • Internet Access: Browsing, social media, news consumption via DSL, cable, or fiber.
  • Entertainment: Netflix, Amazon Prime, YouTube, Spotify — all rely on broadband networks.
  • Smart Home: IoT devices (smart lights, thermostats, security cameras) connected via Wi-Fi or Zigbee.
  • Person-to-person communication: WhatsApp, FaceTime, Skype calls with family and friends.

Scientific & Social Applications

  • Distributed Computing: Large scientific problems (protein folding, climate modeling) solved using distributed network clusters.
  • SETI@home: Used home computers worldwide to search for extraterrestrial intelligence.
  • Social Networks: Facebook, Twitter, Instagram — enabling global social interaction and information sharing.
  • Open Source Collaboration: GitHub enables millions of developers worldwide to collaborate on code.

Section 1.6

Advantages & Disadvantages

✅ Advantages

  • Resource sharing (hardware, software, data)
  • Reduced cost through shared infrastructure
  • Fast and reliable communication
  • Centralised data management and backups
  • Enables remote access and teleworking
  • Flexibility and scalability
  • Improved collaboration and productivity
  • Access to global information (Internet)

❌ Disadvantages

  • Security threats (hacking, malware, phishing)
  • Initial setup cost (cables, hardware, licenses)
  • Dependency — if network fails, all users affected
  • Requires skilled administration and maintenance
  • Privacy concerns with shared data
  • Virus and malware can spread rapidly
  • Performance bottlenecks under heavy traffic
  • Legal and compliance challenges
💡
Exam Tip
Remember the three Cs of networking goals: Communication, Cost reduction, and Centralised resource sharing. For disadvantages, focus on Security and Reliability/dependency issues.
