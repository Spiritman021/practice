Section 8.4

End-to-End Packet Flow Walkthrough

What actually happens when Host A sends a web request (HTTP) to Host B across a router?

1

Application Layer (Host A)

The web browser generates an HTTP GET request message.

2

Transport Layer (Host A)

TCP encapsulates the data with a TCP header containing Source Port (e.g. 54321) and Destination Port (80). PDU = Segment.

3

Network Layer (Host A)

IP encapsulates the segment with an IP header containing Source IP (192.168.1.10) and Destination IP (10.0.0.50). PDU = Packet.

4

Data Link Layer (Host A)

Ethernet encapsulates packet with Frame Header containing Source MAC (Host A) and Destination MAC (Default Gateway / Router interface MAC). Adds CRC trailer. PDU = Frame.

5

Router Processing (Intermediate Node)

Router receives bits at Layer 1, decapsulates L2 Frame, reads L3 IP Header. Checks routing table for Destination IP (10.0.0.50). Decrements TTL by 1. Re-encapsulates with NEW L2 Source MAC (Router interface) and NEW L2 Destination MAC (Host B).

6

Receiver Decapsulation (Host B)

Host B receives bits → checks MAC (L2) → checks IP (L3) → checks Port 80 (L4) → delivers raw HTTP request data to Web Server software (L7).

Section 8.5

Exam Cheat Sheet & Quick Summary

📌
Golden Rules for Exam Questions
• MAC address is used at Layer 2 (Data Link) for local hop-to-hop forwarding.
• IP address is used at Layer 3 (Network) for end-to-end routing across networks.
• Port number is used at Layer 4 (Transport) for process-to-process communication.
• Routers strip and change Layer 2 headers at every hop, but Layer 3 IP addresses stay unchanged end-to-end.
• Switches operate at Layer 2 and do NOT modify IP or MAC headers.
• TCP = Reliable, Connection-oriented, 3-way handshake, Flow control.
• UDP = Connectionless, Fast, Lightweight, Video/VoIP/DNS.
