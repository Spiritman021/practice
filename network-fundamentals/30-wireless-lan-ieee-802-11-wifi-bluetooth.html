30.1 IEEE 802.11 WLAN Architecture (BSS & ESS)

The IEEE 802.11 standard defines two primary operational modes for Wireless LANs:

  • Infrastructure Mode: Wireless clients connect through a central **Access Point (AP)** connected to a wired backbone.
  • Ad-Hoc Mode (IBSS - Independent BSS): Peer-to-peer wireless network without a central Access Point.

Key Architectural Components

ComponentAbbreviationDescription & Function
Basic Service SetBSSThe fundamental building block of 802.11; consists of stationary/mobile wireless stations and an Access Point (AP). Identified by a BSSID (AP MAC address).
Extended Service SetESSConsists of two or more BSSs connected via a wired **Distribution System (DS)**. Allows seamless roaming across APs under a single SSID.
Distribution SystemDSThe underlying wired Ethernet network connecting multiple APs together.

Section 30.2

Hidden & Exposed Station Problems

Wireless transmission media suffer from physical radio range limitations that cause unique access problems:

Collision Threat
Hidden Station Problem
Station A and Station C are both in range of Access Point B, but A and C cannot hear each other. If both transmit to B simultaneously, a collision occurs at B!
Wasted Capacity
Exposed Station Problem
Station B is sending data to A. Station C hears B and falsely assumes the channel is busy, deferring its transmission to D even though C sending to D would cause zero interference at A!
🤝
Section 30.3

CSMA/CA with RTS/CTS Handshake

To solve the Hidden Station problem, 802.11 uses CSMA/CA (Collision Avoidance) with an optional **RTS/CTS Reservation Handshake**:

  1. Request to Send (RTS): Sender transmits a short RTS packet containing the duration needed for transmission.
  2. Clear to Send (CTS): Receiver broadcasts a CTS packet. All neighboring stations hearing the CTS freeze their transmission for the specified duration (**NAV - Network Allocation Vector**).
  3. Data Transmission: Sender transmits the main data frame safely without collisions.
  4. Acknowledgement (ACK): Receiver returns an ACK frame to confirm successful delivery.

30.5 Bluetooth Basics (Piconet & Scatternet)

Bluetooth (IEEE 802.15.1) is a Short-Range Wireless Personal Area Network (WPAN) operating in the **2.4 GHz ISM band** using **Frequency Hopping Spread Spectrum (FHSS)** (hops 1600 times per second across 79 channels).

Bluetooth Network Topologies

  • Piconet: An ad-hoc network consisting of **1 Primary Master node** and up to **7 active Secondary Slave nodes** (plus up to 255 parked nodes). All communication flows through the Master.
  • Scatternet: Formed by interconnecting multiple Piconets. A node can act as a Slave in one Piconet and a Master/Slave in another Piconet.
