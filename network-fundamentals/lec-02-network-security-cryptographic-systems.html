2.1 Cryptographic System Model & Binary Arithmetic

A Cryptographic System transforms unreadable Plaintext ($P$) into encrypted Ciphertext ($C$) using a mathematical Cipher algorithm and a Secret Key ($K$).

🔄 Cryptographic Encryption/Decryption Flow:
Plaintext ($P$)
+ Key ($K$) $\rightarrow$
Cipher Algorithm (Black Box)
$\rightarrow$
Ciphertext ($C$)

Binary Modulo Arithmetic Operations in Ciphers

Computers represent all message bits as 0s and 1s. Encryption algorithms rely on basic binary bitwise logic:

Operation Symbol Mathematical Name Logical Equivalent Truth Table & Rules
$\oplus$ Modulo 2 Addition XOR (Exclusive OR) $0 \oplus 0 = 0, \quad 0 \oplus 1 = 1, \quad 1 \oplus 0 = 1, \quad 1 \oplus 1 = 0$
True ONLY if inputs are different. ($A \oplus A = 0$)
$\otimes$ Modulo 2 Multiplication AND $0 \otimes 0 = 0, \quad 0 \otimes 1 = 0, \quad 1 \otimes 0 = 0, \quad 1 \otimes 1 = 1$
True ONLY if both inputs are 1.

2.2 Stream Ciphers vs Block Ciphers

Symmetric key ciphers are divided into two main operational categories based on how they process plaintext input:

Dimension Stream Ciphers Block Ciphers
Input Unit Processes continuous stream of plaintext bit-by-bit or byte-by-byte. Processes fixed-size blocks of plaintext (e.g. 64-bit or 128-bit blocks).
Implementation Target Implemented primarily in Hardware devices (ASICs, FPGAs) for minimal latency. Implemented primarily in Software on general-purpose CPUs.
Memory & Complexity Low memory requirement (no buffering needed). Requires buffer memory to hold fixed-size data blocks.
Examples RC4, A5/1 (GSM cellular), ChaCha20. DES, 3DES, AES, IDEA, Blowfish.

2.3 Symmetric Block Ciphers Master Guide

1. DES (Data Encryption Standard)
• Published by NIST / FIPS 46 in 1975/1977.
• Block Size: 64 Bits.
• Key Size: 56 Bits (64-bit key input, 8 parity bits dropped).
• Rounds: 16 Feistel Rounds (using 48-bit subkeys).
• Structure: Initial Permutation (IP) $\rightarrow$ 16 Feistel rounds $\rightarrow$ Final Permutation ($IP^{-1}$).
• Status: Broken by brute force in 1997 due to small 56-bit key space.
2. Triple DES (3DES / TDEA)
• Applies DES algorithm three consecutive times (Encrypt-Decrypt-Encrypt EDE).
• Block Size: 64 Bits.
• Key Size: 112 Bits (2-key) or 168 Bits (3-key).
• Overcomes DES vulnerability, but slow in software execution.
3. AES (Advanced Encryption Standard)
• Published by NIST in 2001 (FIPS 197, Rijndael cipher).
• Block Size: Fixed 128 Bits (16 Bytes).
• Key Sizes & Rounds:
  - 128-bit key $\rightarrow$ 10 Rounds
  - 192-bit key $\rightarrow$ 12 Rounds
  - 256-bit key $\rightarrow$ 14 Rounds
• 4 Sub-operations per Round:
  1. SubBytes (S-box byte substitution)
  2. ShiftRows (Cyclic row shift)
  3. MixColumns (Column mixing matrix)
  4. AddRoundKey (XOR with round key)
• Exam Trap: Final round OMITS MixColumns!

4. IDEA (International Data Encryption Algorithm)

Published in 1991 by Lai, Massey, and Murphy. Block size is 64 bits, key size is 128 bits. Consists of 8 identical rounds + 1 half-round final transformation.

2.4 RSA Public Key Cryptosystem & Step-by-Step Math Example

Introduced in 1978 by Ron Rivest, Adi Shamir, and Leonard Adleman. RSA relies on the mathematical difficulty of factoring large prime numbers.

🧮 Step-by-Step RSA Key Generation & Numerical Walkthrough
  1. Select two prime numbers: Let $p = 3$ and $q = 11$.
  2. Calculate Modulus $n$: $$n = p \times q = 3 \times 11 = 33$$
  3. Calculate Euler's Totient $\phi(n)$: $$\phi(n) = (p - 1) \times (q - 1) = (3 - 1) \times (11 - 1) = 2 \times 10 = 20$$
  4. Choose Public Exponent $e$: Select $e$ such that $1 < e < \phi(n)$ and $\gcd(e, \phi(n)) = 1$. Let $e = 7$.
  5. Calculate Private Exponent $d$: Solve for $d$ such that $(d \times e) \equiv 1 \pmod{\phi(n)}$: $$(d \times 7) \equiv 1 \pmod{20} \implies d = 3 \quad (\text{since } 3 \times 7 = 21 = 1 \times 20 + 1)$$
  6. Key Pairs Formed:
    • Public Key: $(e, n) = (7, 33)$
    • Private Key: $(d, n) = (3, 33)$
  7. Encryption Example: To encrypt message $m = 2$: $$c = m^e \bmod n = 2^7 \bmod 33 = 128 \bmod 33 = 29 \quad (\text{Ciphertext } c = 29)$$
  8. Decryption Example: To decrypt ciphertext $c = 29$: $$m = c^d \bmod n = 29^3 \bmod 33 = 24389 \bmod 33 = 2 \quad (\text{Plaintext } m = 2 \text{ recovered!})$$
RSA Key Size (Bits) Security Strength Rating Current Industry Status
512 Bits Low-strength key Broken (Cracked in 1999).
1024 Bits Medium-strength key Deprecated (Insecure for modern use).
2048 Bits High-strength key Current Minimum Security Standard.
4096 Bits Very high-strength key Ultra-secure banking & root CA standard.

Q1. What is the key size and block size used by the Data Encryption Standard (DES)?
A) 128-bit block, 64-bit key
B) 64-bit block, 56-bit key ✓
C) 64-bit block, 128-bit key
D) 128-bit block, 128-bit key
Correct Answer: B) 64-bit block, 56-bit key.
Explanation: DES accepts a 64-bit block of plaintext and a 64-bit key input, but 8 bits are used for parity, resulting in an effective key length of 56 bits executed over 16 Feistel rounds.

A) 10 Rounds
B) 12 Rounds ✓
C) 14 Rounds
D) 16 Rounds
Correct Answer: B) 12 Rounds.
AES Round Rule: 128-bit key = 10 rounds; 192-bit key = 12 rounds; 256-bit key = 14 rounds. (Block size is always fixed at 128 bits).

A) 33
B) 20 ✓
C) 30
D) 14
Correct Answer: B) 20.
Calculation: $\phi(n) = (p - 1)(q - 1) = (3 - 1)(11 - 1) = 2 \times 10 = 20$.

D) Davies-Meyer Structure
Correct Answer: C) Sponge Construction (Keccak).

2.7 Quick Exam Revision Cheat Sheet

1. Binary Modulo 2: $\oplus$ Modulo 2 Addition = XOR ($A \oplus A = 0$). $\otimes$ Modulo 2 Multiplication = AND.

2. Stream vs Block: Stream = continuous bits/bytes, Hardware-oriented (RC4). Block = fixed-size blocks, Software-oriented (DES, AES).

3. DES: 64-bit block, 56-bit key, 16 Feistel rounds. Initial & Final Permutations.

4. AES: Fixed 128-bit block. 128-bit key = 10 rounds, 192-bit key = 12 rounds, 256-bit key = 14 rounds. Round steps: SubBytes, ShiftRows, MixColumns (omitted in final round), AddRoundKey.

5. RSA Math: $n = p \times q$, $\phi(n) = (p-1)(q-1)$. Public Key = $(e, n)$, Private Key = $(d, n)$. Encryption $c = m^e \bmod n$, Decryption $m = c^d \bmod n$. Minimum standard size = 2048 bits.

6. Hashes: MD5 = 128-bit | SHA-1 = 160-bit | Whirlpool = 512-bit | SHA-256 = 256-bit | SHA-3 = Sponge Keccak (224/256/384/512 bits) | BLAKE3 = Merkle tree with 7 rounds.
