Section 01

What is a Computer Network?

A Computer Network is a group of interconnected computers and computing devices linked via communication channels that enable nodes to share resources, data, hardware, and applications.

Core Objective 1
📁 Resource Sharing
Sharing physical devices (printers, hard drives) and software/databases across multiple users efficiently.
Core Objective 2
⚡ High Reliability & Speed
If one machine fails, copies of files exist on other nodes. Enables instantaneous communication (email, VoIP).
Core Objective 3
💰 Cost Reduction
Small computers linked in a network offer a better price-to-performance ratio than a single mainframe machine.

Category 1
📡 PAN (Personal Area Network)
- Range: Within 10 meters (personal space).
- Examples: Bluetooth headphones, smartwatch to phone, Wireless USB, Zigbee.
- Key Property: Low power, single-user operation.
Category 2
🏢 LAN (Local Area Network)
- Range: Single room, office building, home (up to ~1 km).
- Privately owned: High speed (10 Mbps to 10 Gbps), low error rate.
- Technologies: Ethernet (IEEE 802.3), Wi-Fi (IEEE 802.11).
Category 3
🏙️ MAN (Metropolitan Area Network)
- Range: Entire city or town (5 to 50 km).
- Connects: Multiple LANs across a town or corporate branches.
- Examples: Cable TV network, Cable Broadband Internet, FDDI.
Category 4
🌍 WAN (Wide Area Network)
- Range: Country, continent, or global space.
- Uses: Telecom, satellite links, fiber optics.
- Examples: The Internet, Banking ATM network (national).

Section 03

Specialized Network Types (SAN, CAN, BAN, NAN, RAN)

Acronym Full Name Description & Key Characteristics Typical Use Case
SAN Storage Area Network Dedicated high-speed network that provides block-level network access to storage. Connects servers to data storage devices (disk arrays, tape libraries). Data centers, Enterprise backups (Fibre Channel, iSCSI).
CAN Campus Area Network Larger than a LAN, smaller than a MAN. Interconnects multiple LANs across a specific geographical campus (university, military base). University campuses, Corporate HQ complexes.
BAN Body Area Network Network of wearable or implanted medical sensors and computing devices on or inside the human body. Heart rate monitors, Pacemakers, Smart health trackers (IEEE 802.15.6).
NAN Near-Me Area Network Communication between wireless devices located in close physical proximity without requiring a central router. Mobile P2P file sharing, Wi-Fi Direct, Apple AirDrop.
RAN Radio Access Network The radio frequency part of a cellular telecommunication system connecting individual mobile devices to core network. Cellular mobile networks (3G, 4G LTE, 5G NR).

Section 04

Message Delivery & Routing Schemes

Routing schemes define how messages are addressed and delivered from a sender to destination endpoints across the network.

🎯 Unicast
One-to-One (1 : 1) association.
Delivers a message to a single specific node. Each destination address uniquely identifies one receiver endpoint.
Example: HTTP web browsing, Telnet, SSH, private email.
1 : 1 Delivery
📢 Broadcast
One-to-All (1 : All) association.
Delivers a message to ALL nodes in the network/subnet. Network automatically replicates the packet.
Example: ARP Request, IPv4 Broadcast (255.255.255.255, Limited/Directed Broadcast).
1 : All Delivery
👥 Multicast
One-to-Many (1 : Many) association.
Delivers a message to a specific subset of nodes that expressed interest (subscribed group).
Example: Live video streaming, IPTV, OSPF/RIP routing updates (Class D IP: 224.0.0.0/4).
1 : Many Delivery
📍 Anycast
One-to-One-of-Many (1 : Nearest) association.
Delivers a message to any single member of a group of potential receivers (typically the nearest node geographically/topologically).
Example: DNS Root Servers, CDN (Cloudflare/Akamai), IPv6 Anycasting.
1 : Nearest Node
🗺️ Geocast
Geographic Location-Based delivery.
Delivers a message to a group of nodes based on their physical geographical position.
Example: Vehicular Ad-Hoc Networks (VANETs), Emergency location alerts.
Geo-Location Delivery

Section 05

Line Configurations & Network Topologies Overview

1. Line Configurations

Configuration 1
↔️ Point-to-Point (P2P)
Dedicated link between two devices. Entire link capacity is reserved for transmission between those two nodes. (e.g., microwave link, direct cable).
Configuration 2
🔀 Multipoint (Multidrop)
More than two devices share a single link. Channel capacity is shared either spatially or temporally. (e.g., Traditional Bus Topology).

2. Topologies Formulas Cheat Sheet

⚡ Mesh Topology Links Formula
L = \frac{N(N - 1)}{2}
N = Number of nodes  |  Number of I/O ports required per device = N - 1

Section 07

IBPS SO IT PYQ Practice Questions

PYQ 01 Network Classification
Which network type covers a geographical area usually spanning a city or a large town?
  • A. LAN
  • B. MAN ✓
  • C. WAN
  • D. PAN
Answer: B — MAN (Metropolitan Area Network)
A MAN spans a city or town (typically 5–50 km). LAN covers a single building/office (<1 km), WAN covers countries/continents, and PAN covers personal space (<10m).
PYQ 02 Mesh Topology Formula
In a fully connected Mesh topology with 10 computers, how many physical duplex links are required?
  • A. 10
  • B. 90
  • C. 45 ✓
  • D. 20
Answer: C — 45
Formula for Mesh duplex links: $L = \frac{N(N - 1)}{2} = \frac{10 \times 9}{2} = 45$ links.
Number of ports per node = $N - 1 = 9$ ports.
PYQ 03 Multicast Address Class
Which IPv4 address class is specifically reserved for Multicast communication?
  • A. Class A
  • B. Class B
  • C. Class C
  • D. Class D ✓
Answer: D — Class D
Class D IP addresses (224.0.0.0 to 239.255.255.255) are dedicated to Multicast communication (1-to-many).
PYQ 04 Anycast Concept
In Anycast routing, a packet sent from a client is delivered to:
  • A. All servers in the network
  • B. A specific hardcoded server
  • C. The single nearest server in a group sharing the same IP ✓
  • D. All servers in a specific geographic region
Answer: C
Anycast delivers to the single nearest node (in terms of routing distance) among a group of servers sharing the same IP address (commonly used in DNS Root Servers and CDNs).
PYQ 05 Storage Area Network
A dedicated, high-speed network that provides block-level storage access to servers is known as:
  • A. LAN
  • B. SAN ✓
  • C. MAN
  • D. NAS
Answer: B — SAN (Storage Area Network)
A SAN connects servers to high-performance storage targets (disk arrays, tape drives) over Fibre Channel or iSCSI.
PYQ 06 Line Configuration
A line configuration in which two and only two devices share a dedicated link is called:
  • A. Point-to-Point ✓
  • B. Multipoint
  • C. Multidrop
  • D. Broadcast
Answer: A — Point-to-Point
Point-to-point provides a dedicated link strictly between two devices. Multipoint/multidrop links share channel capacity among three or more devices.
PYQ 07 Broadcast Address
The IP address 255.255.255.255 represents:
  • A. Loopback address
  • B. Limited Broadcast Address ✓
  • C. Directed Broadcast Address
  • D. Multicast Group Address
Answer: B — Limited Broadcast Address
255.255.255.255 is the limited broadcast address used to send data to all hosts on the local network without passing through routers.
PYQ 08 Bluetooth Network
Bluetooth technology is an example of which category of computer network?
  • A. PAN ✓
  • B. LAN
  • C. MAN
  • D. WAN
Answer: A — PAN (Personal Area Network)
Bluetooth operates over short distances (approx. 10 meters) to form a Piconet/PAN for personal devices.
PYQ 09 Wireless LAN Standard
Which IEEE standard governs Wireless LAN (Wi-Fi) communication?
  • A. IEEE 802.3
  • B. IEEE 802.11 ✓
  • C. IEEE 802.15
  • D. IEEE 802.1
Answer: B — IEEE 802.11
IEEE 802.11 specifies Wireless LAN (Wi-Fi). IEEE 802.3 is Ethernet, and IEEE 802.15 is Wireless PAN (Bluetooth/Zigbee).
PYQ 10 Routing Scheme Comparison
Which delivery scheme uses a one-to-many-of-many association where datagrams are routed simultaneously in a single transmission to multiple interested recipients?
  • A. Unicast
  • B. Broadcast
  • C. Multicast ✓
  • D. Anycast
Answer: C — Multicast
Multicast sends datagrams to a specific subset/group of interested hosts (one-to-many), unlike Broadcast which sends to ALL hosts on the subnet.
