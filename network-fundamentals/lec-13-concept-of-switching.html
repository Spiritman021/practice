Section 01

Taxonomy of Switched Networks

A switched network consists of a series of interconnected nodes called switches capable of routing data from a source node to a destination node without requiring a direct physical cable between every pair of computers.

Category 1
🔌 Circuit-Switched
Dedicated physical connection established at Physical Layer before data transmission begins. (PSTN Telephony).
Category 2
📦 Packet-Switched
Data divided into small packets transmitted independently. Divided into Datagram (Connectionless) and Virtual-Circuit (Connection-Oriented).
Category 3
📨 Message-Switched
Entire message stored and forwarded node-by-node at Application Layer. High storage requirement at nodes.
⚡
Section 02

Circuit-Switched Networks (Physical Layer)

🔥 IBPS SO IT – Core High Frequency Topic

Operates at the Physical Layer (Layer 1). A dedicated physical circuit path is reserved between source and destination before data transfer starts.

1
Phase 1: Setup Phase
End-to-end request sent through switches to reserve dedicated links and switches.
2
Phase 2: Data Transfer Phase
Contiguous stream of data flows across the reserved path. No packet headers attached!
3
Phase 3: Teardown Phase
Disconnection signal released to free reserved switches and transmission resources.
⚡ Circuit-Switching Total Delay Formula
$$\text{Total Delay} = T_{\text{setup}} + T_{\text{transmission}} + T_{\text{propagation}} + T_{\text{teardown}}$$
Note: Zero queuing/processing delay during data transfer phase!
📦
Section 03

Datagram Packet-Switched Networks (Connectionless IP)

Operates at the Network Layer (Layer 3). Connectionless approach: each packet is treated independently as an autonomous entity called a Datagram.

Feature 1
Independent Routing
Packets belonging to the same message may travel along **different dynamic paths** to reach the destination based on routing tables.
Feature 2
Out-of-Order Delivery
Packets may arrive out-of-order at the destination. The Transport Layer (TCP) reorders them using sequence numbers.
Feature 3
Full Address Header
Every single datagram must carry the complete source and destination IP addresses in its header.
⚡ Datagram Total Delay (H Hops)
$$\text{Total Delay} = \sum_{i=1}^{H} \left( T_{\text{trans}, i} + T_{\text{prop}, i} + T_{\text{queue}, i} + T_{\text{proc}, i} \right)$$
Uses Store-and-Forward mechanism (router receives full packet before forwarding).
🔗
Section 04

Virtual-Circuit Packet Networks (Connection-Oriented)

Combines features of Circuit Switching and Datagram Packet Switching (used in Frame Relay, ATM, MPLS).

Feature 1
Logical Path Setup
A logical virtual circuit path is established before data transfer. All packets follow the exact same pre-established route.
Feature 2
VCI Tag Identifiers
Packets carry a small Virtual Circuit Identifier (VCI) tag instead of full source/destination IP addresses in each header.
Feature 3
In-Order Arrival
Packets arrive strictly in-order at the destination because they follow the identical sequence.
📨
Section 05

Message Switching (Store-and-Forward)

Message switching sends the entire message as a single unit node-by-node. Each intermediate switch must have enough disk storage to store the entire message before forwarding it to the next hop.

⚙️
Section 06

Switch Hardware (Crossbar, Clos Criterion & TSI)

Hardware Type 1
Crossbar Switch
Space-division switch connecting $N$ inputs to $N$ outputs using a grid of $N^2$ crosspoint electronic switches. Inefficient for large $N$.
Hardware Type 2
Clos Multistage Switch
Reduces total crosspoints by arranging switches in multiple stages.
⚡ Clos Criterion for Non-blocking Switch
$$k \ge 2n - 1$$
$n$ = inputs per small first-stage switch  |  $k$ = number of middle-stage switches
Hardware Type 3
Time-Slot Interchange (TSI)
Time-division switch that uses RAM memory buffer to store incoming time slots and read them out in a reordered sequence.
📊

Section 08

IBPS SO IT PYQ Practice Questions

PYQ 01 Circuit Switching Setup
Which switching technique establishes a dedicated physical path between source and destination BEFORE data transfer begins?
  • A. Circuit Switching ✓
  • B. Datagram Packet Switching
  • C. Message Switching
  • D. Packet Filter Switching
Answer: A — Circuit Switching
Circuit switching reserves a dedicated physical connection through 3 phases: Setup, Data Transfer, and Teardown.
PYQ 02 Datagram Independent Paths
In a Datagram Packet-Switched network, why can packets belonging to the same message arrive out of order at the destination?
  • A. Because packets carry no headers
  • B. Because each datagram is routed independently and may take different paths ✓
  • C. Because virtual circuits are pre-established
  • D. Because of circuit teardown delays
Answer: B
Datagram switching is connectionless. Every packet carries full address headers and is routed independently along dynamic paths based on current router tables.
PYQ 03 Virtual Circuit VCI Tag
What header identifier is used in Virtual-Circuit packet switching to forward packets along the pre-established route?
  • A. Full Source and Destination IP Address
  • B. Virtual Circuit Identifier (VCI) tag ✓
  • C. MAC Address only
  • D. Port Number only
Answer: B — Virtual Circuit Identifier (VCI) tag
Virtual circuit packets carry a small VCI tag in their header instead of full IP address headers, reducing header overhead.
PYQ 04 Clos Criterion Non-blocking
According to Clos Criterion for a 3-stage non-blocking space-division switch, if each small first-stage switch has $n = 4$ inputs, how many middle-stage switches ($k$) are required?
  • A. 4
  • B. 6
  • C. 7 ✓
  • D. 16
Answer: C — 7
Clos Criterion formula: $k \ge 2n - 1 = 2(4) - 1 = 8 - 1 = \mathbf{7\text{ middle switches}}$.
PYQ 05 Crossbar Crosspoint Complexity
A single-stage Crossbar switch connecting $N = 100$ inputs to $N = 100$ outputs requires how many total crosspoints?
  • A. 200
  • B. 1,000
  • C. 10,000 ✓
  • D. 100,000
Answer: C — 10,000
Crossbar crosspoint formula = $N^2 = 100 \times 100 = \mathbf{10,000\text{ crosspoints}}$.
PYQ 06 Layer Operating Level
Circuit Switching operates primarily at which layer of the OSI model?
  • A. Physical Layer (Layer 1) ✓
  • B. Data Link Layer (Layer 2)
  • C. Network Layer (Layer 3)
  • D. Transport Layer (Layer 4)
Answer: A — Physical Layer (Layer 1)
Circuit switching operates at Layer 1 by physically connecting transmission lines. Datagram packet switching operates at Layer 3.
PYQ 07 Header Overhead Comparison
Which switching method has ZERO header overhead during the actual data transfer phase?
  • A. Circuit Switching ✓
  • B. Datagram Packet Switching
  • C. Virtual Circuit Switching
  • D. Message Switching
Answer: A — Circuit Switching
Once the physical circuit is established, data streams continuously over the dedicated path without any packet headers added to the data bits.
PYQ 08 Store-and-Forward Delay
What is the Store-and-Forward mechanism used in packet switches and routers?
  • A. Router forwards bits as soon as they arrive
  • B. Router must receive and buffer the entire packet before inspecting header and forwarding to next hop ✓
  • C. Router drops packets if queue is empty
  • D. Router reserves physical wires indefinitely
Answer: B
Store-and-forward means a router buffers the complete incoming packet, checks its CRC for errors, inspects destination IP, and then transmits it onto the output link.
PYQ 09 TSI RAM Buffer
A Time-Slot Interchange (TSI) switch achieves time-division switching by storing incoming time slots into:
  • A. RAM Memory Buffer ✓
  • B. Optical Prisms
  • C. Crosspoint Grid
  • D. Low-pass Filter
Answer: A — RAM Memory Buffer
TSI switches store time slots into RAM memory locations sequentially and read them out out-of-order to resequence the time slots.
PYQ 10 Bandwidth Efficiency
Why is Datagram Packet Switching more bandwidth-efficient than Circuit Switching for computer data traffic?
  • A. Circuit switching uses optical lasers
  • B. Packet switching uses statistical multiplexing so channel bandwidth is shared and not wasted during idle periods ✓
  • C. Datagram packets carry no headers
  • D. Circuit switching has higher queuing delay
Answer: B
Computer data is bursty. Circuit switching reserves bandwidth even during silent/idle periods, wasting resources. Packet switching shares link capacity dynamically among active packets.
