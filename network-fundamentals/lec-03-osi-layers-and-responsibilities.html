Section 01

What is the OSI Reference Model?

Developed by the **International Organization for Standardization (ISO)** in **1984**, the **Open Systems Interconnection (OSI)** model is an abstract 7-layer framework for network protocol design and computer communication.

💡
Exam Mnemonic (Top to Bottom: 7 to 1)

"All People Seem To Need Data Processing"
Application (7) ➔ Presentation (6) ➔ Session (5) ➔ Transport (4) ➔ Network (3) ➔ Data Link (2) ➔ Physical (1)

Category 1
💻 Upper / Host Layers
Layers 7, 6, 5, 4: Dealt with by software in host machines. Focus on user interaction, data format, sessions, and end-to-end delivery.
Category 2
🔌 Lower / Media Layers
Layers 3, 2, 1: Dealt with by network hardware/routers/switches. Focus on packet routing, framing, and bit transmission.

Section 03

Lower Layers: Physical, Data Link & Network

Layer 1
⚡ Physical Layer
- Responsibility: Transmits raw bits (0s and 1s) over a physical medium.
- Key Duties: Signal encoding, bit rate (duration of a bit), bit synchronization, line configuration (P2P/Multipoint), physical topology, transmission mode (Simplex/Half/Full Duplex).
- Devices: Hub, Repeater, Cables, Connectors.
Layer 2
📦 Data Link Layer
- Responsibility: Node-to-node (Hop-to-hop) frame delivery.
- Key Duties: Framing (adding header/trailer), Physical addressing (48-bit MAC address), Flow control (node-to-node), Error control (CRC/Parity), Access control (MAC sublayer CSMA/CD).
- Devices: Switch, Bridge, NIC.
Layer 3
🌐 Network Layer
- Responsibility: Source-to-destination (Host-to-Host) packet delivery across multiple networks.
- Key Duties: Logical addressing (IP address: 32-bit IPv4 / 128-bit IPv6), Routing (path determination, OSPF/RIP/BGP).
- Devices: Router, Layer 3 Switch.
💻
Section 04

Upper Layers: Transport, Session, Presentation & Application

Layer 4
🚚 Transport Layer
- Responsibility: Process-to-Process (End-to-End) message delivery.
- Key Duties: Service-point / Port addressing (16-bit Port numbers), Segmentation & Reassembly (sequence numbers), Connection control (TCP vs UDP), End-to-end Flow & Error control.
- Protocols: TCP, UDP, SCTP.
Layer 5
🗣️ Session Layer
- Responsibility: Establishes, maintains, and synchronizes dialog control.
- Key Duties: Dialog control (Half-duplex / Full-duplex session establishment), Synchronization (inserting checkpoints/synch points in data stream to resume after failure).
- Protocols: NetBIOS, PPTP.
Layer 6
🎨 Presentation Layer
- Responsibility: Concerned with syntax and semantics of transmitted data.
- Key Duties: Translation (EBCDIC to ASCII, interoperability), Encryption / Decryption (privacy schemes, SSL/TLS), Data Compression (reducing bit size).
- Formats: JPEG, ASCII, MPEG.
Layer 7
🖥️ Application Layer
- Responsibility: Provides network services directly to the end user / application.
- Key Duties: Network Virtual Terminal (Telnet), File Transfer (FTP/FTAM), Mail Services (SMTP/POP3/IMAP), Directory Services (DNS/LDAP).
- Protocols: HTTP, HTTPS, FTP, DNS, SMTP, DHCP.

Four Levels of Addressing in OSI Model

Address Level OSI Layer Size / Format Primary Purpose Example
Physical Address Layer 2 (Data Link) 48-bit (6 Bytes) Hexadecimal Node-to-node (Hop-to-hop) local frame delivery 00:1A:2B:3C:4D:5E (MAC Address)
Logical Address Layer 3 (Network) 32-bit (IPv4) / 128-bit (IPv6) Source-to-destination (Host-to-host) global routing 192.168.1.1 / 2001:db8::1
Port Address Layer 4 (Transport) 16-bit Unsigned Integer (0–65535) Process-to-process delivery (identifies specific application) Port 80 (HTTP), Port 443 (HTTPS)

Section 06

Data Encapsulation & Decapsulation Process

1
Application, Presentation & Session (Layers 7, 6, 5)
User data is created, formatted, encrypted, compressed, and session is established. Output = Data.
2
Transport Layer (Layer 4 Encapsulation)
Adds Transport Header ($H_4$) containing Source & Destination Port numbers and sequence numbers. Output = Segment.
3
Network Layer (Layer 3 Encapsulation)
Adds Network Header ($H_3$) containing Source & Destination IP addresses. Output = Packet.
4
Data Link Layer (Layer 2 Encapsulation)
Adds Data Link Header ($H_2$) with MAC addresses AND Data Link Trailer ($T_2$) containing CRC checksum. Output = Frame.
5
Physical Layer (Layer 1 Transmission)
Converts frame into stream of bits (0s & 1s) and transmits as signals over physical medium.

Section 08

IBPS SO IT PYQ Practice Questions

PYQ 01 Transport Layer Delivery
Which layer of the OSI model is responsible for Process-to-Process (End-to-End) message delivery?
  • A. Network Layer
  • B. Transport Layer ✓
  • C. Data Link Layer
  • D. Session Layer
Answer: B — Transport Layer
Transport Layer handles Process-to-Process (End-to-End) delivery using Port numbers.
Network Layer handles Host-to-Host (Source-to-Destination) delivery using IP addresses.
Data Link Layer handles Node-to-Node (Hop-to-Hop) delivery using MAC addresses.
PYQ 02 PDU at Data Link Layer
What is the Protocol Data Unit (PDU) at the Data Link Layer?
  • A. Packet
  • B. Segment
  • C. Frame ✓
  • D. Bit
Answer: C — Frame
PDU Hierarchy: Layer 4 = Segment; Layer 3 = Packet; Layer 2 = Frame; Layer 1 = Bit.
PYQ 03 Presentation Layer Responsibilities
Data Encryption, Decryption, Translation, and Compression are primary functions of which OSI layer?
  • A. Application Layer
  • B. Presentation Layer ✓
  • C. Session Layer
  • D. Transport Layer
Answer: B — Presentation Layer
Presentation Layer (Layer 6) deals with data syntax, representation, encryption/decryption (SSL/TLS), and compression.
PYQ 04 Port Addressing
Port numbers operate at which layer of the OSI model?
  • A. Layer 2
  • B. Layer 3
  • C. Layer 4 ✓
  • D. Layer 5
Answer: C — Layer 4 (Transport Layer)
16-bit Port numbers (e.g., Port 80 for HTTP, Port 443 for HTTPS) operate at Layer 4 (Transport Layer) to direct traffic to the specific running application/process.
PYQ 05 Session Layer Checkpoints
The process of inserting synchronization points (checkpoints) into a long data stream to enable resumption after crash is handled by:
  • A. Transport Layer
  • B. Session Layer ✓
  • C. Presentation Layer
  • D. Network Layer
Answer: B — Session Layer
Session Layer (Layer 5) adds synchronization checkpoints. If a crash occurs during a 100-page file transfer at page 45, transmission can resume from page 45 instead of starting over from page 1.
PYQ 06 Data Link Header & Trailer
Which layer of the OSI model is the ONLY layer that adds BOTH a Header and a Trailer to data during encapsulation?
  • A. Transport Layer
  • B. Network Layer
  • C. Data Link Layer ✓
  • D. Physical Layer
Answer: C — Data Link Layer
Data Link Layer adds a Header ($H_2$ containing MAC addresses) AND a Trailer ($T_2$ containing CRC error-check bits) to form a complete frame.
PYQ 07 Logical Addressing
IP Address (Logical Addressing) is used for routing at which layer?
  • A. Layer 1
  • B. Layer 2
  • C. Layer 3 ✓
  • D. Layer 4
Answer: C — Layer 3 (Network Layer)
Logical IP addresses (32-bit IPv4 / 128-bit IPv6) are used at Layer 3 (Network Layer) for packet routing across independent networks.
PYQ 08 MAC Address Length
What is the size of a Physical MAC Address at the Data Link Layer?
  • A. 32 bits
  • B. 48 bits (6 Bytes) ✓
  • C. 64 bits
  • D. 128 bits
Answer: B — 48 bits (6 Bytes)
A MAC address is a 48-bit (6-byte) hexadecimal address burned into the Network Interface Card (NIC) by the manufacturer.
PYQ 09 Dialog Control
Establishing whether a communication session is Simplex, Half-Duplex, or Full-Duplex is a dialog control function of:
  • A. Transport Layer
  • B. Session Layer ✓
  • C. Data Link Layer
  • D. Physical Layer
Answer: B — Session Layer
Session Layer (Layer 5) manages dialog control (determining whose turn it is to transmit in half-duplex or managing simultaneous full-duplex sessions).
PYQ 10 OSI Layer Count Order
In the OSI model, Layer 2 and Layer 4 are respectively:
  • A. Network Layer & Application Layer
  • B. Data Link Layer & Transport Layer ✓
  • C. Physical Layer & Network Layer
  • D. Data Link Layer & Session Layer
Answer: B — Data Link Layer & Transport Layer
Layer 1 = Physical, Layer 2 = Data Link, Layer 3 = Network, Layer 4 = Transport, Layer 5 = Session, Layer 6 = Presentation, Layer 7 = Application.
