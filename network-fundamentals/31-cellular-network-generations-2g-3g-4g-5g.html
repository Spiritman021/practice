31.1 Cellular Architecture & Frequency Reuse

A Cellular Network divides a geographic service area into small hexagonal geographic units called **Cells**, each served by a central base station (eNodeB / gNodeB).

Core Principles

  • Frequency Reuse: Adjacent cells use different frequency channels to prevent co-channel interference, while non-adjacent cells separated by a buffer distance reuse the same frequencies.
  • Handoff / Handover: The automated process of transferring an active voice call or data session from one cell base station to another as the user moves.

Section 31.2

Cellular Generations Evolution (1G to 4G LTE)

  • 1G (1980s - Analog Voice): Analog radio technology (AMPS, NMT). Max speed ~2.4 kbps. Voice calls only; zero security/encryption.
  • 2G (1990s - Digital Voice & SMS): Digital encryption (GSM, CDMA). Introduced SMS text messaging. Upgraded via **GPRS (2.5G - 114 kbps)** and **EDGE (2.75G - 384 kbps)** for packet data.
  • 3G (2000s - Mobile Data & Web): High-speed packet switching (UMTS, WCDMA, HSPA). Enabled mobile web browsing, video calls, and app stores (up to 21 Mbps).
  • 4G LTE (2010s - All-IP Broadband): Unified All-IP network architecture using OFDM and MIMO antenna technology. Delivered true mobile broadband up to 1 Gbps (LTE-Advanced).

31.3 5G NR Architecture & The Three Pillars

5G New Radio (NR) is designed to serve diverse use cases beyond smartphone data through **3 Core Pillars** defined by ITU IMT-2020:

Pillar 1
eMBB (Enhanced Mobile Broadband)
Delivers peak data rates up to 20 Gbps for 8K video streaming, AR/VR immersive applications, and dense urban environments.
Pillar 2
URLLC (Ultra-Reliable Low Latency)
Provides sub-millisecond (< 1 ms) radio latency and 99.999% reliability for autonomous vehicles, remote surgery, and industrial robotics.
Pillar 3
mMTC (Massive Machine-Type Comm)
Supports up to 1 million connected IoT devices per square kilometer with low energy consumption and long battery life.

31.5 5G Network Slicing Concept

Network Slicing uses Software Defined Networking (SDN) and Network Functions Virtualization (NFV) to multiplex virtual, isolated end-to-end networks over a single shared physical 5G infrastructure. Each "slice" is customized with specific QoS, bandwidth, and latency parameters for different industries!
