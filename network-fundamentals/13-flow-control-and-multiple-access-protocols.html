Section 13.1

Flow Control & ARQ Protocols Overview

Flow control prevents a fast sender from overwhelming a slow receiver with data. **ARQ (Automatic Repeat Request)** protocols combine flow control with error control by retransmitting lost or corrupted frames.

13.2 Stop-and-Wait ARQ

The sender transmits **one frame** and stops, waiting for an Acknowledgement (ACK) before sending the next frame. If an ACK doesn't arrive before the timer expires, the sender retransmits the frame.

    • Sender Window Size (Ws): 1
    • Receiver Window Size (Wr): 1
    • Sequence Numbers Needed: 0 and 1 (1-bit sequence number).
    📐
    Efficiency Formula
    η = Tt / (Tt + 2Tp) = 1 / (1 + 2a)
    where Tt = Frame Size / Bandwidth (Transmission Time), Tp = Distance / Speed (Propagation Delay), and a = Tp / Tt.

13.3 Go-Back-N (GBN) ARQ

The sender can transmit **multiple frames** (up to window size Ws) without waiting for an ACK. The receiver accepts frames **in strict order only**. If a frame is lost or corrupted, the receiver discards all subsequent out-of-order frames, and the sender must **go back and retransmit all frames** starting from the lost frame.

  • Sender Window Size (Ws): 2m - 1 (for m-bit sequence number).
  • Receiver Window Size (Wr): 1
  • ACK Type: Cumulative ACK (ACK N acknowledges all frames up to N-1).
  • Efficiency: η = Ws / (1 + 2a) (for Ws ≤ 1 + 2a).

13.4 Selective Repeat (SR) ARQ

The sender transmits multiple frames. The receiver maintains a window size Wr > 1 and **buffers out-of-order frames**. The sender **retransmits ONLY the specific frame** that was lost or corrupted (using negative ACK or timeout).

  • Sender Window Size (Ws): 2m-1
  • Receiver Window Size (Wr): 2m-1
  • ACK Type: Independent / Selective ACK (ACKs individual frames).
  • Efficiency: Highest among ARQ protocols (η = Ws / (1 + 2a)).

Section 13.6

Multiple Access Protocols Overview

When multiple nodes share a single broadcast link (e.g. Wi-Fi, Ethernet bus), a **Medium Access Control (MAC)** protocol is needed to coordinate access and avoid collisions.

Category 1
Random Access
Nodes contend for channel; no central control. Collisions can occur. (ALOHA, CSMA, CSMA/CD, CSMA/CA).
Category 2
Controlled Access
Nodes consult each other or a master node to find who has right to send. Collision-free. (Reservation, Polling, Token Passing).
Category 3
Channelization
Available bandwidth is divided by frequency, time, or code. (FDMA, TDMA, CDMA).

Section 13.8

CSMA, CSMA/CD & CSMA/CA

CSMA (Carrier Sense Multiple Access) operates on the principle: **"Listen Before Talk"**. A node senses the channel before transmitting.

1. CSMA Persistence Modes

  • 1-Persistent: Senses channel; if idle, transmits immediately with 100% probability. If busy, continuously senses until idle.
  • Non-Persistent: Senses channel; if idle, transmits. If busy, waits a random amount of time and senses again. (Reduces collisions).
  • p-Persistent: Used in slotted channels. If idle, transmits with probability p; defers to next slot with probability 1 - p.

2. CSMA/CD (Collision Detection - Ethernet 802.3)

Operates on: **"Listen While Talk"**. Used in wired Ethernet. If a collision is detected during transmission, the node sends a high-frequency **Jamming Signal** (32 bits), stops transmission, and executes **Binary Exponential Backoff algorithm** (0 ≤ K ≤ 2n - 1) to pick a random wait time.

📐
Minimum Frame Size Formula for CSMA/CD
To ensure a node detects a collision before it finishes transmitting the frame:
Tt ≥ 2 × Tp  ⇒  Frame Size (bits) / Bandwidth (bps) ≥ 2 × Tp
Minimum Frame Size = 2 × Tp × Bandwidth
In standard Ethernet (10 Mbps, 51.2 µs RTT), Minimum Frame Size = 64 Bytes (512 bits).

3. CSMA/CA (Collision Avoidance - Wi-Fi 802.11)

Used in wireless networks where collision detection is impossible (hidden station problem). Operates on: **"Listen Before Talk + Reservation"**.

  • Uses **IFS (Inter-Frame Space)**: SIFS (Short IFS) for ACKs, DIFS (Distributed IFS) for data frames.
  • Uses **RTS / CTS Handshake**: Sender transmits Request to Send (RTS); Receiver responds with Clear to Send (CTS). All other nodes freeze their transmission.

Section 13.9

Controlled Access & Channelization (CDMA)

1. Controlled Access

  • Reservation: Nodes reserve time slots in a reservation frame before transmitting.
  • Polling: A Master primary node polls each Secondary node sequentially ("Do you have data to send?").
  • Token Passing: A special control frame called a **Token** circulates around a logical ring. Only the node holding the token can transmit data. (No collisions).

2. CDMA (Code Division Multiple Access)

Each station is assigned a unique **orthogonal chip sequence** (Walsh Code). All stations transmit over the same frequency band at the same time. The receiver extracts a specific station's data by calculating the **dot product (inner product)** of the combined signal with that station's unique code vector.
