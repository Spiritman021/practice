💡 1. What is a Machine Instruction? (PDF Page 2 & 3)

A machine instruction is a sequence of binary bits (0s and 1s) representing a command to the CPU to perform a specific primitive operation (e.g., addition, data movement, comparison).

Binary Command

Tells the CPU what operation to execute and where the operands (data sources/destinations) are located in memory or registers.

Real-Life Analogy

Like a step-by-step recipe for an automated robot (e.g., "Add 50g Sugar to Bowl"). Each instruction must be precise and unambiguous.

Assembly vs Machine Level

Mnemonic form: ADD A, B
Binary form: 10000000 0000 0001 (Opcode + Register IDs).

🧩 2. Anatomy & Structure of an Instruction (PDF Page 3 & 4)

Every instruction is split into distinct bit-fields:

Instruction Format: [ OPCODE | OPERAND 1 | OPERAND 2 | ... ] Example (ADD A, B): [ ADD | A | B ]
  • Opcode (Operation Code): Specifies the action to be performed (e.g., ADD, SUB, MOV, JMP). If a system supports $N$ unique opcodes, the Opcode field requires at least $\lceil \log_2 N \rceil$ bits.
  • Operand(s): The data inputs or memory/register addresses on which the operation takes place. Can be explicit or implicit.
  • Mode Field (Optional): Specifies the addressing mode (Direct, Indirect, Indexed, Immediate).
🔥 IBPS SO IT & GATE High-Yield Numerical

Problem: A computer has 32-bit instructions and 128 CPU registers. If there are 64 distinct opcodes, calculate the number of bits remaining for a memory address field in a 2-address instruction format.

Step-by-step Solution:
1. Opcode bits required = $\log_2(64) = 6 \text{ bits}$.
2. Register address bits = $\log_2(128) = 7 \text{ bits}$ per register.
3. Total bits used by Opcode + 1 Register = $6 + 7 = 13 \text{ bits}$.
4. Remaining bits for Memory Address = $32 - (6 + 7) = 19 \text{ bits}$.
$\implies$ Maximum directly addressable memory size = $2^{19} \text{ words} = 512 \text{ KB}$.
📋 3. Categories / Types of Instructions (PDF Page 5)

Instructions in CPU instruction sets (like Intel 8085/8086, ARM, MIPS) are categorized based on their functional role:

Instruction Category Common Mnemonics Primary Function & IBPS Exam Clue
1. Data Transfer MOV, LOAD, STORE, PUSH, POP, XCHG Copies data between registers and memory without altering flags.
2. Arithmetic ADD, SUB, INC, DEC, MUL, DIV Performs mathematical operations in ALU; updates zero ($Z$), carry ($CY$), sign ($S$) flags.
3. Logical & Bit Manipulation AND, OR, NOT, XOR, CMP, TEST, SHL, SHR Bitwise Boolean operations and logical shifts; XOR A, A clears register A to 0.
4. Branch / Program Control JMP, JZ, JNZ, CALL, RET Alters sequential program flow by updating Program Counter ($PC$).
5. Input / Output (I/O) IN, OUT Transfers data between CPU registers and external peripheral ports.
6. System / Machine Control HLT, NOP, EI, DI Stops execution (HLT) or consumes clock cycles for timing delay without operation (NOP).
⚙️ 4. Instruction Format Types (0, 1, 2, 3-Address) (PDF Page 8)

Instructions are classified based on the number of explicit memory/register addresses specified in the instruction word:

0-Address Format (Stack Architecture)

Example: ADD
Operands are implicit at the Top of Stack ($TOS$). Operates by popping two values and pushing the sum.
Used in Stack-based machines (e.g. JVM).

1-Address Format (Accumulator Architecture)

Example: ADD X
One operand is explicit ($X$); second operand and destination are implicitly the Accumulator ($AC$).
AC ← AC + M[X]

2-Address Format (General Register Architecture)

Example: ADD A, B
Two explicit addresses. Destination overwrites one of the source operands.
A ← A + B
Most common in CISC (e.g. x86).

3-Address Format (RISC / Register-Register)

Example: ADD A, B, C
Three explicit addresses: Destination, Source 1, Source 2.
A ← B + C
Shortest program length, used in RISC.

🔄 5. Instruction Execution Cycle & Micro-operations (PDF Page 6)

Every instruction undergoes a 4-phase execution lifecycle in the CPU:

[ FETCH ] ──► [ DECODE ] ──► [ EXECUTE ] ──► [ STORE / WRITE-BACK ]
  • 1. Fetch Phase: The CPU fetches the instruction byte from memory address stored in Program Counter ($PC$) into Instruction Register ($IR$). Micro-operations:
    $$\text{MAR} \leftarrow \text{PC}$$ $$\text{MDR} \leftarrow \text{M}[\text{MAR}], \quad \text{PC} \leftarrow \text{PC} + 1$$ $$\text{IR} \leftarrow \text{MDR}$$
  • 2. Decode Phase: The Control Unit ($CU$) decodes the opcode bits in $IR$ to generate control signals and identify addressing modes.
  • 3. Execute Phase: ALU performs arithmetic or logical operations specified by the opcode.
  • 4. Store / Write-Back Phase: Results are written back to destination registers or RAM addresses.
⚖️ 6. RISC vs CISC Architecture Comparison (PDF Page 9 & 10)
Feature / Parameter RISC (Reduced Instruction Set) CISC (Complex Instruction Set)
Instruction Set Size Small, simple, fixed length (e.g., 32 bits) Large, complex, variable length (1 to 15 bytes)
Execution Speed & CPI 1 instruction per clock cycle ($\text{CPI} \approx 1$) Multiple clock cycles per instruction ($\text{CPI} > 1$)
Memory Access Architecture Load/Store only (ALU operations occur only in registers) Memory-to-Memory operations permitted
Control Unit Type Hardwired Control Unit (Fast, hardware based) Microprogrammed Control Unit (ROM microcode based)
Register File Size Large number of general-purpose registers (32 to 128) Smaller number of registers (8 to 16)
Pipelining Suitability Highly optimized for pipelined execution Difficult to pipeline due to variable length
Real-world Examples ARM (Smartphones, Apple Silicon), MIPS, RISC-V Intel x86 (Pentium, Core i3/i5/i7/i9), AMD64
📝 7. IBPS SO IT Mains Practice Questions

Q1. In a 1-address instruction format, which register implicitly stores one of the operands and the final result?

A) Program Counter (PC)
B) Instruction Register (IR)
C) Accumulator (AC)
D) Memory Address Register (MAR)

View Answer & Explanation

Correct Answer: C) Accumulator (AC)
In 1-address machines, ADD B means $AC \leftarrow AC + M[B]$. Accumulator is the implicit source and destination.

Q2. Which instruction format is used in Stack-oriented architectures where operands are implicitly popped from the stack?

A) Zero-address format
B) One-address format
C) Two-address format
D) Three-address format

View Answer & Explanation

Correct Answer: A) Zero-address format
Zero-address instructions specify no explicit memory/register operands in the instruction word (e.g. ADD pops $TOS$ and $TOS-1$).

Q3. Which of the following statements is TRUE regarding RISC architecture?

A) Uses microprogrammed control unit
B) Arithmetic operations can directly operate on memory operands
C) Only LOAD and STORE instructions access main memory
D) Instructions have variable word lengths

View Answer & Explanation

Correct Answer: C) Only LOAD and STORE instructions access main memory
RISC follows a strict Load/Store architecture. All arithmetic and logical operations are executed exclusively between CPU registers.
