Computer Network Basics
Components, criteria & geographical classification (PAN to WAN)
Computer Network: A collection of interconnected devices that communicate and share resources.
Main Components
  • Sender & Receiver
  • Transmission medium (wired or wireless)
  • Message / Data
  • Protocol (set of rules governing communication)
Network Criteria
1. Performance

Throughput, transit time, response time, and delay.

2. Reliability

Frequency of failure, recovery time, and robustness.

3. Security

Protection from unauthorized access, damage & data loss.

Network Topologies
Bus, Star, Ring, Mesh, Tree, Hybrid
Bus Topology

All devices share one common backbone cable. Cheap, but backbone failure halts entire network. High collision rate.

Star Topology ⭐

All devices connect to a central hub/switch. Easy to manage; central failure brings network down. Most common LAN topology.

Ring Topology

Each device connects to two neighbors. Token travels in ring. Break in ring disrupts network (unless dual ring exists).

Mesh Topology ⭐

Every device has dedicated point-to-point links to other devices. (n-1)/2$ links for $ nodes. Extremely reliable & fault-tolerant, but expensive.

Tree Topology

Hierarchical combination of star networks (Root → Parent → Child).

Hybrid Topology

Combination of two or more different topologies (e.g. Star-Bus, Star-Ring).

Transmission Modes
Simplex, Half Duplex, Full Duplex
Simplex (↑)

Unidirectional (one-way only).
Example: Keyboard → CPU, TV / Radio broadcast.

Half Duplex (↑↓ not simultaneous)

Both directions, but one at a time.
Example: Walkie-talkie.

Full Duplex (↑↓ simultaneous)

Both directions simultaneously.
Example: Telephone conversation, modern full-duplex Ethernet.

4
Data Communication Components
Analog vs Digital, Bit Rate, Baud Rate
  • Analog Signal: Continuous wave signal (e.g. human voice).
  • Digital Signal: Discrete signal represented using 0 and 1.
  • Bit Rate: Number of bits transmitted per second (bps).
  • Baud Rate: Number of signal symbols transmitted per second.
🔑 Key Formula
Bit Rate = Baud Rate × Bits per Symbol
For binary signaling (1 bit per symbol): 1 baud = 1 bit/sec.

Switching Techniques
Circuit Switching, Packet Switching (Datagram vs Virtual Circuit), Message Switching
Switching TypeHow It WorksKey Features
Circuit SwitchingDedicated end-to-end physical path reserved before transmission. (Setup → Transfer → Teardown).Predictable performance, wastes idle bandwidth. Used in PSTN telephony.
Packet Switching ⭐Data split into discrete packets; packets routed independently or via logical circuits.High efficiency, statistical multiplexing. Internet primarily uses packet switching.
Message SwitchingEntire message stored and forwarded at each intermediate node.No dedicated path, requires massive intermediate storage, high delay.
Datagram Packet Switching

Connectionless. Each packet treated independently and can take different routes. Out-of-order arrival possible. (IP network).

Virtual Circuit Packet Switching

Connection-oriented. Pre-planned logical path established before data transfer. Packets arrive in order.

Physical Layer Metrics & Delays HIGH YIELD
Bandwidth, Throughput, Transmission, Propagation, Total Delay
Bandwidth vs Throughput

Bandwidth: Theoretical maximum data capacity (bps).
Throughput: Actual rate of successful data transfer.

Latency / Delay

Time taken for complete data packet to reach destination.

Key Delay Formulas 🔥
Transmission Delay (Tx) = Packet Size (L) / Bandwidth (B) Propagation Delay (Tp) = Distance (d) / Propagation Speed (v) Total Delay ≈ Transmission + Propagation + Queuing + Processing

Nyquist Bit Rate & Shannon Channel Capacity TOP PRIORITY 🔥
Noiseless vs Noisy Channel Capacity
Nyquist Theorem (Noiseless Channel)
Bit Rate = 2B log&sub2;L

B = Bandwidth (Hz), L = Number of signal levels.

Shannon Capacity (Noisy Channel)
Capacity C = B log&sub2;(1 + S/N)

B = Bandwidth (Hz), S/N = Signal-to-Noise ratio (linear value).

🧠 Exam Distinction
Nyquist → Noiseless  |  Shannon → Noisy Channel

Data Link Layer Responsibilities
Framing, MAC addressing, Error control, Flow control, Access control
  • Framing: Packaging Network-layer packets into frames.
  • Physical / MAC Addressing: Adding source and destination 48-bit MAC addresses.
  • Error Detection & Control: Detecting corrupted frames (CRC, Parity, Checksum) and requesting retransmission (ARQ).
  • Flow Control: Preventing fast sender from swamping slow receiver (Sliding window).
  • Access Control / Media Access: Coordinating channel access on shared media (CSMA/CD, CSMA/CA, ALOHA).

Error Detection Techniques TOP PRIORITY 🔥
Parity Bit, Checksum, CRC (Cyclic Redundancy Check)
TechniqueMechanismKey Advantage / Limitation
Parity BitSingle bit added (Even parity = even number of 1s; Odd parity = odd 1s).Detects single-bit errors; fails for even number of error bits.
ChecksumData divided into 16-bit segments, 1s-complement sum calculated and inverted.Used in IP, TCP, UDP headers.
CRC (Cyclic Redundancy Check) ⭐Binary polynomial division. Divides data bits by generator polynomial; appends remainder.Extremely powerful; detects all burst errors of length ≤ generator degree.

Hamming Distance & Error Bounds HIGH YIELD
Minimum Hamming distance $ for detection and correction
Hamming Distance ($) = Minimum number of bit positions in which two valid codewords differ.
🔑 Golden Formulas
To detect up to $ errors: Minimum Hamming distance \ge e + 1$
To correct up to $ errors: Minimum Hamming distance \ge 2t + 1$ (or = \lfloor(d-1)/2 floor$)

Flow Control in Data Link Layer
Stop-and-Wait vs Sliding Window Protocol
Stop-and-Wait

Sender transmits 1 frame, then waits for ACK before sending next. Simple, but very low link utilization on long-distance high-speed links.

Sliding Window

Allows sender to transmit multiple frames up to window size $ before waiting for ACKs. Significantly higher bandwidth utilization.

Stop-and-Wait ARQ, Go-Back-N, Selective Repeat
ARQ ProtocolSender Window ($)Receiver Window ($)Retransmission Behavior on Error
Stop-and-Wait ARQ11Retransmits current unacknowledged frame on timeout.
Go-Back-N (GBN) ⭐$ (^k - 1$)1Discard lost frame and ALL subsequent frames; retransmits from lost frame onward. Uses Cumulative ACKs.
Selective Repeat (SR) ⭐^{k-1}$^{k-1}$ ( = W_r$)Retransmits ONLY the specific damaged/lost frame. Receiver buffers out-of-order frames. Uses Individual/Negative ACKs.

ALOHA Protocols
Pure ALOHA (18.4%) vs Slotted ALOHA (36.8%)
Pure ALOHA

Transmit whenever data is ready. Vulnerable collision period = imes T_{fr}$. Maximum theoretical efficiency = 18.4% (/2e$).

Slotted ALOHA

Time divided into discrete slots; transmit only at slot boundary. Vulnerable time = {fr}$. Maximum efficiency = 36.8% (/e$).

19
CSMA (Carrier Sense Multiple Access) TOP PRIORITY 🔥
CSMA/CD (Ethernet) vs CSMA/CA (Wi-Fi)
CSMA Rule: "Listen before talk" — Sense the channel before transmitting.
CSMA/CD (Collision Detection)

Used in traditional shared Ethernet (wired). Transmits and listens simultaneously; if collision detected → sends Jam signal → applies Exponential Backoff → retransmits.

CSMA/CA (Collision Avoidance)

Used in Wi-Fi (wireless 802.11). Wireless transceivers cannot reliably detect collisions while transmitting. Uses IFS, Contention Window & RTS/CTS handshake.

32-bit address, Dotted-Decimal Notation, Network ID + Host ID
IPv4 address = 32 bits (4 bytes). Represented in dotted decimal: 4 octets (0–255 each), e.g. 192.168.1.10.
Structure: Network ID (NetID) + Host ID (HostID).

Special IPv4 Addresses
Loopback (127.0.0.1), APIPA (169.254.x.x), Broadcast
  • Loopback Address: 127.0.0.1 (tests local TCP/IP stack without sending packets on wire).
  • APIPA (Automatic Private IP Addressing): 169.254.0.0/16 — automatically self-assigned when DHCP server fails.
  • Limited Broadcast: 255.255.255.255 (all hosts on local subnet, not forwarded by routers).
  • Directed Broadcast: Host bits all 1s (e.g. 192.168.1.255).

Subnetting & CIDR TOP PRIORITY 🔥
Classless Inter-Domain Routing & Host Formulas
Subnetting splits a large network into smaller broadcast domains, improving address utilization and security.
🔑 Usable Hosts Formula
For a subnet with $ host bits (CIDR mask 32 - h$):
Total IP addresses = ^h$
Usable Host addresses = ^h - 2$ (subtracts Network ID and Broadcast address).
Example: /24 has =8$ → ^8 - 2 = 254$ usable hosts.

IPv6 Addressing
128-bit address, Hex representation, No broadcast
  • Address Length: 128 bits (16 bytes).
  • Notation: 8 groups of 4 hexadecimal digits separated by colons (e.g. 2001:0db8::1).
  • Loopback Address: ::1  |  Unspecified: ::
  • No Broadcast in IPv6: Replaced by Multicast and Anycast.
  • Built-in IPsec support and simplified fixed 40-byte base header.

NAT & PAT (Network Address Translation)
Private to Public IP translation & Port Address Translation
NAT (Network Address Translation)

Translates private IP addresses to public routable IP addresses. Conserves public IPv4 addresses and adds security.

PAT / NAT Overload ⭐

Multiple internal private hosts share a single public IP address by mapping unique source port numbers.

ARP & RARP TOP PRIORITY 🔥
Address Resolution Protocol (IP to MAC)
ARP (Address Resolution Protocol) ⭐

Resolves IPv4 Address → MAC Address. Broadcasts request on local network; target unicasts reply.

RARP (Reverse ARP)

Resolves MAC Address → IP Address (Historical; superseded by BOOTP & DHCP).

31
ICMP (Internet Control Message Protocol)
Error reporting & Diagnostics (ping, traceroute)
ICMP operates at the Network Layer (Layer 3) alongside IP (IP Protocol number = 1). It is NOT a transport protocol.
  • Used for error reporting (e.g. Destination Unreachable, Time Exceeded).
  • ping uses ICMP Echo Request (Type 8) & Echo Reply (Type 0).
  • traceroute uses ICMP Time Exceeded (Type 11) messages triggered by incrementing TTL.
32
Static vs Dynamic Routing
Manual configuration vs automated routing protocol updates
Static Routing

Routes configured manually by network administrator. Secure and zero protocol overhead, but does not adapt automatically to link failures.

Dynamic Routing

Routers exchange topology/cost info dynamically via protocols (RIP, OSPF, BGP). Automatically recalculates paths on link failure.

Routing Algorithms
Distance Vector (Bellman-Ford) vs Link State (Dijkstra) vs Path Vector

Distance VectorRIPRouters periodically send entire routing table to immediate neighbors (Bellman-Ford).Count-to-Infinity problem (Mitigated by Split Horizon, Route Poisoning, Holddown timers).

Autonomous Systems (AS), IGP vs EGP
Intra-domain vs Inter-domain routing
Autonomous System (AS) = Collection of IP networks and routers under a single administrative control.
IGP (Interior Gateway Protocol)

Transport Layer Responsibilities
Process-to-process delivery, port addressing, multiplexing
  • Process-to-Process Delivery: Identifies specific target application using 16-bit Port Numbers.
  • Connection Management: Establishes, maintains, and terminates connections (TCP 3-way handshake).

39
TCP Connection Termination & Flags
FIN / ACK teardown & 6 Control Flags
  • Termination: 4-step teardown (FIN → ACK → FIN → ACK).
  • 6 Main Control Flags:
    • SYN: Synchronize sequence numbers (connection start).
    • ACK: Acknowledgment field is valid.
    • FIN: Finished (no more data from sender).
    • RST: Reset the connection.
    • PSH: Push data immediately to application layer.
    • URG: Urgent pointer field is significant.
40
TCP Reliability Mechanisms
Sequence numbers, cumulative ACKs, retransmission timer
  • Byte Sequence Numbers: Every byte is assigned a sequence number.
  • Cumulative ACKs: ACK = N indicates all bytes up to -1$ have been successfully received.
  • Retransmission Timeout (RTO): Dynamically calculated based on Round Trip Time (RTT).
  • Checksum: Detects corrupted segments.
41
TCP Flow Control
Receive Window (rwnd) advertised in header
TCP uses an end-to-end sliding window flow control mechanism via the Receive Window (rwnd) field advertised by the receiver in each ACK. It prevents a fast sender from overflowing receiver buffers.

TCP Congestion Control TOP PRIORITY 🔥
Slow Start, Congestion Avoidance, Fast Retransmit, Fast Recovery
PhaseGrowth Rate / Behavior
Slow StartCongestion Window ($) starts at 1 MSS and doubles every RTT (exponential growth) until reaching ssthresh.
Congestion AvoidanceStarts when \ge ssthresh$; $ grows by 1 MSS per RTT (linear growth / additive increase).

Cryptography in Networking
Symmetric (AES) vs Asymmetric (RSA)
Symmetric Encryption

Same shared secret key for encryption and decryption. Fast, ideal for bulk data. Examples: AES, DES, 3DES.

Asymmetric Encryption

Public key (encrypt/verify) + Private key (decrypt/sign). Solves key distribution. Examples: RSA, ECC, Diffie-Hellman.

62
Hashing
One-way fixed length digest (SHA-256 vs MD5)
Hash function: One-way mathematical transformation producing a fixed-size digest. Hashing ≠ Encryption (cannot be reversed).
Secure: SHA-256, SHA-512  |  Broken: MD5, SHA-1.

🔑 Digital Signature Rules
Sender signs with their PRIVATE KEY  |  Receiver verifies using sender's PUBLIC KEY.

Digital Certificate & CA
X.509 standard binding Public Key to Identity
Digital Certificate binds an identity to a public key, signed by a trusted Certificate Authority (CA) following the X.509 format.

SSL vs TLS
Transport Layer Security evolution
  • SSL (Secure Sockets Layer): Deprecated and cryptographically broken (POODLE attack).
  • TLS (Transport Layer Security): Modern secure successor (TLS 1.2 and TLS 1.3). Powers HTTPS.

  • QoS (Quality of Service): Mechanisms to prioritize sensitive traffic (voice/video) over bulk data.

74
IPv4 Header Structure NEW
20–60 Bytes, IHL, TTL, Protocol field
Minimum size: 20 bytes (up to 60 bytes with Options).
  • Version (4 bits), IHL (Header Length in 4-byte words), Total Length (16 bits).
  • Identification, Flags, Fragment Offset: Controls fragmentation.
  • TTL (Time to Live) ⭐: Decrements by 1 at each router hop. Discarded when TTL=0 (prevents routing loops; basis of traceroute).
  • Protocol field: 6 = TCP, 17 = UDP, 1 = ICMP, 2 = IGMP.
  • Header Checksum: Verifies IP header integrity only.
75
TCP Header Structure NEW
20–60 Bytes, Sequence/Ack, Flags, Window Size
Minimum size: 20 bytes.
  • Source & Destination Ports: 16 bits each.
  • Sequence Number (32 bits) & Acknowledgment Number (32 bits).
  • Data Offset / Header Length (4 bits).
  • 6 Control Flags: URG, ACK, PSH, RST, SYN, FIN.
  • Window Size (16 bits): Receiver flow control window (rwnd).
  • Checksum (16 bits) & Urgent Pointer (16 bits).
76
UDP Header Structure NEW
Fixed 8 Bytes header
Fixed size: 8 bytes total (4 fields of 2 bytes each).
[ Source Port (16 bits) | Destination Port (16 bits) ] [ Length (16 bits) | Checksum (16 bits) ]
77
Bandwidth-Delay Product (BDP) & Window Size NEW
Optimal sliding window sizing
🔑 BDP Formula
BDP = Bandwidth × Round Trip Time (RTT)
Represents maximum unacknowledged data "in-flight" on the link. For 100% link utilization: Window Size ≥ BDP.
78
Piggybacking NEW
Attaching ACK to outgoing data frames
Piggybacking: Attaching the acknowledgment of a received frame onto the next outgoing data frame instead of sending a separate standalone ACK. Saves network bandwidth and header overhead in full-duplex transmission.
79
Congestion Control: Leaky Bucket vs Token Bucket NEW ⭐
Traffic shaping & policing algorithms
Leaky Bucket Algorithm

Smooths out bursty traffic into a strictly constant uniform output rate (like water leaking from a hole). Drops excess packets on overflow.

Token Bucket Algorithm

Tokens generated at constant rate. Packets sent only if tokens available. Allows controlled bursty traffic up to token capacity.

Managing IPv4 multicast memberships
IGMP operates at the Network Layer (Layer 3). Used by hosts and adjacent routers to establish and manage multicast group memberships on IPv4 local networks.

DNS Query Types NEW
Recursive vs Iterative Queries
Recursive Query

Client asks DNS server: "Find the full answer for me." The DNS server contacts other servers itself and returns the final IP or error.

Iterative Query

DNS server returns the best answer it has (referral to next name server); client queries the next server itself.

Types of ARP NEW
Proxy ARP, Gratuitous ARP, Reverse ARP
  • Proxy ARP: A router answers ARP requests on behalf of a host on another subnet.
  • Gratuitous ARP: Unsolicited broadcast of own IP-to-MAC mapping to update neighbor caches and detect duplicate IP conflicts.
  • Reverse ARP (RARP): Resolves MAC → IP (Legacy).

Preventing Layer 2 loops and broadcast storms
STP (IEEE 802.1D) prevents Layer 2 switching loops in redundant topologies by blocking specific redundant switch ports while keeping them available as backup. Uses BPDUs (Bridge Protocol Data Units).

MTU & IP Fragmentation NEW
Maximum Transmission Unit (1500 bytes on Ethernet)
  • MTU (Maximum Transmission Unit): Largest IP packet size a link can carry without fragmentation (Ethernet default = 1500 bytes).
  • IPv4 Fragmentation: Intermediate routers fragment oversized packets if DF (Don't Fragment) = 0.
  • IPv6 Fragmentation: Routers NEVER fragment in IPv6. Source host performs Path MTU Discovery and fragments at origin only.
98
TTL & Traceroute Mechanism NEW
ICMP Time Exceeded & Hop-by-Hop Path Discovery
Traceroute sends packets with incrementally increasing TTL values (TTL=1, TTL=2, TTL=3...). Each intermediate router decrements TTL to 0, drops the packet, and responds with an ICMP Time Exceeded (Type 11) message, revealing its IP address and hop delay.
