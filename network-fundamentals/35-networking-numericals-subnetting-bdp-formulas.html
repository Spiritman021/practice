35.1 Subnetting Formulas & Solved Examples

🧮
Master Subnetting Formulas & Quick Tricks
1. Total Host Addresses per Subnet = 2(32 - CIDR)
2. Usable Hosts per Subnet = 2(32 - CIDR) - 2 (subtract Network ID and Broadcast IP)
3. Number of Subnets Created = 2(Subnet Bits Borrowed)
4. Magic Block Size Trick = 256 - (Subnet Mask Octet Value)

Problem 1: FLSM Subnetting Analysis

Question: An organization is assigned IP prefix 192.168.10.0/27. Determine the Subnet Mask, Block Size, Total Usable Hosts per subnet, Network ID, First Usable Host, Last Usable Host, and Broadcast Address for the first subnet.

Solution:
• Subnet Mask: CIDR /27 means 27 ones in binary: 11111111.11111111.11111111.11100000 → 255.255.255.224
• Block Size: 256 - 224 = 32 (Subnets jump in steps of 32!)
• Usable Hosts: 32 - 2 = 30 hosts per subnet
• Subnet 0 Ranges:
  - Network ID: 192.168.10.0
  - First Usable Host: 192.168.10.1
  - Last Usable Host: 192.168.10.30
  - Broadcast Address: 192.168.10.31

Bandwidth-Delay Product (BDP) Solved Numericals

📐
Bandwidth-Delay Product Formula
BDP = Bandwidth (bps) × Round-Trip Time (RTT in seconds)
BDP represents the maximum number of bits that can be "in flight" in the network pipe at any instant.

Problem 2: BDP & Window Size Calculation

Question: A point-to-point link has a bandwidth of 100 Mbps and a Round-Trip Time (RTT) of 50 ms. Calculate: (a) The Bandwidth-Delay Product (BDP) in Bytes, and (b) The minimum TCP Receiver Window size required to achieve 100% link utilization.

Solution:
• Bandwidth $B = 100 \text{ Mbps} = 100 \times 10^6 \text{ bits/sec}$
• RTT $= 50 \text{ ms} = 0.05 \text{ seconds}$
• (a) $\text{BDP in bits} = 100 \times 10^6 \times 0.05 = 5,000,000 \text{ bits}$
• $\text{BDP in Bytes} = \frac{5,000,000}{8} = \mathbf{625,000 \text{ Bytes} \ (625 \text{ KB})}$
• (b) Minimum TCP Window Size = BDP = 625,000 Bytes.

35.3 ARQ Protocol Efficiency & Window Size Numericals

🔄
Sliding Window Efficiency Formulas
• Transmission Delay: Tt = Packet Length (L) / Bandwidth (B)
• Propagation Delay: Tp = Distance (d) / Velocity (v)
• Delay Ratio: a = Tp / Tt
• Stop-and-Wait Efficiency (η): η = Tt / (Tt + 2 Tp) = 1 / (1 + 2a)
• Optimal Sliding Window Size (N): N = 1 + 2a = 1 + 2(Tp / Tt)
• Throughput: Throughput = η × Bandwidth

Problem 3: Stop-and-Wait ARQ Efficiency

Question: A packet of size 1000 Bytes is sent over a 1 Mbps link. The propagation delay between sender and receiver is 20 ms. Calculate: (a) $T_t$, (b) $T_p$, (c) Efficiency $\eta$, and (d) Optimal window size $N$ for 100% throughput.

Solution:
• Packet Length $L = 1000 \text{ Bytes} = 8000 \text{ bits}$
• Bandwidth $B = 1 \text{ Mbps} = 10^6 \text{ bits/sec}$
• (a) $T_t = \frac{8000}{10^6} = 0.008 \text{ sec} = \mathbf{8 \text{ ms}}$
• (b) $T_p = \mathbf{20 \text{ ms}}$
• (c) $a = \frac{T_p}{T_t} = \frac{20}{8} = 2.5$
• $\eta = \frac{1}{1 + 2a} = \frac{1}{1 + 2(2.5)} = \frac{1}{6} = \mathbf{16.67\%}$
• (d) Optimal Window Size $N = 1 + 2a = 1 + 5 = \mathbf{6 \text{ frames}}$.

Nyquist & Shannon Channel Capacity Numericals

Formula NameEquationVariables
Nyquist Bit Rate (Noiseless Channel) $\text{Bit Rate} = 2 \times B \times \log_2(V)$ $B$ = Bandwidth (Hz), $V$ = Signal discrete voltage levels
Shannon Capacity (Noisy Channel) $C = B \times \log_2(1 + \text{SNR})$ $B$ = Bandwidth (Hz), $\text{SNR}$ = Signal-to-Noise Ratio (linear)

Problem 4: Shannon Capacity Calculation

Question: A telephone channel has a bandwidth of 3 kHz and a Signal-to-Noise ratio ($\text{SNR}_{\text{dB}}$) of 30 dB. Calculate the maximum theoretical channel capacity $C$ in kbps.

Solution:
• Convert $\text{SNR}_{\text{dB}}$ to linear scale: $\text{SNR}_{\text{dB}} = 10 \log_{10}(\text{SNR}) = 30 \implies \text{SNR} = 10^3 = 1000$
• $C = B \times \log_2(1 + \text{SNR}) = 3000 \times \log_2(1 + 1000) \approx 3000 \times \log_2(1001)$
• Since $\log_2(1024) = 10$, $\log_2(1001) \approx 9.97$
• $C = 3000 \times 9.97 = \mathbf{29,910 \text{ bps} \ \approx 30 \text{ kbps}}$.

35.5 Hamming Code & CRC Error Correction Numericals

📌
Hamming Parity Bits Condition
2r ≥ m + r + 1
where m is the number of data bits and r is the minimum number of parity/redundancy bits required.

Problem 5: Hamming Parity Bits Calculation

Question: How many parity bits $r$ are required to transmit a 7-bit ASCII data payload ($m = 7$) using Hamming error correction code?

Solution:
• Test values of $r$ in $2^r \ge 7 + r + 1 = 8 + r$:
  - Try $r = 3$: $2^3 = 8 \ge 8 + 3 = 11$ (False!)
  - Try $r = 4$: $2^4 = 16 \ge 8 + 4 = 12$ (True!)
• Minimum parity bits required = 4 bits (Total codeword length = 7 + 4 = 11 bits).
