29.1 Attack Classification (Passive vs Active)

Eavesdropping
Passive Attacks
Attacker monitors and records network traffic without altering payload contents or system resources. Hard to detect. (Packet sniffing, Traffic analysis).
Disruption
Active Attacks
Attacker actively modifies data, injects malicious code, or degrades network availability. (DoS, MITM, IP Spoofing, Session Hijacking).

29.2 DoS & DDoS Attacks (SYN Flood, Amplification)

A Denial of Service (DoS) attack aims to make a network service unavailable to legitimate users. A **DDoS (Distributed DoS)** uses a botnet of thousands of compromised devices (zombies) to flood the target simultaneously.

Key DoS/DDoS Vectors

  • TCP SYN Flood: Attacker sends thousands of TCP SYN requests with spoofed IP addresses. Target server allocates memory for half-open connections until SYN queue fills up, causing legitimate requests to be dropped. (Defended via SYN Cookies!).
  • UDP Flood: Floods random UDP ports on target with massive datagram bursts, exhausting server bandwidth.
  • ICMP Ping of Death: Sends oversized/malformed ICMP echo packets that crash vulnerable network stacks during reassembly.
  • DNS / NTP Amplification Attack: Attacker sends tiny DNS requests with spoofed victim IP to open DNS resolvers. Resolvers reply to victim with 50x larger response payloads!

Section 29.3

Man-in-the-Middle (MITM) & ARP Poisoning

In a Man-in-the-Middle (MITM) attack, the attacker secretly intercepts and alters communication between two legitimate nodes without their knowledge.

ARP Poisoning / ARP Spoofing

Attacker sends forged ARP response messages over the local LAN binding their MAC address to the Default Gateway's IP address. All client traffic flows through the attacker's machine before reaching the router!

Section 29.4

IP, MAC & DNS Spoofing Attacks

  • IP Spoofing: Forging the Source IP header field in IP packets to impersonate a trusted host or hide attacker identity.
  • MAC Spoofing: Changing a network interface's factory MAC address to bypass MAC filtering or impersonate authorized devices.
  • DNS Cache Poisoning: Injecting false IP mappings into a DNS resolver's cache (e.g. mapping bank.com → 66.66.66.66 attacker IP) to redirect users to malicious phishing pages.

Phishing & Social Engineering Vectors

Phishing VectorTarget & Mechanism

Spear PhishingHighly customized, targeted attack directed at a specific individual or organization.
