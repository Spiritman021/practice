🎯 1. What is an Addressing Mode? (PDF Page 2)

An addressing mode specifies the rule or mechanism used by the CPU to locate the operand (data) needed by an instruction.

Instruction = [ OPCODE | ADDRESS MODE FIELD | ADDRESS / OPERAND FIELD ] Opcode → What operation to perform (e.g., ADD, MOV, JMP) Operand → The data or location where the data resides Mode → How to interpret the address field to find Effective Address (EA)

Effective Address (EA): The actual physical memory address of the operand in RAM or CPU register where the operand is fetched during the execution phase.

⚡ 2. Comprehensive Guide to All 8 Addressing Modes (PDF Pages 3–10)

1. Immediate Mode FASTEST

The operand is specified directly inside the instruction itself. No memory or register lookup is needed for data.

Effective Address: N/A (Data in Instruction)

Example: MOV R1, #5 (Loads value 5 into R1)

💡 Real-life Analogy: You already know the number in your mind.

2. Register Mode VERY FAST

The operand is stored in a CPU register specified by the instruction register field.

Effective Address: EA = R (Register R)

Example: MOV R1, R2 (Copies R2 content to R1)

📱 Real-life Analogy: Phone number is saved directly in your contacts list.

3. Direct / Absolute Mode SIMPLE

The instruction contains the explicit memory address of the operand.

Effective Address: EA = A (Address Field)

Example: MOV A, [5000] (Reads memory location 5000 into A)

📄 Real-life Analogy: Address is written directly on a sheet of paper.

4. Register Indirect Mode POINTERS

The register holds the memory address of the operand rather than the data itself.

Effective Address: EA = [R] (Contents of R)

Example: MOV A, [R1] (Reads RAM location stored in R1)

📔 Real-life Analogy: Paper says: "Look up contact stored in Diary".

5. Indexed Mode ARRAY A[i]

Effective address is computed by adding an Index Register ($IX$) to a base displacement address.

Effective Address: EA = Index Reg + Base Addr

Example: MOV A, [R1 + 5] (Accesses array element $A[i]$)

🔢 Real-life Analogy: Locating the 5th person in a sorted queue.

6. PC-Relative Mode JUMPS & LOOPS

Effective address is calculated by adding an offset to the Program Counter ($PC$). Used in branch/jump instructions.

Effective Address: EA = PC + Offset

Example: JUMP LOOP (Jumps relative to current PC location)

⏭️ Real-life Analogy: Moving 3 steps forward from where you are currently standing.

7. Base Register Mode OS RELOCATION

Effective address is formed by adding a Base Register ($BX$) to a displacement. Enables OS program relocation.

Effective Address: EA = BX + Displacement

Example: MOV A, [BX + 200] (Accesses struct field from base $BX$)

🏢 Real-life Analogy: Building number (Base) + Apartment number (Displacement).

8. Implied / Implicit Mode BUILT-IN

The operand is implicitly defined by the opcode itself. No address field required in instruction word.

Effective Address: Implicit (e.g. Accumulator / Stack)

Example: CLR A (Clear Accumulator), CMA (Complement A)

👩 Real-life Analogy: Saying "Call Mom" — phone already knows who Mom is.
📊 3. Memory Reference Counts & Speed Comparison (PDF Page 11)

Implied Implicit in Opcode 0 Ultra Fast
Immediate Operand in Instruction Word 0 (Only fetch instruction) Ultra Fast
Register $EA = R$ 0 (Operand in Register) Very Fast
Direct / Absolute $EA = \text{Address Field}$ 1 (Access RAM at $EA$) Moderate
Register Indirect $EA = [R]$ 1 (Access RAM at address in $R$) Moderate

🧮 4. Effective Address Calculation - Solved Numericals
🔥 IBPS SO IT / GATE Solved Numerical 1

Problem: In a computer system, the Program Counter ($PC$) currently contains address 2000. A branch instruction located at address 2000 has a PC-Relative offset of -45. What is the Effective Address of the target instruction?

Step-by-step Solution:
1. During instruction fetch, $PC$ auto-increments to next instruction: $PC_{next} = 2000 + 1 = 2001$ (or 2002 if 2-byte instruction).
2. Relative Effective Address formula: $EA = PC_{next} + \text{Offset}$.
3. $EA = 2001 + (-45) = 1956$.
$\implies$ Target Branch Address = 1956.
🔥 IBPS SO IT / GATE Solved Numerical 2

Problem: An instruction MOV A, [R1 + 100] uses Indexed Addressing. If Register R1 contains value 4000, and memory location 4100 contains value 99, what value is loaded into Accumulator A?

Step-by-step Solution:
1. Calculate Effective Address ($EA$): $EA = \text{Contents of R1} + \text{Displacement} = 4000 + 100 = 4100$.
2. Fetch data at RAM address $4100$: $M[4100] = 99$.
$\implies$ Value loaded into Accumulator $A$ = 99.
📝 5. IBPS SO IT Mains Practice Questions

Q1. Which addressing mode requires TWO memory references to fetch the operand?

A) Direct Addressing Mode
B) Register Indirect Addressing Mode
C) Memory Indirect Addressing Mode
D) Immediate Addressing Mode

View Answer & Explanation

Correct Answer: C) Memory Indirect Addressing Mode
Explanation: In Memory Indirect mode, the instruction specifies a memory address containing a pointer. The CPU makes 1st memory access to read the pointer, and 2nd memory access to read the actual operand.

Q2. Which addressing mode is most suitable for stepping through Array elements $A[i]$ in a loop?

A) Immediate Addressing
B) Indexed Addressing
C) Absolute Addressing
D) Implied Addressing

View Answer & Explanation

Correct Answer: B) Indexed Addressing
Explanation: Indexed mode computes $EA = \text{Base} + \text{Index Reg}$. Incrementing the Index Register steps seamlessly to the next array element $A[i+1]$.

Q3. Which addressing mode facilitates program relocation in memory at runtime without modifying address constants?

A) Direct Addressing
B) Register Addressing
C) PC-Relative / Base-Register Addressing
D) Immediate Addressing

View Answer & Explanation

Correct Answer: C) PC-Relative / Base-Register Addressing
Explanation: PC-Relative and Base Register modes compute addresses relative to current position or base segment ($EA = \text{Base} + \text{Offset}$), enabling programs to run anywhere in memory.
