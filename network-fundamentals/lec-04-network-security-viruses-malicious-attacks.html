4.1 Classification of Security Attacks: Passive vs Active

Security attacks are categorized based on whether they alter system data and resources or merely observe them:

1. Passive Attacks
• Definition: Attempts to learn or make use of system information but does NOT affect system resources or alter data.
• Goal: Eavesdropping on or monitoring data transmissions.
• Two Main Types:
  a) Release of Message Contents: Intercepting confidential emails or calls.
  b) Traffic Analysis: Observing message pattern, frequency, and length even if payload is encrypted.
• Detection vs Prevention: Extremely difficult to detect because no data is modified. Focus is on Prevention using Encryption (SSL/TLS, IPsec).
2. Active Attacks
• Definition: Attempts to alter system resources or affect their operation. Involves data modification or creation of false streams.
• Four Main Categories:
  a) Masquerade: Impersonating another entity (IP Spoofing).
  b) Replay: Capturing & retransmitting valid data to produce unauthorized effects.
  c) Message Modification: Altering message contents in transit.
  d) Denial of Service (DoS): Inhibiting legitimate access.
• Detection vs Prevention: Hard to prevent completely. Focus is on Detection & Recovery (Firewalls, IPS, Audit Logs).
Comparison Feature Passive Security Attack Active Security Attack
System Data Alteration No (Data is not modified or corrupted). Yes (Data stream modified, fabricated, or blocked).
Primary Target Confidentiality & Privacy. Integrity & Availability.
Detection Difficulty Very Difficult to Detect (leaves no trace). Easier to Detect (leaves audit logs/error alerts).
Primary Defense Focus Prevention (Encryption, Data Hiding). Detection & Recovery (Firewalls, IPS, Backups).

4.2 Malware Definition & Distribution Vectors

Malware (Malicious Software) is a general term for any software inserted into an information system to cause harm to that system or connected networks.

🌐 Social Engineering & Phishing

Deceptive messages or emails tricking users into executing malicious attachments.

💾 Drive-by Downloads & Media

Infected USB drives, pirated software cracks, or compromised malicious websites.

📦 Network Exploits

Scanning network ports for unpatched OS vulnerabilities to spread autonomously.

4.3 Computer Viruses & The 5 Major Virus Types

A Computer Virus is a piece of code loaded onto a computer without user knowledge. Key Trait: Requires a host file/program to attach to and requires human action to execute.

Virus Category Infection Target & Mechanism Exam Key Characteristics
1. File Infector Virus Attaches to executable program files (e.g. .exe, .com, .sys, .dll). Executes whenever the infected host application is launched.
2. Boot Sector Virus Infects the boot sector / boot record of storage drives (floppy disks, hard drives, USBs). Loads into memory during system boot before the Operating System loads.
3. Master Boot Record (MBR) Virus Infects the Master Boot Record (MBR) controlling the partition table and system boot loader. Prevents OS startup; can destroy disk partition structures.
4. Multipartite Virus (Polypartite) Infects BOTH boot sectors AND executable program files simultaneously. Re-infects system if only file or boot sector is cleaned; hard to eradicate.
5. Macro Virus Written in macro programming languages embedded within Office documents (Word .doc, Excel .xls). Executes automatically when the infected document or spreadsheet is opened.

4.4 Worms vs Trojan Horses vs Spyware vs Ransomware

Understanding the functional distinction between malware types is a high-yield IBPS SO IT requirement:

Malware Type Self-Replicating? Requires Host File? User Interaction Needed? Core Purpose & Behavior
Virus Yes Yes (Attaches to host) Yes (User must execute) Corrupts files, modifies disk sectors, spreads via file sharing.
Worm Yes No (Standalone program) No (Autonomous spread) Traverses network nodes autonomously, consuming bandwidth & system memory.
Trojan Horse No No Yes (Masquerades as valid app) Disguises as useful utility (e.g. game); installs backdoors (RATs), keyloggers.
Spyware Varies Varies No (Lurks silently) Monitors user activity, records keystrokes (keyloggers), steals banking passwords.
Ransomware Varies Varies Yes Encrypts user files or locks OS; demands ransom payment for decryption key.

4.5 Botnets, Adware, Phishing & Spam

🤖 Botnets & Zombie Hosts

A network of malware-infected computers (called "zombies" or "bots") controlled remotely by a Botmaster to launch massive DDoS attacks or send bulk spam emails.

🔒 Ransomware (CryptoLocker / Locky)

Holds computer systems captive by encrypting files using strong asymmetric/symmetric keys. Demands ransom cryptocurrency for recovery.

🎣 Phishing & Social Engineering

Spoofed messages tricking users into surrendering financial data, credentials, or Social Security numbers by linking to fake bank login pages.

📢 Adware & Unwanted Spam

Adware automatically displays pop-up advertisements. Spam refers to bulk unsolicited commercial email carrying malicious attachments.

4.7 IBPS SO IT Verified Solved Question Bank

IBPS SO IT 2022 Verified
Q1. Which category of security attack involves eavesdropping or traffic analysis without altering system resources or modifying data?
A) Passive Attack ✓
B) Active Attack
C) Masquerade Attack
D) Denial of Service Attack
Correct Answer: A) Passive Attack.
Explanation: Passive attacks observe or monitor transmissions without altering data (e.g. eavesdropping, traffic analysis). Active attacks alter data or create false streams.
IBPS SO IT 2023 Verified
Q2. What is the fundamental operational difference between a Computer Virus and a Computer Worm?
A) Viruses spread across networks; worms do not
B) Worms are self-replicating and autonomous; viruses require a host file and user action ✓
C) Trojans require host files; worms do not
D) Viruses cannot infect boot sectors
Correct Answer: B) Worms are self-replicating and autonomous; viruses require a host file.
Key Distinction: A worm spreads automatically across network nodes without human intervention and does not need a host program. A virus attaches to a host executable file and needs execution to spread.
IBPS SO IT 2020 Verified
Q3. A computer virus that infects BOTH executable program files (.exe) AND hard drive boot sectors simultaneously is classified as a:
A) Macro Virus
B) File Infector Virus
C) Multipartite Virus ✓
D) Boot Sector Virus
Correct Answer: C) Multipartite Virus (Polypartite).
Explanation: Multipartite viruses target multiple infection vectors simultaneously—infecting executable files as well as master boot sectors.
IBPS SO IT 2021 Verified
Q4. A malicious software program disguised as a legitimate free computer game that installs a hidden backdoor without self-replicating is a:
A) Worm
B) Trojan Horse ✓
C) Macro Virus
D) Adware
Correct Answer: B) Trojan Horse.
Explanation: Trojan horses masquerade as desirable software and do NOT self-replicate.
IBPS SO IT 2024 Verified
Q5. Why are Passive Attacks extremely difficult to detect in a network environment?
A) Because they bypass firewalls automatically
B) Because they do not involve any alteration or modification of data ✓
C) Because they disable intrusion detection systems
D) Because they only execute during system boot
Correct Answer: B) Because they do not involve any alteration or modification of data.
Explanation: Passive attacks eavesdrop without modifying traffic, leaving no audit trace. Hence prevention (encryption) is the primary line of defense.

4.8 Quick Exam Revision Cheat Sheet

1. Passive Attacks: Eavesdropping, Traffic Analysis. No data alteration. Hard to detect $\rightarrow$ Focus on Prevention (Encryption).

2. Active Attacks: Masquerade, Replay, Message Modification, DoS. Alters data/resources $\rightarrow$ Focus on Detection & Recovery.

3. Virus vs Worm vs Trojan:
• Virus = Host file needed + Replicates + User action required.
• Worm = Standalone + Self-replicating + Autonomous network spread (No host needed).
• Trojan = Disguised as useful app + No self-replication.

4. Virus Types: File Infector (.exe), Boot Sector, MBR, Multipartite (Both files + boot sectors), Macro (Office docs).

5. Spyware & Ransomware: Spyware = Secret credential theft (Keyloggers). Ransomware = File encryption demanding ransom (CryptoLocker, Locky).

6. Famous Malware: ILOVEYOU (2000 Worm), Code Red (2001 IIS Worm), Stuxnet (2010 SCADA Cyberweapon), Pegasus (2020 Spyware).
