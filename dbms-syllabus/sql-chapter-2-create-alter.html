🏗️ 1. CREATE TABLE Command

CREATE TABLE is a DDL (Data Definition Language) command — the very first command you use in any RDBMS workflow because you must define a structure (schema) before storing any data.

📦 Why CREATE TABLE First?
In RDBMS, data is always stored in tables (relations). The table schema — column names and their data types — must be defined before any data can be inserted. This is unlike NoSQL (MongoDB) which is schema-less.

📐 Syntax

SQL — CREATE TABLE Syntax
CREATE TABLE table_name (
    column1_name  datatype,
    column2_name  datatype,
    column3_name  datatype
);
-- NOTE: No comma after the LAST column — only a closing ) and semicolon.
-- Table names with spaces (e.g., "student detail") will cause an ERROR.
-- Use underscore instead: student_detail
⚠️ Common Beginner Mistakes
  • Do NOT put a comma after the last column — it will throw a syntax error.
  • Do NOT use spaces in table names: student detail → Error. Use student_detail instead.
  • Always end the statement with a semicolon (;).

🗄️ Oracle Data Types

📌 VARCHAR vs VARCHAR2 in Oracle
Oracle recommends using VARCHAR2 over VARCHAR. If you use VARCHAR, Oracle silently converts it to VARCHAR2. For portability and clarity, always use VARCHAR2 in Oracle.

💡 Complete Example — Employee Table

Oracle SQL — CREATE TABLE
-- Create an employee table with 3 columns
CREATE TABLE employee (
    id      INT,
    name    VARCHAR2(50),
    salary  NUMBER
);

Table created.

🔍 Viewing the Schema — DESC Command

After creating a table, use the DESC (DESCRIBE) command to inspect its structure — column names, data types, sizes, and constraints.

Oracle SQL — DESC
DESC employee;
-- or: DESCRIBE employee;
Schema Output (DESC employee)
Name     Null?    Type
-------- -------- ------------
ID                NUMBER(38)
NAME              VARCHAR2(50)
SALARY            NUMBER(38)
📋 Reading the DESC Output
  • Name: Column name
  • Null?: Whether NOT NULL or PRIMARY KEY constraint is applied (blank = NULL allowed)
  • Type: Data type and size. NUMBER(10,2) = precision 10, scale 2 (decimal places)
  • INT defaults to NUMBER(38) in Oracle's internal representation

🔧 2. ALTER TABLE Command

ALTER TABLE is also a DDL command. It is used to make changes to the structure (schema) of an already existing table — without deleting it.

💡 When to Use ALTER vs CREATE?
Use CREATE when building something new from scratch. Use ALTER when the table already exists and you need to modify its structure (add/remove/rename columns, change data types, apply/remove constraints).
➕
ADD Column
Add one or more new columns to an existing table
🗑️
DROP Column
Remove an existing column from the table permanently
✏️
MODIFY Column
Change data type or increase/decrease column size
🏷️
RENAME Column / Table
Rename a column or even the whole table
🔑
ADD / DROP Constraint
Add or remove PRIMARY KEY, FOREIGN KEY, NOT NULL, etc.

➕ 2.1 ALTER TABLE — ADD Column

Use ADD to append one or more new columns to an existing table. You must specify the data type — Oracle cannot infer it.

Oracle SQL — ALTER ADD
-- Add a single column
ALTER TABLE employee
ADD address VARCHAR2(200);

-- Add multiple columns at once (wrap in parentheses)
ALTER TABLE employee
ADD (email  VARCHAR2(100),
     phone  VARCHAR2(15));
Output
Table altered.

🗑️ 2.2 ALTER TABLE — DROP Column

Use DROP COLUMN to permanently remove a column. You must include the keyword COLUMN — just DROP alone will not work for columns. No data type needed when dropping.

Oracle SQL — ALTER DROP COLUMN
-- Drop a single column (data type NOT needed)
ALTER TABLE employee
DROP COLUMN address;

-- Drop multiple columns
ALTER TABLE employee
DROP (email, phone);
⚠️ Warning: DROP COLUMN is Irreversible
Dropping a column permanently removes it and all its data. There is no undo unless you have a backup. In production databases, only the DBA (Database Administrator) should perform this operation.

✏️ 2.3 ALTER TABLE — MODIFY Column

Use MODIFY to change the data type or size of an existing column.

Oracle SQL — ALTER MODIFY
-- Change data type: id from INT/NUMBER to VARCHAR2
ALTER TABLE employee
MODIFY id VARCHAR2(10);

-- Increase the size of name column from 50 to 100
ALTER TABLE employee
MODIFY name VARCHAR2(100);
📌 Condition for MODIFY
The new data type must be compatible with the existing data. For example, you can safely change NUMBER to VARCHAR2 (numbers fit in strings), but changing VARCHAR2 to NUMBER will fail if the column contains non-numeric data.

🏷️ 2.4 ALTER TABLE — RENAME Column & Table

Oracle SQL — ALTER RENAME
-- Rename a column: id → roll_number
ALTER TABLE employee
RENAME COLUMN id TO roll_number;

-- Rename the whole table: employee → employee_detail
ALTER TABLE employee
RENAME TO employee_detail;

🔑 2.5 ALTER TABLE — ADD / DROP Constraints

Oracle SQL — ALTER Constraints
-- Add a PRIMARY KEY constraint to roll_number
ALTER TABLE employee
ADD PRIMARY KEY (roll_number);

-- Add a NOT NULL constraint (using MODIFY in Oracle)
ALTER TABLE employee
MODIFY name VARCHAR2(100) NOT NULL;

-- Add a FOREIGN KEY constraint
ALTER TABLE employee
ADD CONSTRAINT fk_dept
FOREIGN KEY (dept_id) REFERENCES departments(dept_id);

-- Drop the primary key constraint
ALTER TABLE employee
DROP PRIMARY KEY;

🔁 Complete Workflow Example

Oracle SQL — Full ALTER Workflow
-- Step 1: Create the initial table
CREATE TABLE employee (
    id    INT,
    name  VARCHAR2(50)
);

-- Step 2: Add a new column
ALTER TABLE employee ADD address VARCHAR2(200);

-- Step 3: Check schema after adding
DESC employee;    -- shows id, name, address

-- Step 4: Drop the address column
ALTER TABLE employee DROP COLUMN address;

-- Step 5: Modify id's datatype from INT to VARCHAR2
ALTER TABLE employee MODIFY id VARCHAR2(10);

-- Step 6: Increase name size from 50 to 100
ALTER TABLE employee MODIFY name VARCHAR2(100);

-- Step 7: Rename column id to roll_number
ALTER TABLE employee RENAME COLUMN id TO roll_number;

-- Step 8: Add PRIMARY KEY on roll_number
ALTER TABLE employee ADD PRIMARY KEY (roll_number);

-- Step 9: Rename the table itself
ALTER TABLE employee RENAME TO emp11;

-- Step 10: Verify final schema
DESC emp11;

🎯 Exam Focus — Key Q&A

Q1: What category does CREATE TABLE belong to?
👉 DDL — Data Definition Language.

Q2: What command is used to view the schema (structure) of a table in Oracle?
👉 DESC table_name; (or DESCRIBE table_name;)

Q3: Which keyword is mandatory when dropping a column using ALTER?
👉 The keyword COLUMN is mandatory: ALTER TABLE t DROP COLUMN col_name;

Q4: What is the difference between VARCHAR and VARCHAR2 in Oracle?
👉 Oracle recommends VARCHAR2. VARCHAR is silently converted to VARCHAR2. Always use VARCHAR2 in Oracle for safety.

Q5: Can you add multiple columns in a single ALTER statement?
👉 Yes — wrap multiple column definitions in parentheses: ALTER TABLE t ADD (col1 TYPE, col2 TYPE);

Q6: How do you rename a table in Oracle SQL?
👉 ALTER TABLE old_name RENAME TO new_name;
