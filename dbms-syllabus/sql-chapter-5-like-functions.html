🔍 Part A: LIKE Command in SQL

The LIKE command is used to search/filter data based on a partial pattern in a column. Unlike WHERE col = 'value' which requires an exact match, LIKE lets you use wildcards to search by pattern — for example, find all names starting with 'A', or containing 'ee', or exactly 5 characters long.

🃏 The Two LIKE Wildcards

%
Percent Sign — Any sequence
Represents zero or more characters of any kind. Use when you don't care how many characters are there or what they are.
_
Underscore — Exactly one character
Represents exactly one character. Use when you want to fix the length or position of a specific character in the string.
📌 LIKE Syntax
SELECT * FROM table_name WHERE column_name LIKE 'pattern';

The pattern is enclosed in single quotes. The % and _ wildcards appear inside the pattern string.

❌ Karuna (6 chars), Ranjeet (7 chars), Arun (4 chars)

📝 SQL Queries — All 5 Cases

Oracle SQL — LIKE Patterns
-- Case 1: Name starts with 'A'
SELECT * FROM emp WHERE name LIKE 'A%';
-- Output: Arun, Amrit, Ajeet

-- Case 2: Name ends with 'n'
SELECT * FROM emp WHERE name LIKE '%n';
-- Output: Varun, Arun

-- Case 3: Name contains 'ee' anywhere
SELECT * FROM emp WHERE name LIKE '%ee%';
-- Output: Ajeet, Ranjeet

-- Case 4: Second letter is 'a' (any first char + a + anything)
SELECT * FROM emp WHERE name LIKE '_a%';
-- Output: Varun, Karuna, Ranjeet

-- Case 5: Second letter 'a' AND exactly 5 characters total
SELECT * FROM emp WHERE name LIKE '_a___';
-- Output: Varun (1 underscore + a + 3 underscores = 5 chars total)

⚠️ Key Decision Rule
Use % when the number of characters doesn't matter (zero or more, anything).
Use _ when you want to fix exactly one character position (fixes both the position and the count of 1 character).

Example: '_a___' means exactly 5 characters total with 'a' in position 2.

⚙️ Part B: Single Row vs Multi Row Functions

SQL has two major categories of functions — Single Row Functions (applied per row, return one output per row) and Multi Row Functions (applied across multiple rows, return one combined output). Understanding this distinction is crucial for GATE, Oracle Certification (OCA), and placement interviews.

⚡ The Core Distinction

🔹 Single Row Functions

Applied to one row at a time. Returns one output per input row. If a table has 6 rows, a single row function returns 6 results.

e.g., UPPER('varun') → 'VARUN'
Applied separately on each name row.
🔷 Multi Row Functions (Aggregate)

Applied across multiple rows. Returns one single output for all those rows combined, regardless of how many rows.

e.g., SUM(salary) → 1,40,000
Adds all salary rows → one answer.
📌 Exam Tip
Multi Row Functions = Aggregate Functions (MAX, MIN, COUNT, SUM, AVG) — already covered in Chapter 4. The focus of this chapter's Part B is on Single Row Functions and their sub-categories.

SELECT ROUND(50.926, 2) FROM dual;   -- Output: 50.93
SELECT TRUNC(50.926, 2) FROM dual;   -- Output: 50.92
SELECT MOD(10, 3)      FROM dual;   -- Output: 1

🔧 4. General Functions (NULL Handling)

General functions primarily help handle NULL values in SQL. NULL handling is a critical concept in Oracle SQL.

FunctionPurposeExample → Output
NVL(expr, replacement)Replaces NULL with a given valueNVL(salary, 0) → if salary is NULL, returns 0
NVL2(expr, val1, val2)If NOT NULL → val1, if NULL → val2NVL2(salary, 'Has Salary', 'No Salary')
COALESCE(e1, e2, ...)Returns first non-NULL value from listCOALESCE(NULL, NULL, 500) → 500
CASE WHEN...THEN...ENDIf/else logic inside a queryConditional output based on column value
DECODE(col, v1, r1, ...)Oracle-specific if/else shorthandDECODE(dept,'HR','Human Res','Unknown')
Oracle SQL — General Functions
-- NVL: replace NULL salary with 0
SELECT name, NVL(salary, 0) FROM emp;

-- CASE: if/else conditional output
SELECT name,
  CASE WHEN salary > 30000 THEN 'High'
       WHEN salary > 15000 THEN 'Mid'
       ELSE 'Low'
  END AS salary_band
FROM emp;

-- DECODE: same as above using Oracle shorthand
SELECT name, DECODE(dept, 'IT', 'Tech Team', 'HR', 'HR Team', 'Other') FROM emp;

🎯 Exam Focus — Key Q&A

Q1: What is the difference between % and _ in LIKE?
👉 % matches zero or more characters of any kind. _ matches exactly one character. % is for unknown/variable length; _ is for fixing a specific position.

Q2: How do you find names starting with 'A'?
👉 WHERE name LIKE 'A%' — A is fixed at position 1, % allows anything after.

Q3: How to find names with exactly 5 characters?
👉 WHERE name LIKE '_____' (five underscores, each fixing exactly one character position)

Q4: How to find names with 'a' as the second letter and exactly 5 characters total?
👉 WHERE name LIKE '_a___' — _ fixes position 1, a fixes position 2, ___ fix positions 3-4-5.

Q5: What is the key difference between ROUND and TRUNC?
👉 ROUND rounds the number normally (≥5 rounds up). TRUNC simply cuts off at the specified decimal — no rounding ever occurs.

Q6: What are Single Row Functions? Give one example from each category.
👉 Functions applied to one row at a time, returning one output per row. Examples: Number→ROUND, Char→UPPER, Date→ADD_MONTHS, General→NVL, Conversion→TO_CHAR.

Q7: What is the difference between Single Row and Multi Row functions?
👉 Single row functions return one output per row (N rows → N results). Multi row functions (aggregate) operate on multiple rows and return one combined result (N rows → 1 result).

Q8: What is INITCAP in Oracle SQL?
👉 INITCAP converts the first letter of every word in a string to uppercase. INITCAP('hello world') → 'Hello World'.

Q9: What is NVL used for?
👉 NVL handles NULL values. NVL(salary, 0) replaces NULL salary with 0 in the output, without changing the actual stored data.

Q10: What does the pattern '%ee%' match?
👉 It matches any string that contains 'ee' anywhere in the name — at the start, middle, or end. e.g., Ajeet, Ranjeet.
